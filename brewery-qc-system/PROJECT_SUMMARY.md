# 精酿酒厂品控检测与放行判断交班系统

## 项目概述

本系统解决精酿酒厂品控检测与放行判断之间的责任不清问题，实现检测备注流转、角色差异化入口、状态清晰追踪。

## 在线预览

开发服务器运行在: http://localhost:3002/

## 角色入口

### 1. 酿酒师 (/brewer)
**核心功能:**
- 发酵罐监控卡片（温度、比重、压力）
- 发起品控检测申请
- 查看批次列表和状态
- 查看检测结果和备注

**页面特点:**
- 发酵罐实时状态展示
- 异常发酵罐高亮提醒
- 批次状态一目了然

### 2. 包装主管 (/packaging)
**核心功能:**
- 待检测批次处理
- 品控检测执行
- 批量操作（批量通过、批量导出）
- 异常标注处理

**页面特点:**
- 异常批次红色高亮 + 脉冲动画提醒
- 批量选择和批量操作
- 检测状态实时更新

### 3. 销售内勤 (/sales)
**核心功能:**
- 待放行批次审核
- 检测记录完整回看
- 放行/拒签判断操作
- 添加放行备注

**页面特点:**
- 异常批次顶部警示条
- 标签页切换（全部待放行/异常批次/处理记录）
- 最新检测结论直接展示
- 备注流转全程可追溯

### 4. 交班记录 (/records)
**核心功能:**
- 所有操作记录时间线视图
- 按角色筛选操作记录
- 操作人、时间、内容完整记录
- 责任追溯一目了然

## 模拟数据位置

所有模拟数据存储在 `src/data/mock/` 目录下:

| 文件 | 说明 |
|------|------|
| `batches.ts` | 批次基础数据（批次号、产品名、配方、发酵罐、状态等） |
| `testRecords.ts` | 检测记录（检测项、标准值、实测值、结论） |
| `notes.ts` | 备注流转数据（各角色添加的备注、时间、角色） |
| `statusLogs.ts` | 状态流转日志（状态变更、操作人、时间、备注） |

## 核心流程

```
酿酒师发起检测 → 批次进入待检测
    ↓
包装主管执行检测 → 填写检测数据 + 备注
    ↓
    ├─ 检测正常 → 待放行状态
    └─ 检测异常 → 异常提醒 + 待放行状态
    ↓
销售内勤回看记录 → 查看完整检测流程 + 历史备注
    ↓
    ├─ 放行通过 → 已放行，可安排发货
    └─ 拒签退回 → 退回重检，记录备注
```

## 视觉层级设计

### 色彩系统
- **主色调**: 深琥珀色 #8B4513（代表精酿啤酒质感）
- **正常状态**: 酒花绿 #2E8B57
- **异常状态**: 警示橙 #FF6B35（带脉冲动画提醒）
- **信息状态**: 确认蓝 #4A90D9

### 视觉层次
1. **顶部警示条**: 异常批次红色高亮，最高优先级
2. **统计卡片**: 4个关键指标，使用渐变色区分
3. **状态标签**: 不同颜色圆角标签，异常带脉冲动画
4. **异常行高亮**: 表格/列表中异常批次背景色高亮
5. **时间线视图**: 交班记录垂直时间线，不同角色颜色区分

## 暂未实现的集成点

| 集成点 | 说明 | 优先级 | 对接方式 |
|--------|------|--------|----------|
| 发酵罐记录系统 | 自动获取发酵温度、压力等实时数据 | 高 | REST API |
| 配方管理系统 | 拉取产品配方标准参数、检测标准 | 中 | REST API |
| 经销商订货群 | 同步放行信息到经销商微信群 | 中 | Webhook/企业微信机器人 |
| 条码打印系统 | 放行后自动生成并打印产品条码 | 低 | SDK |
| 仓储管理系统 | 放行后通知WMS系统入库 | 低 | REST API |

## 技术栈

- **前端框架**: React 18 + TypeScript
- **构建工具**: Vite 8
- **样式方案**: TailwindCSS 4
- **状态管理**: Zustand
- **路由方案**: React Router 7
- **图标库**: Lucide React
- **动画方案**: Framer Motion
- **日期处理**: date-fns
