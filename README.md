# 乳品配送站 - 月结账单与客户申诉系统

## 系统概述

本系统用于乳品配送站的月结账单管理和客户申诉处理，解决了账单和申诉之间责任不清的问题。系统围绕月结账单和客户申诉分别设计了独立的管理模块，各角色（站点文员、配送员、客服）职责清晰，详情页可回看完整历史记录。

## 技术栈

- **后端**: Node.js + Express
- **前端**: React 18 + React Router
- **数据存储**: 内存存储（便于演示）

## 核心功能

### 1. 月结账单管理
- 账单列表展示，支持按状态、月份、客户姓名筛选
- 新建账单，支持多奶品明细录入
- 账单详情页：基本信息、费用明细、回瓶情况、处理信息
- 状态流转：待处理 → 处理中 → 已退回/待补材料 → 已关闭
- 批量处理：批量标记处理、催促、关闭
- 关联申诉查看：可查看账单关联的所有客户申诉

### 2. 客户申诉管理
- 申诉列表展示，支持按状态、类型、客户姓名筛选
- 新建申诉，支持关联已有账单
- 申诉详情页：基本信息、问题描述、证据材料、处理信息
- 状态流转：待处理 → 处理中 → 已退回/待补材料 → 已关闭
- 批量处理：批量标记处理、要求补材料、关闭
- 证据材料上传管理

### 3. 关联与跳转
- 从月结账单可直接发起客户申诉，自动带入客户信息
- 客户申诉详情页显示关联的月结账单信息
- 双向跳转不丢失责任人和历史说明

### 4. 历史记录
- 所有状态变更都记录操作人、操作时间、状态变化、处理说明
- 详情页专门的"处理历史"标签页展示完整历史轨迹

## 状态说明

| 状态 | 说明 |
|------|------|
| 待处理 | 刚创建，等待分配处理 |
| 处理中 | 正在处理中 |
| 已退回 | 处理有问题，退回上一级 |
| 待补材料 | 需要客户补充证据材料 |
| 有人催 | 客户或领导催办，优先处理 |
| 已关闭 | 处理完成，结案 |

## 快速开始

### 1. 安装依赖

```bash
# 安装后端依赖
npm install

# 安装前端依赖
cd client && npm install
```

### 2. 启动服务

```bash
# 方式一：同时启动前后端（推荐）
npm run dev

# 方式二：分别启动
# 启动后端（端口 5000）
npm run server

# 启动前端（端口 3000）
cd client && npm start
```

### 3. 访问系统

打开浏览器访问：http://localhost:3000

## 演示路径

系统已预置演示数据，覆盖完整业务流程：

### 路径一：月结账单完整流程
1. 进入「月结账单」列表
2. 点击「新建账单」创建一个新账单（状态：待处理）
3. 点击账单进入详情页
4. 点击「开始处理」（状态：处理中）
5. 点击「要求补材料」（状态：待补材料）
6. 点击「标记催促」（状态：有人催）
7. 点击「退回」（状态：已退回）
8. 点击「关闭」（状态：已关闭）
9. 切换到「处理历史」标签页，查看完整操作轨迹

### 路径二：客户申诉完整流程
1. 进入「客户申诉」列表
2. 点击「新建申诉」创建一个新申诉
3. 点击申诉进入详情页
4. 点击「开始处理」（状态：处理中）
5. 点击「要求补材料」（状态：待补材料）
6. 点击「补充材料」上传证据（自动转回处理中）
7. 点击「退回」（状态：已退回）
8. 点击「标记催促」（状态：有人催）
9. 点击「关闭」（状态：已关闭）
10. 切换到「处理历史」标签页，查看完整操作轨迹

### 路径三：账单与申诉关联
1. 进入「月结账单」，选择一个有「待处理」状态的账单
2. 进入详情页，点击「发起申诉」
3. 系统自动跳转到申诉创建页面，并预填账单和客户信息
4. 填写申诉内容后提交
5. 在申诉详情页可看到关联的账单信息
6. 点击关联的账单编号，可跳转回账单详情页
7. 在账单详情页的「关联申诉」标签页中可看到刚才创建的申诉

### 路径四：批量处理
1. 进入「月结账单」或「客户申诉」列表
2. 勾选多个条目
3. 使用顶部的批量操作按钮进行批量处理

## API 接口

### 月结账单接口

- `GET /api/bills` - 获取账单列表（支持筛选）
- `GET /api/bills/:id` - 获取账单详情（含关联申诉）
- `POST /api/bills` - 创建新账单
- `PUT /api/bills/:id/status` - 更新账单状态
- `POST /api/bills/batch-update` - 批量更新账单状态

### 客户申诉接口

- `GET /api/complaints` - 获取申诉列表（支持筛选）
- `GET /api/complaints/:id` - 获取申诉详情（含关联账单）
- `POST /api/complaints` - 创建新申诉
- `PUT /api/complaints/:id/status` - 更新申诉状态
- `POST /api/complaints/batch-update` - 批量更新申诉状态
- `POST /api/complaints/:id/evidence` - 补充证据材料

### 通用接口

- `GET /api/status` - 获取状态和角色常量
