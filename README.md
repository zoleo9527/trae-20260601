# 社区志愿服务站管理系统

## 项目概述

本系统旨在替代社区志愿服务站的旧台账、现场记录和沟通截图，提供活动报名处理、岗位分配、异常管理等核心功能，解决时长漏记、活动临时取消、重点对象回访断档等问题。

## 技术架构

### 后端
- **框架**: FastAPI
- **数据库**: SQLite（开发环境）
- **认证**: JWT Token
- **ORM**: SQLAlchemy

### 前端
- **框架**: Vue 3 + Vite
- **UI组件**: Element Plus
- **状态管理**: Pinia
- **路由**: Vue Router

## 核心功能

### 1. 活动报名处理
- 活动创建、编辑、取消
- 报名列表展示与筛选
- 报名审核（通过/拒绝）
- 备注信息流转（报名备注可被岗位分配继续使用）

### 2. 岗位分配回看
- 岗位创建与管理
- 志愿者与岗位匹配
- 分配状态实时查看
- 名额容量管理

### 3. 异常处理抽屉
- 异常类型：时长漏记、活动取消、回访断档、岗位未填满、报名卡壳
- 异常状态追踪：待处理、处理中、已解决
- 处理意见记录

### 4. 附件占位
- 活动附件上传与管理
- 支持签到表、活动照片等文件类型

## 简化说明

### 权限简化
- 用户角色分为四类：站点社工、志愿队长、社区干部、志愿者
- 当前版本未实现细粒度权限控制，所有登录用户均可访问所有功能
- 后续可扩展基于角色的权限控制（RBAC）

### 附件简化
- 附件仅支持基础上传和删除功能
- 文件存储在本地服务器目录（uploads/）
- 未实现文件预览、下载统计等高级功能
- 未对接云存储服务（如阿里云OSS、腾讯云COS）

### 通知简化
- 当前版本未实现站内消息通知功能
- 未实现短信、邮件等外部通知渠道
- 后续可扩展消息中心模块

### 外部系统简化
- 未对接社区网格化管理平台
- 未对接志愿者时长认证系统
- 未对接政务服务平台接口
- 数据仅存储在本地数据库

## 快速开始

### 环境要求
- Python 3.10+
- Node.js 18+

### 启动后端

```bash
cd backend
pip install -r requirements.txt
python init_data.py
python run.py
```

后端服务运行在 http://localhost:8000

### 启动前端

```bash
cd frontend
npm install
npm run dev
```

前端服务运行在 http://localhost:5173

## 系统回答的三个核心问题

1. **谁在处理**：每个报名记录都记录了处理人信息，可追踪站点社工、志愿队长、社区干部的操作记录
2. **活动报名卡在哪里**：通过异常记录模块追踪报名卡壳情况，支持筛选和状态管理
3. **岗位分配为什么还没完成**：岗位列表显示当前名额占用情况，待分配人员列表显示已通过但未分配的志愿者
