# 宠物医院住院护理管理系统

将住院护理、医嘱执行、复诊安排统一到一个平台，解决护理记录分散在笼卡、病历、前台表格三处的问题。

## 快速启动

```bash
# 安装依赖
npm install

# 启动开发服务器（前端 + 后端同时启动）
npm run dev
```

- 前端地址：http://localhost:5173
- 后端 API：http://localhost:3001

首次启动时，SQLite 数据库会自动创建并填入演示数据。

## 如何切换角色

页面**右上角**有角色切换按钮，支持三种角色：

| 角色 | 侧边栏入口 | 看到的重点 |
|------|-----------|-----------|
| **医生** | 住院总览 | 病情趋势（好转/稳定/加重）、诊断信息、异常记录数 |
| **住院护士** | 住院总览 + 今日任务 | 今日待办数量、异常标记、护理任务执行 |
| **前台客服** | 住院总览 + 复诊提醒 | 主人联系方式、复诊状态、沟通记录 |

切换角色后，住院列表卡片显示的内容会立即变化，侧边栏导航也会调整。

## 核心功能

### 护理时间线
- 进入宠物详情页 → 「护理时间线」Tab
- 按时间倒序展示所有护理事件，左侧有时间轴连线
- 异常事件红色边框高亮，附带异常说明
- 支持按类型筛选（用药/换药/喂食/输液/观察/体征）

### 今日任务（护士视图）
- 侧边栏 → 「今日任务」
- 分三组展示：异常/待处理 → 待执行 → 已完成
- 点击「完成」按钮可一键标记任务完成

### 复诊提醒（前台视图）
- 侧边栏 → 「复诊提醒」
- 按状态分组：已逾期 → 待预约 → 其他
- 逾期项红色醒目提示
- 点击「确认预约」或「改期」操作

### 客户沟通记录
- 进入宠物详情页 → 「沟通记录」Tab
- 记录每次与主人沟通的时间、方式（电话/微信/到院）、内容和结果

## 已简化的部分

| 模块 | 简化说明 |
|------|---------|
| **用户认证** | 无登录系统，通过顶部角色按钮切换，所有角色可互相切换 |
| **病历系统** | 仅有诊断和病情趋势字段，无完整病历编辑、影像附件等功能 |
| **收费系统** | 完全未实现，无费用计算、收费记录 |
| **排班系统** | 无护士排班表，执行人通过文本记录 |
| **权限控制** | 前端仅控制显示内容，无后端权限校验 |
| **实时通知** | 无 WebSocket 推送，需手动刷新页面 |
| **数据持久化** | SQLite 本地文件存储，适合演示，非生产级部署 |

## 技术栈

- 前端：React 18 + TypeScript + Tailwind CSS + Zustand
- 后端：Express 4 + TypeScript (ESM)
- 数据库：SQLite (better-sqlite3)
- 构建工具：Vite
