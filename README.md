# 蓝领招聘平台 - 入职回执与稳定期跟踪系统

## 系统概述

本系统是一个基于Python + PyQt5开发的桌面应用程序，专为蓝领招聘平台设计，用于管理入职回执与稳定期跟踪。系统支持离线使用，所有数据存储在本地SQLite数据库中。

## 功能模块

### 1. 仪表板
- **待处理事项统计**: 显示待处理回执、待面试、风险预警、在招岗位数量
- **待处理事项列表**: 列出所有待处理的入职回执和面试
- **风险预警列表**: 显示所有标记为风险预警的稳定期跟踪记录
- **最近变更记录**: 显示系统最近15条操作记录
- **即将过期岗位**: 显示7天内即将过期的在招岗位

### 2. 岗位发布管理
- 添加、编辑岗位信息
- 设置岗位状态（招聘中、暂停、已关闭、已过期）
- 设置返费条件和返费金额
- 设置岗位发布日期和过期日期
- 按状态筛选岗位

### 3. 面试名单管理
- 添加、编辑面试记录
- 关联岗位信息
- 设置面试状态（待面试、已面试、爽约、通过、未通过等）
- 面试通过后可直接创建入职回执

### 4. 入职回执处理
- 添加入职回执（关联面试记录）
- 上传回执照片
- 核实/驳回回执
- 设置返费金额和返费到期日
- 回执核实后自动创建稳定期跟踪记录

### 5. 稳定期跟踪
- 显示所有稳定期跟踪记录
- 进度条显示稳定期完成百分比
- 更新工作天数和状态
- 标记风险预警
- 记录返费支付情况
- 设置下次检查日期

## 状态口径说明

系统使用统一的状态定义，确保运营、招聘顾问、企业HR看到的信息口径一致：

| 模块 | 状态 | 说明 |
|------|------|------|
| 岗位 | 招聘中 | 正在招聘的岗位 |
| 岗位 | 暂停 | 暂时停止招聘 |
| 岗位 | 已关闭 | 招聘结束 |
| 岗位 | 已过期 | 超过过期日期 |
| 面试 | 待面试 | 已安排面试时间 |
| 面试 | 已面试 | 面试已完成 |
| 面试 | 爽约 | 候选人未到场 |
| 面试 | 通过 | 面试通过，可入职 |
| 靺试 | 未通过 | 面试未通过 |
| 回执 | 待处理 | 回执已提交，待核实 |
| 回执 | 已核实 | 回执已核实，进入稳定期 |
| 回执 | 已驳回 | 回执信息有误，需重新提交 |
| 稳定期 | 稳定期中 | 正在稳定期跟踪中 |
| 稳定期 | 已完成 | 稳定期已满，返费已支付 |
| 稳定期 | 提前离职 | 候选人提前离职 |
| 稳定期 | 风险预警 | 需要关注的候选人 |

## 安装与运行

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 初始化样例数据（可选）
```bash
python init_sample_data.py
```

### 3. 启动系统
```bash
python main.py
```

## 数据存储

系统使用SQLite数据库存储所有数据，数据库文件名为 `recruitment.db`，位于程序运行目录下。数据完全离线存储，无需联网。

## 责任分工建议

| 角色 | 主要职责 |
|------|----------|
| 运营 | 入职回执核实、稳定期跟踪更新、返费支付确认 |
| 招聘顾问 | 岗位发布、面试安排、面试结果记录 |
| 企业HR | 岗位信息确认、入职回执提交、稳定期状态反馈 |

## 注意事项

1. 入职回执核实后会自动创建稳定期跟踪记录，无需手动创建
2. 稳定期默认为30天，可在入职回执中设置
3. 风险预警会在仪表板突出显示
4. 岗位过期日期到期后建议及时更新状态
5. 面试爽约记录可用于分析候选人质量

- **数据库**: SQLite
