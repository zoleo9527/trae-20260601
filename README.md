# 家政服务公司 - 过程反馈与加项记录管理系统

## 项目简介

本系统旨在解决家政服务公司在过程反馈与加项记录管理中"卡单"问题发现滞后的问题。通过实时监控、异常预警和责任追踪，让管理者能够第一时间发现并处理卡住的单子。

**核心价值**：从"事后发现"转变为"实时暴露"，让客服、家政员、质检主管的处理进度透明可见，过程反馈卡点和加项记录延误原因一目了然。

## 数据重置方式

### 方式1：页面操作

在监控看板页面或个人中心页面，点击"重置数据"按钮，即可将所有模拟数据恢复到初始状态。

### 方式2：浏览器操作

打开浏览器开发者工具（F12），在Console中执行：

```javascript
localStorage.clear()
```

然后刷新页面，系统会自动重新初始化模拟数据。

### 方式3：手动删除特定数据

如果只想重置特定类型的数据，可以在Console中执行：

```javascript
// 只重置订单数据
localStorage.removeItem('orders')

// 只重置过程反馈数据
localStorage.removeItem('feedbacks')

// 只重置加项记录数据
localStorage.removeItem('additions')

// 只重置异常处理记录
localStorage.removeItem('handles')
```

然后刷新页面。

- **模拟方式**：使用固定的模拟用户数据，无需真实认证
- **用户列表**：

- **切换用户**：在个人中心页面点击用户卡片即可切换

### 2. 实时推送通知

- **模拟方式**：使用定时轮询（每30秒）检测卡单状态，非WebSocket
- **检测逻辑**：
  - 订单在"反馈处理中"状态停留超过30分钟 → 标记为卡单
  - 加项记录在"待确认"状态停留超过1小时 → 标记为卡单
  - 卡单自动推送到监控看板的预警面板

### 3. 数据持久化

- **模拟方式**：使用localStorage存储，非真实数据库
- **存储位置**：浏览器本地存储
- **数据类型**：
  - `orders` - 订单数据（20条，其中5条为卡单）
  - `feedbacks` - 过程反馈数据（15条，其中3条为卡住状态）
  - `additions` - 加项记录数据（10条，其中2条为未完成状态）
  - `users` - 用户数据（6个用户）
  - `handles` - 异常处理记录

### 4. 后端API

- **模拟方式**：所有API返回Mock数据，无真实后端
- **服务层**：
  - `orderService` - 订单相关操作
  - `feedbackService` - 过程反馈相关操作
  - `additionService` - 加项记录相关操作
  - `exceptionService` - 异常处理相关操作

## 功能特性

### 1. 监控看板

- **卡单预警面板**：实时展示卡住的订单，按紧急程度排序
- **处理人追踪面板**：显示每个卡单的处理人（客服/家政员/质检主管）
- **状态流转时间线**：可视化展示订单在各状态的停留时长
- **异常处理抽屉**：一键处理卡单，记录处理原因和结果

### 2. 过程反馈管理

- **反馈列表**：展示所有过程反馈，支持筛选和搜索
- **处理进度追踪**：显示反馈卡在哪个环节、谁在处理
- **驳回/补录处理**：提供驳回和补录的正式处理流程

### 3. 加项记录管理

- **记录列表**：展示所有加项记录及其完成状态
- **未完成原因分析**：展示加项记录未完成的具体原因
- **回看功能**：查看加项记录的历史处理记录

### 4. 个人中心

- **用户信息显示**：显示当前用户信息和在线状态
- **用户切换功能**：模拟登录不同角色用户
- **数据重置功能**：一键重置所有模拟数据

## 技术栈

- **前端框架**：React 18 + TypeScript
- **样式方案**：Tailwind CSS 3
- **构建工具**：Vite
- **状态管理**：Zustand
- **路由管理**：React Router 6
- **图标库**：Lucide React

## 注意事项

1. **数据存储**：所有数据存储在浏览器localStorage中，清除浏览器数据会导致数据丢失
2. **用户切换**：切换用户后会重新加载所有数据，确保数据一致性
3. **卡单检测**：系统每30秒自动检测卡单状态，可通过刷新页面手动触发
4. **模拟能力**：本系统为演示目的，不具备真实的生产环境能力
