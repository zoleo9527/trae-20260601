# 滑雪场运营管理系统 — 教练课程与学员签到

替代人工拼凑的租赁单、教练排班表和救援记录，核心解决**雪具错拿、课程爽约和摔伤记录缺证据**三大痛点。

## 启动方式

```bash
# 安装依赖
npm install

# 同时启动前端 (Vite) 和后端 (Express)
npm run dev

# 或分别启动
npm run client:dev   # 前端 http://localhost:5173
npm run server:dev   # 后端 http://localhost:3001
```

启动后浏览器访问 http://localhost:5173

## 数据重置方式

**方法一：API 重置**

```bash
curl -X POST http://localhost:3001/api/reset
```

**方法二：删除数据文件**

```bash
rm data/ski-resort.json
```

重启后端后，系统会自动生成新的模拟数据（包含今日日期的课程、签到、租赁记录）。

## 角色说明

系统通过左侧导航栏底部的角色切换器在三个角色间切换，各角色看到的信息不同但状态口径一致：

| 角色 | 主要权限 | 主要关注 |
|------|----------|----------|
| 租赁员 | 雪具租赁/归还、错拿异常标记 | 雪具状态、异常归还 |
| 教练主管 | 课程创建/取消/确认、学员报名/签到、爽约标记 | 课程安排、教练排班 |
| 安全巡逻员 | 救援记录创建、附件证据管理 | 证据完整性、伤情严重度 |

## 功能模块

### 仪表盘
- 角色感知的统计指标与告警
- 不同角色看到不同维度的数据和待办事项
- 状态口径一致：所有模块共享同一数据源

### 雪具租赁
- 雪具列表与租赁记录双视图
- 租赁时自动关联学员，归还时显示当前租赁人
- **错拿异常标记**：归还时可标记为"错拿"或"损坏"，记录实际归还人和备注
- 异常归还的雪具自动标记为"维护"状态

### 教练排班
- 课程管理（创建/确认到场/结束/取消）
- 教练状态自动计算（在岗/上课中/休息）
- **学员报名**：为课程添加学员，控制上限
- 结束课程时，未签到学员自动标记为"爽约"

### 学员签到
- **课程签到**：选择课程后批量签到
- **签到回看**：按日期/课程/学员查询历史签到
- **空档检测**：检测课程之间的无人负责空档，确保教练课程到学员签到之间不出现空档

### 救援记录
- 事故录入与**附件占位**（至少1个附件，强制要求证据）
- 缺少附件的记录红色醒目提醒
- 所有附件均为占位时橙色提醒
- 支持补全附件操作

## 模拟能力说明

以下功能为模拟实现，未接入真实硬件或外部服务：

- **附件上传**：救援记录的附件仅作占位标记（`isPlaceholder: true`），不支持真实文件上传与预览
- **角色认证**：角色切换为前端本地状态，无后端鉴权，任意角色可自由切换
- **二维码/扫码**：雪具归还的"扫码"为选择操作，非真实扫码
- **爽约通知**：发送爽约通知为模拟，不会实际发送短信或推送
- **教练排班拖拽**：排班调整为表单操作，非日历拖拽
- **数据存储**：JSON 文件存储，非数据库，并发场景不适用
- **实时同步**：多标签页打开时不会实时同步，需手动刷新

## 技术栈

- 前端：Vue 3 + TypeScript + Vite + Tailwind CSS + Vue Router + Pinia
- 后端：Express 4 + TypeScript（ESM）
- 数据：JSON 文件存储（data/ski-resort.json）
