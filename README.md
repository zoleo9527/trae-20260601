# 会计代账公司换人交接与续约风险管理系统

## 项目简介

本系统旨在解决会计代账公司在客户经理或会计人员变动后出现的信息断层问题。通过数字化交接清单、风险标签管理和续约跟进功能，确保客户服务连续性，降低续约风险，提升客户满意度。

## 核心功能

### 1. 交接管理
- **交接清单填写**：记录未完事项、客户习惯、发票口径、下次申报提醒
- **交接审核**：主管审核交接清单，确认信息完整性
- **历史交接查询**：查看历史交接记录，支持导出和打印

### 2. 续约跟进
- **到期预警**：自动标记临近到期客户（30/60/90天内）
- **风险客户管理**：显示高风险客户列表，支持风险原因标注
- **跟进记录**：记录续约沟通情况，设置下次跟进提醒

### 3. 历史备注查询
- **备注搜索**：按客户、时间、关键词、类型搜索历史备注
- **时间线展示**：以时间线形式展示客户所有历史备注

### 4. 客户管理
- **客户列表**：显示所有客户，支持按状态、风险等级、到期时间筛选
- **客户详情**：显示客户基本信息、服务历史、交接记录、风险标签

### 5. 用户管理
- **角色权限**：会计、客户经理、主管、系统管理员四级权限
- **用户管理**：管理员可创建、编辑、删除用户

## 安装和运行

### 1. 安装依赖
```bash
npm install
```

### 2. 启动开发服务器
```bash
npm run dev
```

这将同时启动前端开发服务器（默认端口5173）和后端API服务器（默认端口3001）。

### 3. 单独启动
```bash
# 仅启动前端
npm run client:dev

# 仅启动后端
npm run server:dev
```

### 4. 构建生产版本
```bash
npm run build
```

## 风险标签系统

- 🔴 **高风险**：红色徽章，显示具体风险原因
- 🟡 **中风险**：黄色徽章，需要关注
- 🟢 **低风险**：绿色徽章，正常状态
- ⚪ **无风险**：灰色徽章，新客户或已续约

## 交接清单模板

交接清单包含四个必填部分：

1. **未完事项**
   - 待处理发票
   - 待申报税种
   - 待核对账目
   - 其他待办事项

2. **客户习惯**
   - 沟通偏好（电话/微信/邮件）
   - 最佳联系时间
   - 特殊要求
   - 注意事项

3. **发票口径**
   - 发票类型
   - 开票频率
   - 特殊开票要求
   - 历史问题记录

4. **下次申报提醒**
   - 申报税种
   - 申报截止日期
   - 申报注意事项
   - 相关附件

## API文档

### 认证相关
- POST `/api/auth/login` - 用户登录
- POST `/api/auth/logout` - 用户登出
- GET `/api/auth/me` - 获取当前用户信息

### 客户管理
- GET `/api/customers` - 获取客户列表
- GET `/api/customers/:id` - 获取客户详情
- POST `/api/customers` - 创建客户
- PUT `/api/customers/:id` - 更新客户信息
- DELETE `/api/customers/:id` - 删除客户

### 交接管理
- GET `/api/handovers` - 获取交接清单列表
- GET `/api/handovers/:id` - 获取交接清单详情
- POST `/api/handovers` - 创建交接清单
- PUT `/api/handovers/:id` - 更新交接清单
- PUT `/api/handovers/:id/approve` - 审核通过交接
- PUT `/api/handovers/:id/reject` - 审核驳回交接

### 续约跟进
- GET `/api/renewals/alerts` - 获取到期预警列表
- GET `/api/renewals/risk-customers` - 获取风险客户列表
- POST `/api/renewals/:customerId/follow-ups` - 添加跟进记录

### 历史备注
- GET `/api/notes` - 搜索历史备注
- GET `/api/notes/:customerId/timeline` - 获取客户备注时间线
- POST `/api/notes` - 添加备注

### 统计数据
- GET `/api/statistics/dashboard` - 获取仪表盘统计数据
