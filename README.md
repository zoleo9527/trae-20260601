# 驾校运营管理系统

## 项目简介

面向驾校运营团队的一体化工作台，以学员为中心视角，将招生顾问、教练、考试专员三个核心角色的工作流有机整合。通过实时数据联动和智能预警机制，确保每个环节的信息变更能够即时同步，让"卡住的单子"一目了然。

## 技术栈

- **前端框架**: React 18 + TypeScript
- **路由**: React Router DOM 7
- **状态管理**: Zustand
- **样式**: Tailwind CSS
- **图标**: Lucide React
- **桌面框架**: Tauri 2.x (可选，用于桌面部署)

## 功能模块

### 1. 驾驶台 (`/`)
- 全局统计概览
- 卡单预警列表
- 各角色工作负载监控
- 学员状态分布

### 2. 学员报名 (`/enrollment`)
- 学员信息录入
- 报名状态管理
- 筛选与搜索
- 卡单标识

### 3. 资料建档 (`/archive`)
- 档案列表管理
- 变更感知中心
- 缺件清单展示

### 4. 教练工作台 (`/coach`)
- 分配学员管理
- 变更通知确认
- 训练进度追踪

### 5. 考试管理 (`/exam`)
- 考试预约
- 成绩录入
- 缺考追踪

### 6. 操作历史 (`/history`)
- 全链路操作追溯
- 多维度筛选
- 变更详情展示

## 数据联动机制

### 变更感知流程

当学员信息被修改时：
1. 自动记录变更日志（操作人、操作时间、变更前后数据对比）
2. 关键字段变更（体检状态、居住证状态）自动生成通知
3. 相关角色（教练、档案员）收到实时通知
4. 通知需确认处理，确保信息同步到位

### 卡单判定规则

| 状态 | 超时阈值 |
|------|----------|
| 待资料审核 | 24小时 |
| 待体检后建档 | 48小时 |
| 已建档未分配教练 | 72小时 |
| 分配教练后未开始训练 | 7天 |

## 后续扩展

如需完整的Tauri桌面应用支持，可执行以下步骤：

1. 添加Tauri依赖：
```bash
npm install @tauri-apps/api@^2.2.0 @tauri-apps/plugin-sql@^2.2.0
npm install -D @tauri-apps/cli@^2.2.4
```

2. 初始化Tauri项目：
```bash
npm run tauri init
```

3. 开发桌面应用：
```bash
npm run tauri:dev
```

4. 构建发布：
```bash
npm run tauri:build
```
