# 司法鉴定所样本接收与流转留痕系统

基于 SvelteKit + SQLite 构建的演示系统。

## 快速启动

```bash
npm install
npm run dev
```

访问 http://localhost:5173

## 演示账号

| 角色 | 用户名 | 密码 | 权限说明 |
|------|--------|------|----------|
| 受理员 | acceptor01 | demo123 | 创建样本登记、接收样本、分配鉴定人 |
| 鉴定人 | appraiser01 | demo123 | 接收后开始检测、补充材料请求、完成鉴定 |
| 质控审核 | quality01 | demo123 | 审核流转记录、退回样本 |
| 管理员 | admin | admin123 | 全部权限 |

## 演示路径

### 1. 创建样本（受理员）
1. 使用受理员账号登录
2. 点击"新建样本登记"
3. 填写案件信息（案号可自动生成）
4. 提交创建

### 2. 接收样本（受理员）
1. 在列表中找到待接收的样本
2. 点击样本卡片查看详情
3. 点击"接收样本"按钮
4. 可选填写接收备注

### 3. 分配鉴定人（受理员）
1. 在样本详情中点击"分配鉴定人"
2. 选择鉴定人
3. 确认分配

### 4. 开始检测（鉴定人）
1. 切换到鉴定人账号
2. 找到已接收的样本
3. 点击"开始检测"
4. 可选填写处理备注

### 5. 补充材料（鉴定人）
1. 在检测中的样本详情中
2. 点击"要求补充材料"
3. 填写补充原因和所需材料清单
4. 提交后样本状态变为"需补充"

### 6. 完成鉴定（鉴定人）
1. 检测完成后点击"完成鉴定"
2. 填写完成备注
3. 样本状态变为"已完成"

### 7. 退回样本（质控审核）
1. 质控人员可查看任意样本
2. 发现问题可点击"退回样本"
3. 填写退回原因
4. 样本回到待处理状态

## 系统特性

### 现场压力感设计
- **优先级标签**：特急/紧急/普通/低四档，颜色区分
- **3天内到期提醒**：红色高亮显示
- **待处理数量统计**：实时显示各状态样本数
- **紧急案件标记**：醒目提示

### 流转留痕
- 每次状态变更都记录操作人、时间、备注
- 完整展示样本生命周期
- 支持回溯查看历史操作

### 角色权限
- 不同角色看到不同的操作按钮
- 受理员：创建、接收、分配
- 鉴定人：检测、补充、完成
- 质控：审核、退回

### 数据持久化
- 使用 SQLite 数据库存储
- 数据保存在 forensic_lab.db 文件
- 刷新页面数据不丢失

## 技术栈

- **前端**：SvelteKit + Svelte
- **后端**：Node.js API Routes
- **数据库**：SQLite (better-sqlite3)
- **认证**：Session Cookie

## 项目结构

```
src/
├── lib/
│   ├── components/     # UI 组件
│   ├── server/        # 服务端逻辑
│   │   ├── auth.js    # 认证
│   │   ├── db.js      # 数据库
│   │   └── samples.js # 样本业务
│   ├── api.js         # API 客户端
│   └── stores.js      # Svelte Store
└── routes/
    ├── api/           # API 端点
    ├── login/         # 登录页
    └── +page.svelte   # 主页面
```

- `sample_flows` - 流转记录表
- `notifications` - 通知表
