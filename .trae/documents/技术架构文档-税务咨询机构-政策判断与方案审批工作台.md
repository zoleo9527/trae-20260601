# 税务咨询机构 - 政策判断与方案审批工作台 技术架构文档

## 1. 技术栈选型

### 1.1 前端技术栈
基于用户需求和PRD文档，本项目选择以下技术栈：

- **React 18.2+**：核心框架，支持函数式组件和Hooks
- **TypeScript 5.0+**：类型安全，提高代码质量
- **Vite 5.0+**：构建工具，开发体验优秀
- **Tailwind CSS 3.4+**：原子化CSS框架，快速构建样式
- **Zustand**：轻量级状态管理，简单易用
- **React Router 6**：路由管理
- **React Query 5**：服务端状态管理，处理数据请求和缓存

### 1.2 UI组件库
- **Headless UI**：无头组件库，提供可访问性基础
- **Radix UI**：底层组件原语，质量高
- **clsx + tailwind-merge**：动态类名组合

### 1.3 工具库
- **dayjs**：日期时间处理，轻量级
- **lodash-es**：工具函数库（按需引入）
- **react-hot-toast**：通知提示

## 3. 核心数据模型

### 3.1 工单模型
```typescript
interface WorkOrder {
  id: string;                        // 工单ID
  orderNo: string;                   // 工单编号（TC-2024-00123）
  customerName: string;             // 客户名称
  businessType: BusinessType;       // 业务类型
  urgencyLevel: UrgencyLevel;        // 紧急程度
  status: WorkOrderStatus;           // 当前状态
  assignee: string;                  // 责任人
  createdAt: string;                 // 创建时间
  updatedAt: string;                 // 更新时间
  
  // 政策判断信息
  policyJudgment?: PolicyJudgment;
  
  // 审批信息
  approval?: Approval;
  
  // 签收信息
  signReceipt?: SignReceipt;
  
  // 附件
  attachments: Attachment[];
  
  // 历史备注
  historyRemarks: HistoryRemark[];
}

type BusinessType = '政策咨询' | '税务筹划' | '争议处理';
type UrgencyLevel = '普通' | '紧急' | '加急';
type WorkOrderStatus = 
  | '待判断'      // 0
  | '判断中'      // 1
  | '待审批'      // 2
  | '审批通过'    // 3
  | '审批驳回'    // 4
  | '已签收'      // 5
  | '处理完成';   // 6

interface PolicyJudgment {
  judgmentBasis: string;            // 判断依据
  policyReference: string;          // 政策引用
  riskWarning: string;               // 风险提示
  handlingSuggestion: string;       // 处理意见
  judgedBy: string;                 // 判断人
  judgedAt: string;                 // 判断时间
}

interface Approval {
  approvalOpinion: string;           // 审批意见
  approvalResult: '通过' | '驳回';
  rejectReason?: string;             // 驳回原因（驳回时必填）
  approvedBy: string;                // 审批人
  approvedAt: string;                // 审批时间
}

interface SignReceipt {
  receiptConfirm: string;            // 签收确认
  receiptRemark: string;            // 签收备注
  receivedBy: string;               // 签收人
  receivedAt: string;               // 签收时间
}

interface HistoryRemark {
  id: string;
  timestamp: string;                 // 操作时间
  operator: string;                 // 操作人
  action: string;                   // 操作描述
  detail?: string;                   // 详细信息
  attachments?: string[];            // 附件
}

interface Attachment {
  id: string;
  name: string;                      // 文件名
  type: string;                      // 文件类型
  size: number;                      // 文件大小
  url: string;                       // 文件地址
  uploadedBy: string;                // 上传人
  uploadedAt: string;                // 上传时间
}
```

```typescript
    canSignReceipt: true,
  },

```

### 4.2 权限Hook
```typescript
// hooks/usePermissions.ts
export const usePermissions = () => {
  const user = useAuthStore((state) => state.user);
  
  const canView = (view: string) => {
    return permissions[user.role]?.views.includes(view) ?? false;
  };
  
  const canDo = (action: string) => {
    return permissions[user.role]?.actions.includes(action) ?? false;
  };
  
  return { canView, canDo, role: user.role };
};
```

## 10. 开发规范

### 10.1 命名规范
- 组件：PascalCase（如WorkOrderList）
- 文件：kebab-case（如work-order-list.tsx）
- 函数/变量：camelCase
- 常量：UPPER_SNAKE_CASE
- 类型/接口：PascalCase（带Type/Interface后缀）

### 10.2 代码格式
- 使用Prettier格式化代码
- ESLint检查代码质量
- Git Hooks提交前检查

### 10.3 提交规范
- feat：新功能
- fix：bug修复
- docs：文档更新
- style：代码格式（不影响功能）
- refactor：重构
- test：测试
- chore：构建/工具
