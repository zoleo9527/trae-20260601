## 1. 产品概述

铁路货运站到站通知与提货校验系统，解决到货后无人提、错人提、证件不全三大顽疾。到站通知不等于发完短信就结束——从通知发起到提货签收全链路可回查，确保每票货物"谁通知、谁验证、谁放行"一目了然。

- 核心用户：铁路货运站客服、货运员、装卸班长
- 目标：杜绝冒领、漏领，实现提货全流程闭环可追溯

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 客服 | 系统登录 | 到站登记、发送通知、查看通知记录 |
| 货运员 | 系统登录 | 证件复核、提货办理、异常放行审批 |
| 装卸班长 | 系统登录 | 安排提货口、确认装卸完成 |

### 2.2 功能模块

1. **到站总览页**：到站货物状态看板（待通知/待提货/超期/已完成），快速筛选与统计
2. **到站登记与通知页**：到站货物登记、短信/电话通知发送、通知历史回查
3. **提货校验页**：预约提货登记、证件复核（查看货票+通知次数+预约时间+异常备注）、异常放行、签收录入

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能说明 |
|----------|----------|----------|
| 到站总览页 | 状态看板 | 按状态统计货物数量（待通知/已通知/已预约/提货中/超期未提/已完成），点击卡片跳转筛选列表 |
| 到站总览页 | 货物列表 | 表格展示所有到站货物，支持按状态/车次/到站日期筛选，行内显示通知次数与提货状态 |
| 到站登记与通知页 | 到站登记表单 | 录入车次、货票号、品名、重量、收货人、收货人电话、到站时间 |
| 到站登记与通知页 | 通知记录面板 | 侧滑面板展示某票货物的所有通知记录（时间、方式、操作人、回执），支持一键补发通知 |
| 提货校验页 | 预约提货登记 | 录入提货人姓名、证件号、与收货人关系、预约时间 |
| 提货校验页 | 证件复核面板 | 展示货票信息、通知次数、预约时间、异常备注；核验身份证/委托书/提货单，逐项勾选通过 |
| 提货校验页 | 异常放行 | 证件缺失时填写异常原因、审批人、放行条件，记录异常放行日志 |
| 提货校验页 | 签收录入 | 提货完成后录入签收人、签收时间、提货口编号，标记完成 |

## 3. 核心流程

1. 货物到站 → 客服登记到站信息 → 发送到站通知（短信/电话）
2. 收货人收到通知 → 预约提货时间
3. 提货人到站 → 货运员核验证件（身份证+提货单+委托书）→ 复核通过/异常放行
4. 装卸班长安排提货口 → 提货完成 → 签收录入 → 闭环

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深石板灰(#1e293b) + 铁路琥珀橙(#f59e0b) + 钢铁蓝(#3b82f6)
- **按钮风格**：圆角矩形、实体填充、hover 时亮度提升
- **字体**：标题使用 Noto Sans SC Bold，正文使用 Noto Sans SC Regular，数据/编号使用 JetBrains Mono
- **布局风格**：左侧固定导航栏 + 右侧内容区，卡片式布局
- **图标风格**：Lucide 线性图标，2px 描边

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 到站总览页 | 状态看板 | 6张状态卡片（图标+数字+标签），琥珀橙强调超期卡片 |
| 到站总览页 | 货物列表 | 表格+行内状态标签+操作按钮，行内显示通知次数徽章 |
| 到站登记与通知页 | 到站登记表单 | 左侧表单区（分组字段），右侧近期登记快速预览 |
| 到站登记与通知页 | 通知记录面板 | 右侧滑出抽屉，时间轴样式展示通知历史 |
| 提货校验页 | 预约提货登记 | 模态弹窗表单，含证件上传占位 |
| 提货校验页 | 证件复核面板 | 全屏侧滑面板，左侧货票+通知信息，右侧证件核验清单 |
| 提货校验页 | 异常放行 | 红色警告色模态弹窗，需填写原因+审批人 |
| 提货校验页 | 签收录入 | 底部操作栏，一键确认签收+提货口选择 |

### 4.3 响应式设计

- 桌面优先设计（1920px/1440px/1280px）
- 移动端适配：表格转为卡片列表，侧滑面板变为全屏页面
