## 1. 产品概述

电梯维保计划与到场签到系统——解决维保计划执行过程中"计划到了但人没到、人到了但责任说不清"的核心痛点。系统以维保工单为主轴，将计划→签到→处理→审核串联为一条不可分割的链路，让维保技师、客服、项目主管三方接力有据可查。

- 目标用户：电梯维保公司的维保技师、客服人员、项目主管
- 核心价值：消除维保计划与到场签到之间的责任真空，让每一步都有人负责、有据可查

## 2. 核心功能

### 2.1 用户角色

| 角色 | 登录方式 | 核心权限 |
|------|----------|----------|
| 维保技师 | 演示账号自动登录 | 查看待执行计划、到场签到、提交维保记录 |
| 客服 | 演示账号自动登录 | 查看签到状态、跟进异常工单、添加备注 |
| 项目主管 | 演示账号自动登录 | 审核维保完成记录、批量处理、查看统计 |

### 2.2 功能模块

1. **维保工单列表页**：待办/进行中/已完成三种状态看板，角色视角切换，批量操作入口
2. **工单详情页**：维保计划信息、到场签到记录、处理过程时间线、历史备注
3. **到场签到面板**：签到确认、现场照片占位、异常标记、自动流转
4. **批量处理面板**：多选工单批量签到/批量审核

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 维保工单列表 | 状态看板 | 按待办/进行中/已完成分列显示工单，支持角色视角切换 |
| 维保工单列表 | 角色切换 | 一键切换维保技师/客服/项目主管视角，不同角色看到不同操作按钮 |
| 维保工单列表 | 批量操作栏 | 多选工单后出现批量签到/批量审核操作栏 |
| 工单详情 | 维保计划信息 | 电梯编号、维保类型、计划时间、地址等基础信息 |
| 工单详情 | 到场签到区 | 签到按钮、签到时间记录、异常标记选项 |
| 工单详情 | 处理时间线 | 计划创建→技师签到→客服跟进→主管审核的完整时间线 |
| 工单详情 | 历史备注 | 可添加备注，历史备注按时间倒序展示 |
| 到场签到面板 | 签到确认 | 确认到场时间、标记是否异常 |
| 到场签到面板 | 异常上报 | 异常类型选择、异常描述填写 |
| 批量处理 | 批量签到 | 勾选多个待办工单，一键签到 |
| 批量处理 | 批量审核 | 勾选多个待审核工单，一键通过 |

## 3. 核心流程

维保技师从计划列表接到工单→到场后签到（含异常标记）→系统自动流转给客服→客服跟进异常/添加备注→完成后流转给项目主管→主管审核确认完成。签到不是独立菜单，而是工单详情页内的一个动作节点。

```mermaid
flowchart TD
    "维保计划创建" --> "技师接到工单"
    "技师接到工单" --> "到场签到"
    "到场签到" --> "是否异常"
    "是否异常" -->|"正常"| "自动流转客服"
    "是否异常" -->|"异常"| "标记异常+描述"
    "标记异常+描述" --> "自动流转客服"
    "自动流转客服" --> "客服跟进处理"
    "客服跟进处理" --> "流转项目主管"
    "流转项目主管" --> "主管审核"
    "主管审核" -->|"通过"| "工单完成"
    "主管审核" -->|"退回"| "客服跟进处理"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色：深蓝灰 #1E293B（工业感），辅色：琥珀橙 #F59E0B（警示/行动），状态绿 #10B981（完成）
- 按钮风格：圆角微弧（rounded-lg），主操作用实色填充，次要操作用描边
- 字体：Noto Sans SC（中文优先），标题加粗，正文常规
- 布局：左侧导航 + 右侧内容区，卡片式工单展示
- 图标：lucide-react 图标库

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI要素 |
|----------|----------|--------|
| 维保工单列表 | 顶部角色切换栏 | 三角色标签页切换，当前角色高亮 |
| 维保工单列表 | 状态看板 | 三列布局（待办/进行中/已完成），每列显示工单卡片数量 |
| 维保工单列表 | 工单卡片 | 电梯编号、维保类型、计划时间、状态标签、快捷操作按钮 |
| 工单详情 | 头部信息卡 | 电梯编号+地址，状态标签，角色操作按钮组 |
| 工单详情 | 签到区域 | 大号签到按钮，签到后显示签到时间+异常标记 |
| 工单详情 | 时间线 | 竖向时间线，每个节点显示角色、时间、动作 |
| 工单详情 | 备注区 | 输入框+提交按钮，历史备注列表 |

### 4.3 响应式设计

桌面优先设计，内容区最小宽度 1024px，移动端暂不单独适配但保证不溢出。
