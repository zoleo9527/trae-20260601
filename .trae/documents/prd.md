## 1. 产品概述

安防工程商联调测试与问题整改管理系统——替代旧台账、现场记录和沟通截图，将联调测试和问题整改的流程、责任和状态结构化，消除"责任说不清"的痛点。

- 目标用户：安防工程商的项目经理、施工队长、售后工程师
- 核心价值：让联调测试与问题整改之间的责任边界可追溯、可回看、可交班

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 项目经理 | 角色切换选择 | 查看全部联调测试和问题整改、审批测试结果、指派整改责任人、导出交班报告 |
| 施工队长 | 角色切换选择 | 创建/执行联调测试、提交测试结果、从失败测试一键创建问题整改单 |
| 售后工程师 | 角色切换选择 | 接收整改指派、更新整改进度、提交整改完成、标记验证通过 |

### 2.2 功能模块

1. **工作台首页**：按角色展示待办统计、近期动态、快捷入口
2. **联调测试管理**：列表筛选、创建测试、执行测试、记录结果、一键转问题整改
3. **问题整改管理**：列表筛选、创建整改单、更新进度、验证关闭、责任追溯
4. **详情页历史回看**：操作时间线、状态流转记录、责任人变更日志

## 3. 核心流程

**联调测试主流程**：施工队长创建测试 → 执行逐项检测 → 记录结果 → 未通过项一键转问题整改 → 问题整改闭环后回写测试状态

**问题整改主流程**：问题创建（手动或从测试转入）→ 项目经理指派 → 售后工程师整改 → 整改完成待验证 → 项目经理/施工队长验证 → 关闭

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝灰（#1E293B）+ 琥珀橙强调色（#F59E0B），传达安防行业的专业感与警示性
- 按钮风格：圆角8px，主按钮实色填充，次按钮描边
- 字体：标题用思源黑体/Noto Sans SC Bold，正文用系统默认
- 布局：左侧固定导航栏 + 右侧内容区，卡片式布局
- 图标：使用 lucide-vue-next 图标库

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 角色选择页 | 角色卡片 | 三列等宽卡片，各含角色图标+名称+权限摘要，选中态琥珀橙边框 |
| 工作台首页 | 统计卡片行 | 四张统计卡片（待执行测试/未通过测试/待整改问题/待验证问题），数字大号加粗 |
| 工作台首页 | 近期动态 | 左侧时间轴+右侧操作描述，每条含头像+姓名+动作+时间 |
| 联调测试列表 | 筛选栏 | 顶部横排：状态下拉+项目搜索+日期范围，搜索按钮琥珀橙 |
| 联调测试列表 | 测试卡片 | 卡片左侧状态色条（绿=通过/红=未通过/蓝=进行中/灰=待执行），右侧箭头进详情 |
| 联调测试详情 | 时间线 | 左侧竖线+节点圆点，每条含时间戳+操作人徽章+动作描述+变更前后对比 |
| 问题整改列表 | 筛选栏 | 顶部横排：状态下拉+责任人下拉+严重程度下拉，同色系 |
| 问题整改详情 | 状态横幅 | 顶部全宽色条（红=待指派/橙=整改中/蓝=待验证/绿=已关闭），状态文字居中 |
| 问题整改详情 | 来源关联 | 卡片内嵌联调测试摘要，点击跳转 |

### 4.3 响应式设计

- 桌面端优先（1440px 基准），侧边栏固定240px
- 平板端（768-1024px）侧边栏收起为图标模式
- 移动端（<768px）底部Tab导航，卡片单列
