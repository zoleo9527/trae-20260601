## 1. 产品概述

蛋鸡养殖场鸡舍巡检与产蛋记录系统——解决鸡舍日报、饲料表、蛋品分级单之间"巡检和产蛋谁负责"说不清的问题。系统核心回答三个问题：**谁在处理**（饲养员/分拣员/场长）、**巡检卡卡在哪**、**产蛋记录为什么没完成**。

- 目标用户：中小型蛋鸡养殖场的饲养员、分拣员、场长
- 核心价值：让巡检和产蛋两个环节的责任流转可见、可追溯、可催办，异常不沉没

## 2. 核心功能

### 2.1 用户角色

| 角色 | 登录方式 | 核心权限 |
|------|----------|----------|
| 饲养员 | 演示账号登录 | 发起/完成鸡舍巡检、提交巡检异常 |
| 分拣员 | 演示账号登录 | 确认产蛋数据、完成产蛋记录、提交产蛋异常 |
| 场长 | 演示账号登录 | 查看全局看板、催办超时任务、处理升级异常、审批/驳回 |

### 2.2 功能模块

1. **工作台总览**：全局压力看板，实时展示"卡住了"的巡检卡和未完成产蛋记录，按角色聚焦待办
2. **鸡舍巡检处理**：巡检卡流转（待巡检→巡检中→待确认→已完成/异常），超时计时器，异常快速上报
3. **产蛋记录回看**：按鸡舍/日期回看产蛋记录，关联巡检卡状态，异常标记与原因追溯
4. **异常处理抽屉**：右侧抽屉式面板，展示异常详情、处理人、处理动作（指派/催办/驳回/关闭）、处理时间线

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 工作台总览 | 压力指标条 | 今日超时巡检数、未完成产蛋记录数、待处理异常数，红色/橙色/黄色分级 |
| 工作台总览 | 我的待办 | 按角色过滤的待办队列，每条显示：鸡舍号、任务类型、停留时长、当前处理人 |
| 工作台总览 | 巡检卡卡位图 | 可视化展示所有鸡舍巡检卡当前卡在哪个环节（用不同颜色表示停留状态） |
| 工作台总览 | 产蛋记录状态流 | 展示各鸡舍产蛋记录完成状态，未完成的高亮原因标签 |
| 鸡舍巡检处理 | 巡检卡列表 | 按状态筛选巡检卡，支持按鸡舍号搜索，超时卡置顶并红色标记 |
| 鸡舍巡检处理 | 巡检卡详情 | 展示巡检项（温湿度、通风、饮水、采食、鸡群状态等），可逐项填写，支持快速标记异常 |
| 鸡舍巡检处理 | 异常上报浮层 | 巡检过程中发现异常时弹出，填写异常类型/描述/紧急程度，自动关联当前巡检卡 |
| 产蛋记录回看 | 产蛋记录列表 | 按鸡舍/日期范围查询，展示产蛋量、破蛋数、异常标记 |
| 产蛋记录回看 | 记录详情与关联 | 展示单条产蛋记录详情，关联当次巡检卡信息，可查看异常原因 |
| 异常处理抽屉 | 异常详情 | 右侧抽屉展示异常内容、上报人、上报时间、关联鸡舍/巡检卡/产蛋记录 |
| 异常处理抽屉 | 处理动作 | 场长可：指派处理人、催办、驳回、关闭异常；处理人可：更新处理进度 |
| 异常处理抽屉 | 处理时间线 | 展示异常从上报到处理的完整时间线，每步有操作人和时间戳 |

## 3. 核心流程

**巡检卡流转流程**：饲养员从"待巡检"领取→进入"巡检中"→填写巡检项→若正常则"待确认"→分拣员确认产蛋数据→"已完成"；若异常则进入异常队列→场长处理→流转继续或回退。

**产蛋记录流程**：巡检卡到"待确认"状态后，分拣员填写产蛋数据→提交→记录完成；若产蛋数据异常（如产蛋率骤降），自动标记异常并通知场长。

**异常升级流程**：异常超2小时未处理自动升级→场长催办→超4小时场长直接介入处理。

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深灰底色（#1a1a2e）+ 亮橙强调色（#ff6b35）+ 警报红（#e63946）+ 安全绿（#2ec4b6）
- **风格定位**：工业监控台风格，强调信息密度和紧迫感，正常状态只占小区域，异常和超时占据视觉焦点
- **字体**：标题用 Noto Sans SC Bold，正文用 Noto Sans SC Regular，数字用 JetBrains Mono（等宽显示计时器）
- **布局**：顶部压力条 + 左侧导航 + 主内容区 + 右侧异常抽屉
- **图标**：lucide-react 图标库
- **动效**：超时计时器脉冲动画、异常卡闪烁边框、状态变更时的微位移动画

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 工作台总览 | 压力指标条 | 横贯顶部，三段式计数器，超时数字用红色+脉冲动画 |
| 工作台总览 | 我的待办 | 卡片列表，每张卡左侧色条标识优先级，右上角显示停留时长计时器 |
| 工作台总览 | 巡检卡卡位图 | 网格布局，每格一个鸡舍，颜色表示状态：灰=待巡检、蓝=巡检中、橙=待确认、绿=已完成、红=异常 |
| 鸡舍巡检处理 | 巡检卡列表 | 表格式列表，超时行背景渐变红色，状态标签用pill徽标 |
| 鸡舍巡检处理 | 巡检卡详情 | 分区表单，每区有折叠/展开，异常项用红色边框高亮 |
| 产蛋记录回看 | 记录列表 | 表格+筛选栏，异常行用红色左侧线标记，关联巡检卡号可点击跳转 |
| 异常处理抽屉 | 抽屉面板 | 右侧滑入，半透明遮罩，顶部异常摘要，中部处理动作按钮组，底部时间线 |

### 4.3 响应式

桌面优先设计，最小支持 1280px 宽度。移动端仅保留工作台总览和我的待办，异常抽屉改为全屏面板。

### 4.4 轻量能力说明

| 能力 | 实现方式 | 不含糊的边界 |
|------|----------|-------------|
| 导出 | 前端生成 CSV 文件并触发下载，支持巡检记录和产蛋记录两个导出维度 | 仅支持 CSV 格式，不含 PDF/Excel；导出范围按当前筛选条件，最多 90 天 |
| 附件 | 巡检卡和异常上报支持图片上传，存储在服务端 uploads 目录，单文件限 5MB，每条记录限 3 张 | 仅支持 jpg/png，不含文档附件；上传后可预览缩略图，点击查看大图 |
| 消息通知 | 站内通知栏（顶栏铃铛图标），异常上报/催办/升级时推通知，通知列表可标记已读 | 不含短信/邮件/推送，仅站内通知；通知保留 30 天自动清理 |
