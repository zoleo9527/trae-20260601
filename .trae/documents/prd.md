## 1. 产品概述

社区卫生站转诊申请与结果回传系统——解决转诊申请与结果回传之间责任不清、时效不明的问题，为全科医生、护士、公共卫生专员建立可追踪、可回溯的协同处理节奏。

- 核心问题：转诊申请被改动后结果回传侧无法感知，责任归属和时效节点模糊
- 目标用户：社区卫生站全科医生、护士、公共卫生专员

## 2. 核心功能

### 2.1 用户角色

| 角色 | 登录方式 | 核心权限 |
|------|----------|----------|
| 全科医生 | 演示账号登录 | 创建/修改/提交转诊申请，查看结果回传 |
| 护士 | 演示账号登录 | 审核转诊申请，确认结果回传 |
| 公共卫生专员 | 演示账号登录 | 跟进转诊进度，督促结果回传，标记闭环 |

### 2.2 功能模块

1. **工作台首页**：角色待办队列、转诊状态概览、逾期提醒
2. **转诊申请页**：创建/编辑转诊申请，提交审核
3. **结果回传页**：接收回传结果，感知申请变更，确认签收
4. **详情时间线页**：单条转诊全生命周期时间线，含状态变更、责任人、时间点、备注

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能说明 |
|----------|----------|----------|
| 工作台首页 | 角色待办队列 | 按角色显示待处理转诊列表，含状态标签、逾期标记 |
| 工作台首页 | 转诊状态概览 | 统计各状态转诊数量，饼图或数字卡片 |
| 工作台首页 | 逾期提醒 | 超过预期时限的转诊高亮提醒 |
| 转诊申请页 | 申请表单 | 患者信息、转诊原因、拟转科室、紧急程度、预期回传时限 |
| 转诊申请页 | 提交审核 | 提交后状态变为"待审核"，护士可操作 |

| 结果回传页 | 回传列表 | 按时间倒序展示回传结果，标记"申请已变更" |

| 详情时间线页 | 回传回看 | 展示所有结果回传记录及签收状态 |

## 3. 核心流程

全科医生创建转诊申请 → 护士审核通过 → 申请发送至上级医院 → 上级医院回传结果 → 系统感知申请是否被修改 → 若已修改则标记变更提示 → 护士/公卫专员确认签收 → 公卫专员标记闭环

转诊申请修改时的感知流程：全科医生修改已提交申请 → 系统生成变更快照 → 结果回传列表中对应条目标记"申请已变更" → 签收时需确认已阅读变更内容

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：石板灰(zinc)为中性基底 + 青蓝色(teal)为功能色 + 琥珀色(amber)为警示色
- 按钮风格：圆角微凸，功能色填充，次要按钮描边
- 字体：Noto Sans SC 为主字体，数值/标签用等宽字体
- 布局风格：左侧固定导航 + 右侧内容区，卡片式模块
- 图标风格：线性图标(lucide-react)，统一24px

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 工作台首页 | 角色待办队列 | 列表卡片，左侧状态色条，右侧操作按钮 |
| 工作台首页 | 状态概览 | 数字卡片组，含趋势箭头 |
| 工作台首页 | 逾期提醒 | 琥珀色背景横幅，含天数 |
| 转诊申请页 | 申请表单 | 分组表单，患者信息/转诊信息/时限设置 |
| 转诊申请页 | 提交审核 | 底部固定操作栏，主按钮+次按钮 |
| 结果回传页 | 回传列表 | 卡片列表，变更标记为琥珀色徽章 |
| 结果回传页 | 回传确认 | 弹窗确认，含变更对比面板 |
| 详情时间线页 | 状态时间线 | 左侧竖线时间线，右侧卡片，节点含头像/角色标签 |
| 详情时间线页 | 变更对比 | 左右分栏对比，差异高亮 |

### 4.3 响应式设计

桌面优先，内容区最小宽度1024px，导航可折叠。数据表格在窄屏下转为卡片列表。

不适用
