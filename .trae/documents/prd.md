## 1. 产品概述

港口堆场海关查验与移箱任务管理系统——面向闸口员、堆场调度、客户服务三类角色，实时暴露卡住的集装箱单据（错放箱、超期堆存争议、查验漏通知），并在海关查验完成后自动衔接移箱任务，杜绝靠人工消息串联的断链问题。

- 解决核心痛点：箱号清单、闸口记录和堆位图只记录结果不记录原因，问题单靠事后发现
- 目标：让卡住的箱子在第一时间被看见、被处理，正常单与问题单各有完整闭环

6. **问题单中心**: 卡住箱一览（错放/超期/漏通知）、改期/补录/驳回操作
7. **操作日志**: 全量操作审计、按箱号/角色/时间筛选

## 3. 核心流程

### 3.1 正常流程

集装箱进场 → 闸口登记 → 堆位分配 → 海关查验计划生成 → 通知客户 → 查验执行 → 查验完成(放行) → 自动生成移箱任务 → 移箱执行 → 集装箱出场

### 3.2 问题单流程

**错放箱**: 堆位扫描发现位置不匹配 → 标记为错放 → 调度重新分配堆位 → 生成移箱任务 → 移箱完成 → 状态恢复
**超期堆存**: 免堆期到期未提箱 → 自动标记超期 → 客服确认费用 → 客户缴费或争议 → 争议驳回/费用确认 → 提箱出场
**查验漏通知**: 查验计划已生成但未通知 → 自动检测漏通知 → 客服补发通知 → 客户确认 → 进入正常查验流程

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**: 深海蓝(#0C2340) + 港口橙(#E87722) 作为警示色 + 冰蓝(#4A90D9) 作为辅助色
- **按钮风格**: 圆角8px，主操作按钮用港口橙填充，危险/驳回操作用红色
- **字体**: 标题用 Noto Sans SC Bold，正文用 Noto Sans SC Regular
- **布局风格**: 左侧固定导航栏 + 右侧内容区，顶部状态条
- **图标风格**: Lucide 线性图标，统一 18px

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI要素 |
|----------|----------|--------|
| 登录页 | 角色选择 | 三张卡片居中排列，深蓝背景，港口橙边框选中态，图标+角色名+简述 |
| 工作台 | 预警面板 | 顶部红色/橙色/黄色预警条，数量角标，点击展开卡片列表 |
| 工作台 | 统计面板 | 四宫格数字卡片，大字号数字+小字号标签 |
| 集装箱管理 | 堆位图 | CSS Grid 俯视图，色块表示状态，hover 显示箱号 |
| 海关查验 | 查验表单 | 步骤条(开箱→掏箱→复箱→结果)，表单内联在步骤中 |
| 移箱任务 | 任务卡片 | 卡片列表，左色条标识状态，显示原位→目标位箭头 |
| 问题单中心 | 问题列表 | 表格+左侧色条(红/橙/黄)，操作按钮列 |
| 操作日志 | 日志表格 | 条纹表格，时间线左侧面板，右侧详情 |

### 4.3 响应式设计

- 桌面优先设计，1280px 以上完整展示
- 1024-1280px 隐藏侧边栏文字只留图标
- 768px 以下切换为底部导航 + 全屏内容
