## 1. 产品概述

铁路货运站货损登记与赔付材料管理系统——从责任人和时间线切入，解决货票、装车计划、到达通知只记录结果而不记录"为什么变成货损"的问题。确保货运员、装卸班长、客服看到的信息口径一致，货损登记到赔付材料之间不存在无人负责的空档。

- 目标用户：铁路货运站的货运员、装卸班长、客服人员、站段管理人员
- 核心价值：责任链可追溯、状态口径统一、赔付材料与货损登记无缝衔接

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 货运员 | 工号登录 | 登记货损、填写货损报告、指定责任人、提交赔付申请 |
| 装卸班长 | 工号登录 | 确认装卸环节责任、签收装卸异常、补充装卸记录 |
| 客服 | 工号登录 | 受理赔付申请、跟踪赔付进度、补充赔付材料 |
| 站段管理员 | 工号登录 | 审核赔付、查看统计、责任回溯分析 |

### 2.2 功能模块

1. **工作台首页**：待办事项、异常告警、已完成样例、责任空档提示
2. **货损登记**：登记列表、新建登记、登记详情（含时间线和责任链）
3. **赔付材料**：赔付列表、赔付详情、材料回看、责任衔接检查
4. **角色视图**：按角色切换视角，展示不同侧重点

## 3. 核心流程

货运员发现货损后登记→系统自动生成时间线节点→指定各环节责任人→确认责任链无空档→提交赔付申请→客服受理并补全赔付材料→站段管理员审核→赔付完成。全程状态口径一致，任何环节责任人不明确时系统标红告警。

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深铁灰 (#2D2D2D) 为主，安全橙 (#E8722A) 为强调色，辅以铁道蓝 (#3B6FA0)
- 按钮：圆角微凸，安全橙色用于主要操作，灰色用于次要操作
- 字体：思源黑体 / Noto Sans SC，标题 18px 加粗，正文 14px 常规，注释 12px
- 布局：左侧导航 + 主内容区，详情页右侧侧栏
- 图标风格：线性图标（Lucide），与铁路行业简洁风格匹配
- 状态标签：用色块标签区分——待处理（橙）、处理中（蓝）、异常（红）、已完成（绿）

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 工作台首页 | 待办区 | 卡片列表，左色条标识紧急度，hover 阴影浮起 |
| 工作台首页 | 异常告警区 | 红色边框卡片，脉冲动画提示异常 |
| 工作台首页 | 已完成区 | 淡绿色标签，灰色正文 |
| 工作台首页 | 责任空档提示 | 红色虚线连接的时间线缺口 |
| 货损登记列表 | 筛选栏 | 顶部横向筛选标签组 |
| 货损登记列表 | 登记卡片 | 左侧色条 + 摘要信息 + 状态标签 + 点击展开 |
| 货损登记详情 | 侧栏 | 固定右侧 320px，货票/货物/承运信息 |
| 货损登记详情 | 时间线 | 左侧竖向时间线，节点圆点 + 连线，空档节点红色空心 |
| 货损登记详情 | 责任链 | 横向链路图，人名 + 角色，缺失环节标红虚线 |
| 赔付材料详情 | 材料回看 | 纵向卡片链路，可点击展开原始材料 |
| 角色视图 | 视图切换 | 顶部标签切换，切换后列表/卡片按角色重新排序和筛选 |

### 4.3 响应式

桌面优先，1280px 以上完整展示侧栏详情；1024-1280px 侧栏折叠为抽屉；768px 以下仅主内容区，侧栏改为全屏覆盖。
