## 1. 产品概述

攀岩馆运营交班系统——将课程预约、装备发放与异常记录统一到一条可追溯的链路上，让一线处理与管理回看基于同一份数据，交班时不再靠口头传达。

- **核心问题**：当前信息散落在会员预约表、保护员排班和线路维护记录中，追问时拼不成一条线
- **目标用户**：攀岩馆前台值班员、保护员、运营主管

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 值班员 | 直接访问 | 创建/处理预约、发放/回收装备、记录异常、查看交班 |
| 保护员 | 直接访问 | 查看自己的排班与预约、标记课程状态 |
| 运营主管 | 直接访问 | 全量数据回看、异常审计、交班历史查询 |

### 2.2 功能模块

1. **仪表盘**：当班待办、未关闭异常、近期已完成列表
2. **课程预约**：预约创建、状态流转（待确认→已确认→进行中→已完成/已取消）、关联保护员
3. **装备发放**：发放登记、归还登记、装备状态追溯、历史回看
4. **异常记录**：异常上报、处理跟踪、关联预约/装备记录
5. **交班面板**：当班未关闭事项汇总、一键生成交班快照、历史交班记录回看

| 页面 | 模块 | 功能说明 |
|------|------|----------|
| 仪表盘 | 待办卡片 | 显示当班未完成预约、待回收装备、未关闭异常 |

| 课程预约 | 新建预约 | 填写会员信息、选择课程与时间段、指定保护员，支持幂等提交 |

| 交班面板 | 历史记录 | 按日期回看历史交班快照 |

## 3. 核心流程

**课程预约→装备发放→归还→交班** 主线流程：

1. 值班员创建课程预约（幂等提交，携带 idempotency_key）
2. 保护员确认预约，课程开始
3. 值班员发放装备，关联预约记录（幂等提交）
4. 课程结束，保护员标记预约完成
5. 值班员登记装备归还，记录回场状态
6. 异常可在任意环节上报，关联具体预约或装备记录
7. 交班时，系统汇总当前未关闭事项，生成交班快照

## 4. 用户界面设计

### 4.1 设计风格

- **主色**：岩石灰 `#4A5568` + 攀岩橙 `#ED8936` 作为强调色
- **次色**：安全绿 `#48BB78`（完成状态）、警告红 `#F56565`（异常状态）
- **字体**：标题使用 Source Han Sans / Noto Sans SC，正文使用系统字体
- **布局**：侧边栏导航 + 主内容区卡片式布局，桌面优先
- **按钮风格**：圆角6px，带微弱阴影，状态切换按钮有颜色区分
- **图标**：lucide-react 图标库

### 4.2 页面设计概览

| 页面 | 模块 | UI要素 |
|------|------|--------|
| 仪表盘 | 待办卡片 | 三列卡片布局，各显示待处理预约/待回收装备/未关闭异常数量，点击展开列表 |
| 仪表盘 | 异常提醒 | 列表式，每行显示严重程度色标、异常描述、关联单号、操作人 |
| 仪表盘 | 已完成列表 | 时间线式，按时间倒序排列，显示完成时间与摘要 |
| 课程预约 | 预约列表 | 表格+筛选器，状态列使用彩色标签 |
| 课程预约 | 新建/编辑 | 模态框表单，保护员下拉选择，时间段选择器 |
| 装备发放 | 发放/归还 | 表格视图+侧滑详情面板，回看使用日期范围筛选 |
| 异常记录 | 异常列表 | 卡片+筛选，严重程度使用色标 |
| 交班面板 | 当前班次 | 三栏汇总（预约/装备/异常）+ 生成交班按钮 |

### 4.3 响应式设计

桌面优先设计，侧边栏在移动端折叠为底部导航栏。表格在小屏幕下横向滚动。卡片布局在窄屏下从三列变为单列。

### 4.4 种子数据要求

首页不得为空白，需预置：
- 5条课程预约（含不同状态：待确认、已确认、进行中、已完成、已取消）
- 3条装备发放记录（2条已归还、1条未归还）
- 3条异常记录（1条已关闭、2条未关闭）
- 4条交班待办（2条待处理、2条已完成）
