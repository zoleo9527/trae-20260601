## 1. 产品概述

咖啡烘焙厂烘焙曲线与杯测评分管理系统——解决曲线版本混乱、客诉风味不一致、库存先进先出失控三大痛点。烘焙师、杯测员、渠道客服各自拥有独立工作台，通过操作日志和关联关系实现可追溯协同。

- 目标用户：烘焙厂内烘焙师、杯测员、渠道客服
- 核心价值：每条曲线有版本链，每杯杯测有据可查，每次操作可回溯

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 烘焙师 | 默认进入烘焙曲线工作台 | 创建/编辑烘焙曲线、标记曲线版本、管理烘焙批次 |
| 杯测员 | 默认进入杯测评分工作台 | 录入杯测评分、标记风味异常、关联烘焙批次 |
| 渠道客服 | 默认进入客诉与库存看板 | 录入客诉、查看关联曲线与杯测、查看库存状态 |

### 2.2 功能模块

1. **仪表盘**：待处理项、风险提醒、最近变更、快捷入口
2. **烘焙曲线工作台**：曲线列表、版本管理、批量操作、曲线详情(含历史版本回看)
3. **杯测评分工作台**：评分列表、评分录入、风味异常标记、评分详情(含关联批次与曲线)
4. **客诉与库存看板**：客诉列表、库存先进先出状态、客诉关联追溯
5. **操作日志**：全局操作日志、按模块筛选、按时间回溯

## 3. 核心流程

### 3.1 烘焙曲线版本管理流程

烘焙师创建新曲线或基于历史版本创建新版本 → 系统自动记录版本号与变更内容 → 标记为"草稿"状态 → 烘焙师确认后标记为"正式"版本 → 旧版本自动归档但可回看 → 操作日志记录版本变更

### 3.2 杯测评分录入与追溯流程

杯测员从工作台进入评分录入 → 选择关联的曲线与批次(在同一页面内) → 录入各项评分 → 如发现风味异常则标记并描述 → 评分自动关联曲线版本 → 客诉录入时可追溯到具体评分与曲线

### 3.3 客诉关联追溯流程

客服录入客诉 → 系统自动展示关联的曲线版本和杯测评分(无需跳转) → 标记客诉处理状态 → 风险提醒同步更新

```mermaid
    "发现风味异常→标记风险" --> "仪表盘风险提醒更新"
    "关联烘焙批次" --> "客服录入客诉"
    "客服录入客诉" --> "系统展示关联曲线与杯测"
    "系统展示关联曲线与杯测" --> "操作日志全程记录"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主题色调**：深棕(#3C2415)为主色，搭配暖橙(#D4843E)强调色，奶白(#FAF6F1)背景，深灰文字(#2D2D2D)
- **按钮风格**：圆角(8px)实心按钮，主操作用暖橙，次要操作用浅棕描边
- **字体**：标题用 Playfair Display，正文用 Noto Sans SC
- **布局**：左侧固定导航栏 + 右侧内容区，卡片式布局，表格紧凑
- **图标风格**：使用 lucide-react 线性图标
- **状态色**：风险/异常用红色(#DC2626)，待处理用琥珀(#F59E0B)，已完成用绿(#16A34A)

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 仪表盘 | 待处理卡片 | 三列卡片(曲线/杯测/客诉)，数字加粗，点击跳转链接 |
| 仪表盘 | 风险提醒 | 红色左边框卡片列表，按严重程度排序 |
| 仪表盘 | 最近变更 | 时间线样式，显示操作人、时间、变更内容 |
| 烘焙曲线工作台 | 曲线列表 | 表格+筛选栏，版本号标签，状态徽章 |
| 烘焙曲线工作台 | 曲线详情 | 左侧参数面板+右侧版本历史时间线，底部关联杯测列表 |
| 杯测评分工作台 | 评分列表 | 表格+筛选栏，异常行红色高亮 |
| 杯测评分工作台 | 评分录入 | 侧滑抽屉表单，曲线选择器内嵌，评分滑块 |
| 杯测评分工作台 | 评分详情 | 卡片式评分展示，内嵌关联曲线参数和批次信息 |
| 客诉与库存看板 | 客诉列表 | 表格+状态筛选，关联信息折叠展示 |
| 客诉与库存看板 | 库存状态 | 表格+过期高亮，FIFO进度条 |
| 操作日志 | 日志列表 | 表格+时间+模块筛选，操作内容摘要 |

### 4.3 响应式

桌面优先设计，最小宽度 1024px。移动端暂不做适配。

### 4.4 数据重置

页面底部提供"重置样例数据"按钮，调用接口重置数据库到初始样例状态。
