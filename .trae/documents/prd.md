## 1. 产品概述

种猪场仔猪转栏与淘汰评估工具——解决转栏与淘汰评估之间责任归属模糊、时效失控的日常作业工具。繁育员、兽医、场长各有独立处理入口，每条仔猪记录从转栏申请到淘汰评估完成全程有状态追踪和时间线留痕，杜绝"谁说了算"的扯皮。

- 目标用户：种猪场繁育员、兽医、场长
- 核心价值：用清晰状态流转和操作日志替代模糊的台账/口头沟通，让转栏与淘汰的每一步都有人负责、有时限、可回溯

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 繁育员 | 选择角色进入 | 发起转栏申请、填写转栏信息、查看本人发起的记录 |
| 兽医 | 选择角色进入 | 对待评估仔猪发起淘汰评估、填写评估结论、标记淘汰/留养 |
| 场长 | 选择角色进入 | 审批淘汰评估、查看全场数据概览、操作日志回溯 |

### 2.2 功能模块

1. **工作台首页**：角色差异化入口、待办统计、最近操作
2. **转栏管理**：转栏申请列表、新建转栏、转栏详情与时间线
3. **淘汰评估**：待评估列表、评估表单、评估详情与历史备注
4. **操作日志**：全量操作记录、按时间/角色/类型筛选

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|

## 3. 核心流程

**仔猪转栏与淘汰评估状态流转**：

1. 繁育员发起转栏申请 → 状态：待转栏
2. 繁育员确认转栏完成 → 状态：已转栏
3. 繁育员/场长将已转栏记录提交进入评估 → 状态：待评估
4. 兽医完成淘汰评估 → 状态：待审批（淘汰）/ 已留养
5. 场长审批通过 → 状态：已淘汰 / 已留养；场长驳回 → 回到待评估

```mermaid

    "待转栏" -->|"繁育员确认转栏"| "已转栏"
    "已转栏" -->|"提交进入评估"| "待评估"
    "待评估" -->|"兽医评估-建议淘汰"| "待审批"
    "待评估" -->|"兽医评估-建议留养"| "已留养"
    "待审批" -->|"场长审批通过"| "已淘汰"
    "待审批" -->|"场长驳回"| "待评估"
```

**责任与时效规则**：
- 待转栏超过24小时未确认 → 自动标红提醒场长
- 待评估超过48小时未处理 → 自动标红提醒场长
- 待审批超过24小时未审批 → 自动标红提醒场长
- 每次状态变更自动写入操作日志，不可删除

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深灰(#1a1a2e) + 翡翠绿(#16a34a)作为行动色，搭配琥珀色(#d97706)作为警告色
- **辅助色**：石板灰(#475569)用于次要文字，浅灰(#f1f5f9)用于背景
- **按钮风格**：圆角(8px)、实心填充、hover微上移+阴影
- **字体**：思源黑体 / Noto Sans SC，标题16-20px，正文14px，辅助文字12px
- **布局**：左侧固定导航栏 + 右侧内容区，卡片式布局
- **图标**：Lucide图标库，线条风格

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 工作台 | 角色入口卡片区 | 3张角色卡片横向排列，当前角色高亮，每张卡片含待办数badge |
| 工作台 | 待办统计 | 紧凑数据卡，数字加粗+翡翠绿，标签灰色 |
| 工作台 | 最近操作 | 简洁列表，左侧彩色竖线标识操作类型 |
| 转栏列表 | 筛选栏 | 顶部横向筛选chips + 搜索框 |
| 转栏列表 | 记录卡片 | 紧凑卡片，左上角状态标签(颜色区分)，右侧操作按钮 |
| 新建转栏 | 表单 | 分组表单，每组有标题分隔，输入框带图标前缀 |
| 转栏详情 | 时间线 | 纵向时间线，节点用圆形图标，连接线灰色，时间+操作人+描述 |
| 评估列表 | 筛选+列表 | 同转栏列表风格，状态标签颜色不同 |
| 评估详情 | 评估表单 | 分步骤表单：健康评分→淘汰建议→备注 |
| 评估详情 | 历史备注 | 卡片堆叠，按时间倒序，每条含角色标签+时间 |
| 操作日志 | 日志列表 | 表格式，行hover高亮，操作类型用chips标识 |

### 4.3 响应式

- 桌面优先设计，1280px+为主要视口
- 导航栏在1024px以下收起为汉堡菜单
- 卡片网格在窄屏下由多列切换为单列
