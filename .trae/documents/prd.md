## 1. 产品概述

社区卫生站慢病随访与指标预警系统——解决慢病随访与指标预警之间责任不清、时效脱节的痛点，让随访处理、预警回看、异常提醒和批量动作形成闭环，消除无人负责的空档。

- 目标用户：全科医生、护士、公共卫生专员三类角色，信息视图不同但状态口径一致
- 核心价值：减少翻群记录，让异常样例能直接触发提醒或退回，确保流程接住每一个异常

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 全科医生 | 选择角色登录 | 随访处置、预警确认、异常裁定、批量审核 |
| 护士 | 选择角色登录 | 随访执行、指标录入、异常上报、批量标记 |
| 公共卫生专员 | 选择角色登录 | 预警监控、趋势分析、异常分发、批量派单 |

### 2.2 功能模块

1. **慢病随访工作台**：待办随访列表、随访详情处理、状态流转、责任指派
2. **指标预警中心**：预警列表与回看、异常提醒触发、批量动作面板、预警→随访闭环

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 慢病随访工作台 | 角色切换栏 | 顶部角色切换，切换后列表和操作按钮随之变化，状态口径不变 |
| 慢病随访工作台 | 待办随访列表 | 按状态分组展示待随访/随访中/已完成/已预警卡片，卡片显示患者姓名、病种、指标摘要、责任人和时效倒计时 |
| 慢病随访工作台 | 随访详情面板 | 右侧滑出面板，显示指标趋势、历史随访摘要、当前状态操作（录入指标/提交审核/预警转出/退回） |
| 慢病随访工作台 | 状态流转引擎 | 每次状态变更自动记录操作人、时间、角色，确保随访→预警之间无空档 |
| 指标预警中心 | 预警列表 | 按预警级别（红/橙/黄）分组，显示患者、异常指标、触发规则、当前负责人 |
| 指标预警中心 | 预警回看 | 点击预警卡片展开时间线，展示从随访录入→指标异常→预警触发的完整链路 |
| 指标预警中心 | 异常提醒触发 | 异常样例可直接触发提醒（通知负责人）或退回（退回给上一环节重新处理），按钮即操作 |
| 指标预警中心 | 批量动作面板 | 勾选多条预警后可批量派单、批量确认、批量退回，操作结果即时反馈 |

## 3. 核心流程

用户选择角色后进入对应视图。随访录入指标后系统自动检测异常，异常指标触发预警并自动指派责任人。责任人可选择处理（确认/转随访）或退回上一环节。全程状态一致，无人空档时系统自动升级提醒。

```mermaid
flowchart TD
    "角色选择" --> "慢病随访工作台"
    "慢病随访工作台" --> "待办随访列表"
    "待办随访列表" --> "随访详情处理"
    "随访详情处理" --> "录入指标"
    "录入指标" --> "系统自动检测异常"
    "系统自动检测异常" -->|"无异常"| "随访完成"
    "系统自动检测异常" -->|"检测到异常"| "自动触发预警"
    "自动触发预警" --> "指标预警中心"
    "指标预警中心" --> "预警回看链路"
    "指标预警中心" --> "异常提醒/退回"
    "异常提醒/退回" -->|"触发提醒"| "通知负责人处理"
    "异常提醒/退回" -->|"退回"| "随访详情处理"
    "通知负责人处理" --> "确认/转随访"
    "确认/转随访" --> "闭环完成"
    "指标预警中心" --> "批量动作"
    "批量动作" --> "批量派单/确认/退回"
```

状态流转规则：
- **待随访** → 护士开始执行 → **随访中**
- **随访中** → 录入指标完成 → **待审核**
- **待审核** → 全科医生审核通过 → **已完成**（无异常）或 **已预警**（有异常）
- **已预警** → 公共卫生专员确认 → **处理中**
- **处理中** → 处理完成 → **闭环完成**
- 任意环节 → 退回 → 回到上一状态，责任人自动变更

## 4. 用户界面设计

### 4.1 设计风格

- 主色：深蓝灰（#1E293B）+ 医疗绿（#10B981）+ 预警红（#EF4444）/ 橙（#F59E0B）/ 黄（#EAB308）
- 按钮风格：圆角矩形，状态色填充，hover 微抬升
- 字体：思源黑体 / Noto Sans SC，正文 14px，标题 18-20px
- 布局风格：左侧导航 + 主内容区 + 右侧详情面板（三栏布局）
- 图标风格：线性图标（lucide-react），与文字搭配使用

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 慢病随访工作台 | 角色切换栏 | 顶部横向标签切换，当前角色高亮，角色图标+名称 |
| 慢病随访工作台 | 待办随访列表 | 卡片列表，左侧状态色条，卡片内姓名/病种/指标摘要/时效倒计时/责任人标签 |
| 慢病随访工作台 | 随访详情面板 | 右侧滑出面板，顶部患者信息，中部指标趋势迷你图，底部操作按钮组 |
| 指标预警中心 | 预警列表 | 红橙黄三级分组折叠面板，预警卡片带级别色标，显示异常指标值和触发规则 |
| 指标预警中心 | 预警回看 | 卡片展开后显示垂直时间线，节点标注操作人/角色/时间 |

### 4.3 响应式设计

- 桌面优先设计，主内容区最小宽度 1024px
- 详情面板在窄屏下全屏覆盖
- 批量动作栏始终固定底部

## 5. 异常样例与闭环验证

系统内置以下异常样例，可直接触发提醒或退回：

1. **血糖持续偏高**：连续3次空腹血糖 ≥ 7.0 mmol/L → 触发红色预警 → 可提醒全科医生或退回护士重新录入
2. **血压波动异常**：收缩压 ≥ 180 mmHg 或舒张压 ≥ 110 mmHg → 触发橙色预警 → 可派单公共卫生专员
3. **随访超时未处理**：随访单超过48小时未进入下一状态 → 自动触发黄色提醒 → 可批量派单
4. **指标录入缺失**：随访中应录指标未录入即提交 → 退回给护士

每个异常样例的操作结果即时反映在状态链路上，确保流程接住异常。
