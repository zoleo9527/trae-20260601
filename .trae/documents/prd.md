## 1. 产品概述

精酿酒厂经销订单与发货跟踪系统，解决酿酒师、包装主管、销售内勤三方在经销订单与发货环节中责任不清、时效不明的问题。通过角色驱动的状态流转和全程操作留痕，确保每一笔订单"谁提交、谁确认、何时交接"都有据可查；异常样例可一键退回或触发提醒，杜绝流程断裂。

- 目标用户：精酿酒厂内部团队（酿酒师、包装主管、销售内勤）
- 核心价值：用明确的状态机替代口头交接，用操作日志替代事后追责

## 3. 核心流程

### 3.1 经销订单状态机

销售内勤创建订单 → 酿酒师确认生产 → 酿酒师完成生产 → 包装主管确认包装 → 包装主管确认发货 → 销售内勤确认签收 → 订单关闭

每个正向流转节点均可"退回"，退回必须填写原因，状态回退至上一节点并触发提醒。超时未操作自动标记异常。

### 3.2 状态流转图

```mermaid

    "草稿" -->|"销售内勤提交"| "待确认"
    "待确认" -->|"酿酒师确认"| "生产中"
    "待确认" -->|"酿酒师退回"| "已退回"
    "生产中" -->|"酿酒师完成"| "待发货"
    "生产中" -->|"酿酒师退回"| "已退回"
    "待发货" -->|"包装主管确认发货"| "已发货"
    "待发货" -->|"包装主管退回"| "已退回"
    "已发货" -->|"销售内勤确认签收"| "已完成"
    "已发货" -->|"销售内勤标记异常"| "异常"
    "已退回" -->|"销售内勤修改后重新提交"| "待确认"
    "异常" -->|"管理员处理"| "待确认"
```

### 3.3 退回与异常规则

- 任何节点退回必须选择退回原因（库存不足/生产问题/包装问题/物流问题/其他）并填写补充说明
- 退回后订单回到"已退回"状态，原操作人收到提醒
- 订单在任一节点停留超过 48 小时未操作，系统自动标记为异常并在工作台首页显示
- 异常订单需管理员介入处理后方可继续流转

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：琥珀色（#D97706）呼应精酿啤酒色系，搭配深炭色背景（#1C1917）
- **辅助色**：暖白（#FAFAF9）用于卡片背景，砖红（#DC2626）用于异常/退回状态
- **字体**：标题使用 Noto Serif SC（衬线体呼应传统酿造），正文使用 Noto Sans SC
- **按钮风格**：圆角 8px，正向操作为琥珀色实心，退回/异常为砖红描边
- **布局**：左侧固定导航栏 + 右侧内容区，卡片式布局
- **状态标签**：圆角胶囊标签，不同状态用不同颜色区分

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 要素 |
|----------|----------|---------|
| 工作台首页 | 待办看板 | 3 张统计卡片（待确认/待发货/异常），琥珀色数字高亮 |
| 工作台首页 | 异常横幅 | 顶部红色横幅，显示异常订单数，点击展开列表 |
| 工作台首页 | 近期订单 | 紧凑表格，状态胶囊标签，行悬停高亮 |
| 经销订单页 | 订单列表 | 表格 + 顶部筛选栏，状态列彩色标签 |
| 经销订单页 | 新建订单 | 侧滑抽屉面板，表单分步骤填写 |
| 经销订单页 | 订单详情 | 左侧状态时间线 + 右侧产品明细卡片 |
| 经销订单页 | 退回操作 | 居中弹窗，下拉选原因 + 文本域说明 |
| 发货跟踪页 | 发货列表 | 表格，发货信息列可内联编辑 |
| 发货跟踪页 | 发货确认 | 弹窗填写物流公司+单号+发货日期 |
| 操作日志页 | 日志列表 | 紧凑表格，操作类型彩色标签 |

### 4.3 响应式

桌面优先设计，最小支持 1280px 宽度；移动端适配表格横向滚动和导航折叠。
