## 1. 产品概述

快递网点退回处理与责任复盘系统——面向网点客服、派件员、驿站负责人三角色接力的退件全流程闭环工具。将退回登记→退回处理→责任复盘串联为一个连续工作面，驳回与补录作为真实操作写入数据，而非仅停留在提示文案中。

- 解决退回件流转断档、责任模糊、复盘与处理割裂的问题
- 目标用户：快递网点运营团队（客服、派件员、驿站负责人）

## 2. 核心功能

### 2.1 用户角色

| 角色 | 登录方式 | 核心权限 |
|------|----------|----------|
| 网点客服 | 账号密码登录 | 登记退回件、发起退回处理、驳回补录、查看复盘 |
| 派件员 | 账号密码登录 | 接收退回任务、提交退回说明、补充证据、确认退回 |
| 驿站负责人 | 账号密码登录 | 责任认定、驳回/通过、发起复盘、复盘回看 |

### 2.2 功能模块

1. **退回工作台**：退回件列表、状态筛选、分页浏览、快速登记退回件
2. **退回处理流**：客服登记→派件员确认→驿站负责人认定，三角色接力处理
3. **责任复盘面板**：内嵌于退回详情中，随单流转的复盘记录，支持回看

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 登录页 | 角色登录 | 选择角色（客服/派件员/驿站负责人）登录，模拟权限切换 |
| 退回工作台 | 退回件列表 | 分页表格展示退回件，支持按状态/时间/角色筛选 |
| 退回工作台 | 快速登记 | 客服填写运单号、退回原因、备注，创建退回件 |
| 退回处理流 | 客服处理 | 客服确认退回原因，可驳回要求派件员补充说明 |
| 退回处理流 | 派件员处理 | 派件员查看任务，填写退回说明/上传签收图，确认退回 |
| 退回处理流 | 驿站负责人认定 | 查看全流程记录，认定责任方，通过或驳回 |
| 责任复盘面板 | 复盘记录 | 内嵌于退回详情中，显示状态变更时间线、责任人、备注 |
| 责任复盘面板 | 复盘回看 | 驿站负责人发起复盘，追加复盘结论和改进措施 |

## 3. 核心流程

退回件从客服登记开始，按角色接力流转，驳回时回退到上一节点，补录后继续推进。退回处理完成后自动进入责任复盘阶段，复盘不是独立菜单，而是退回详情的延续。

```mermaid

    "状态: 待派件员确认" --> "派件员确认退回"
    "派件员确认退回" --> "派件员补充说明"
    "派件员补充说明" --> "状态: 待驿站认定"
    "状态: 待驿站认定" --> "驿站负责人认定"
    "驿站负责人认定" --> "通过: 退回处理完成"
    "驿站负责人认定" --> "驳回: 退回上一节点"
    "驳回: 退回上一节点" --> "派件员补充说明"
    "驳回: 退回上一节点" --> "客服补录"
    "客服补录" --> "状态: 待派件员确认"
    "通过: 退回处理完成" --> "责任复盘阶段"
    "责任复盘阶段" --> "驿站负责人发起复盘"
    "驿站负责人发起复盘" --> "追加复盘结论"
    "追加复盘结论" --> "复盘完成"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深石板蓝 (#1e293b) + 亮橙 (#f97316) 作为强调色，传达物流行业的沉稳与效率感
- 次色调：浅灰背景 (#f8fafc)，卡片白 (#ffffff)，边框灰 (#e2e8f0)
- 按钮风格：圆角(8px)，主操作实色填充，次操作描边
- 字体：系统字体栈 -apple-system/Segoe UI，标题加粗 600，正文 400
- 布局：左侧导航栏 + 右侧内容区，卡片式内容组织
- 图标：lucide-react 线性图标

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 登录页 | 角色登录 | 居中卡片，角色选择按钮组，简约表单 |
| 退回工作台 | 退回件列表 | 顶部筛选栏+分页表格，状态标签用颜色区分，行点击展开详情 |
| 退回工作台 | 快速登记 | 右侧抽屉式面板，表单输入+提交按钮 |
| 退回处理流 | 三角色接力 | 垂直时间线布局，每个节点显示角色、操作、时间、备注 |
| 责任复盘面板 | 复盘记录 | 退回详情底部折叠面板，时间线+备注追加区域 |

### 4.3 响应式

桌面优先设计，侧边栏在窄屏收起为汉堡菜单，表格在移动端改为卡片列表。
