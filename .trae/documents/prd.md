# 保险理赔中心-客户申诉与复核系统 PRD

## 1. 产品概述

保险理赔中心客户申诉与复核系统旨在解决现有流程中信息分散、交互轮次多、责任界定不清的问题。系统通过整合旧台账、现场记录、沟通截图、客户申诉和复核结论于单一记录视图,为接待人员、专业人员、审核主管提供分角色的待办工作台,实现异常提醒、本地流转、申诉处理和复核回看的完整闭环。

核心价值:
- 减少忙碌时30%以上的交互轮次,通过智能信息聚合和预填减少重复录入
- 消除信息遗漏,客户申诉、复核结论、退回原因、补充备注强制在同一条记录中维护
- 提升责任界定清晰度,每个环节的操作人、时间、原因全程可追溯

## 2. 核心功能

### 2.1 用户角色

| 角色 | 职责 | 核心权限 |
|------|------|---------|
| 接待人员 | 接收客户申诉、录入初始信息、分配专业人员 | 录入申诉、查看分配给自己的待办、提交补充材料 |
| 专业人员 | 现场核查、专业判断、提交初步结论 | 查看分配给自己的待办、录入现场记录、提交专业意见 |
| 审核主管 | 复核结论、最终决策、退回重审 | 查看待复核记录、批准/退回、添加复核意见 |

### 2.2 功能模块

1. **工作台页面**: 分角色待办列表、快捷操作入口、异常提醒通知
2. **申诉详情页**: 单一记录视图、信息聚合展示、流程流转操作
3. **流程回看页**: 历史记录查询、时间轴展示、责任追溯

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|

## 3. 核心流程

### 3.1 顺利流(正常处理流程)

客户提交申诉 → 接待人员录入信息并分配专业人员 → 专业人员现场核查并提交初步结论 → 审核主管复核通过 → 归档完成

**关键特征:**
- 每个环节信息完整,无需补充
- 流程顺畅无退回
- 处理时间在规定时限内

### 3.2 问题流(退回重审流程)

客户提交申诉 → 接待人员录入信息并分配专业人员 → 专业人员现场核查并提交初步结论 → 审核主管退回(原因:证据不足) → 专业人员补充材料 → 审核主管复核通过 → 归档完成

**关键特征:**
- 至少一次退回操作
- 需要补充材料或重新核查
- 退回原因和补充备注强制填写
- 异常提醒触发

### 3.3 最终归档流程

审核主管作出最终结论 → 系统自动生成归档记录 → 客户申诉、复核结论、退回原因、补充备注整合归档 → 流程回看页面可查询

**关键特征:**
- 所有信息完整归档
- 责任链路清晰可追溯
- 支持后续审计和回看

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**: 深蓝色(#1E3A8A)代表专业可信,橙色(#F97316)作为行动色强调待办和异常
- **辅助色**: 绿色(#10B981)表示通过/完成,红色(#EF4444)表示退回/异常,灰色(#6B7280)表示待处理
- **按钮风格**: 圆角矩形按钮,主操作按钮填充色,次操作按钮描边样式
- **字体**: 标题使用思源黑体(Source Han Sans CN)Bold,正文使用Regular,字号16px基准
- **布局风格**: 左侧固定导航栏,右侧内容区,卡片式布局,顶部状态栏
- **图标风格**: 线性图标,2px线宽,与文字对齐

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|---------|---------|--------|
| 工作台页面 | 待办列表卡片 | 白色背景卡片,左侧状态色条,右侧操作按钮,hover时轻微阴影提升 |
| 工作台页面 | 异常提醒横幅 | 红色渐变背景,白色文字,闪烁动画吸引注意 |
| 工作台页面 | 快捷操作按钮组 | 水平排列,图标+文字,点击时缩放反馈 |
| 申诉详情页 | 信息聚合区 | 四象限布局,每个象限一个信息类型,中间流程状态指示器 |
| 申诉详情页 | 流程操作区 | 底部固定操作栏,主操作按钮右侧,退回按钮左侧,备注输入框居中 |
| 申诉详情页 | 历史记录时间轴 | 左侧时间轴连线,右侧操作卡片,不同操作类型用不同颜色标记 |
| 流程回看页 | 查询筛选栏 | 顶部固定,输入框+下拉选择,查询按钮右侧对齐 |
| 流程回看页 | 详情弹窗 | 模态窗口,半透明遮罩,内容区滚动,底部操作按钮 |

### 4.3 响应式设计

- **桌面优先**: 主要在办公电脑上使用,最小宽度1280px
- **平板适配**: 768px-1279px时导航栏收起为汉堡菜单,卡片布局改为单列
- **移动端优化**: <768px时隐藏次要信息,突出核心操作,增大点击区域

### 4.4 交互动画

- **页面加载**: 卡片依次淡入上移,stagger延迟100ms
- **状态变更**: 颜色过渡300ms,卡片轻微缩放反馈
- **异常提醒**: 红色横幅脉冲动画,每2秒闪烁一次
- **时间轴**: 滚动时连线逐渐绘制,使用stroke-dashoffset动画

## 6. 非功能性需求

- **性能**: 页面加载时间<2秒,操作响应时间<500ms
- **可用性**: 界面简洁直观,新员工培训后即可上手,减少50%的操作错误
- **数据完整性**: 所有操作记录不可删除,只能归档,保证审计追溯
- **异常处理**: 网络中断时本地缓存数据,恢复后自动同步
