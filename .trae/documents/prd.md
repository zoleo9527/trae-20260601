## 1. 产品概述

养老护理院服药提醒与异常上报系统——解决服药提醒流向异常上报时的**责任断层**与**时效丢失**问题。

- 当前痛点：护工标记"异常"后仅弹出提示文案"请及时上报"，驳回和补录也只存在于 toast 里，无法追溯、无法操作，导致责任不清、时效延误
- 目标：服药提醒完成（或异常）后，异常上报**自然衔接、不可跳过**；驳回和补录均为**实质操作**而非文案提示；护理主管、责任护工、社工三角色入口分离、权限隔离

## 2. 核心功能

### 2.1 用户角色

| 角色 | 入口特征 | 核心权限 |
|------|----------|----------|
| 护理主管 | 概览视图 + 审批台 | 查看全院服药/异常数据，审批或驳回异常上报，超时未处理自动触发提醒 |
| 责任护工 | 任务驱动视图 | 接收并处理服药提醒（确认服药/标记异常），提交异常上报，对驳回记录补录重提 |
| 社工 | 沟通视图 | 查看与家属相关的异常记录，标记家属通知状态，不可操作临床流程 |

### 2.2 功能模块

1. **服药提醒工作台**：按时间线展示待处理提醒，支持确认服药 / 标记异常
2. **异常上报中心**：服药异常自动生成上报单，支持手动补填详情、提交、驳回、补录重提
3. **审批与驳回**：护理主管审批上报，驳回时必须填写驳回原因，驳回记录可直接补录重提
4. **状态回看与追踪**：全生命周期状态标签（待处理→已确认/异常上报→审批中→已通过/已驳回→已补录），支持点击查看详情

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 登录角色选择页 | 角色切换 | 三角色入口卡片，点击进入对应工作台 |
| 护理主管-概览台 | 统计面板 | 今日服药完成率、异常上报数、待审批数、超时未处理数 |
| 护理主管-审批台 | 异常审批列表 | 上报单列表，支持通过/驳回（驳回必填原因），驳回记录显示补录入口 |
| 责任护工-提醒台 | 服药时间线 | 按时段展示提醒，点击确认服药或标记异常，标记异常后**自动跳转异常上报表单** |
| 责任护工-上报台 | 异常上报列表 | 已提交/已驳回/已补录的上报单，驳回记录可点击补录并重提 |
| 社工-沟通台 | 家属通知记录 | 与家属相关的异常记录，可标记"已通知家属"/"家属已确认" |

## 3. 核心流程

### 3.1 服药提醒 → 异常上报（核心交接断点）

当护工处理服药提醒时，选择"标记异常"后，系统**自动创建异常上报草稿**并跳转至上报表单页，上报单与原始提醒**强关联**（提醒ID → 上报ID），不可跳过、不可仅靠文案提示逃避上报责任。若选择"确认服药"，则提醒正常关闭。

### 3.2 异常上报 → 驳回 → 补录重提

护理主管驳回上报时，必须填写驳回原因。驳回后上报单状态变为"已驳回"，责任护工在"上报台"可见驳回原因，点击进入补录模式，补充信息后重新提交。补录操作**写入操作日志**，形成完整责任链。

### 3.3 超时未处理自动升级

服药提醒到期未处理，系统自动标记为"超时异常"并生成异常上报草稿，推送至护理主管审批台，同时通知责任护工。

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深青色 (#0F766E) 象征专业与安心，辅助色琥珀色 (#D97706) 用于异常/紧急状态
- **按钮风格**：圆角 (rounded-lg)，通过用实心青色，驳回用描边琥珀色，补录用虚线边框
- **字体**：思源黑体 / Noto Sans SC，标题 18px 加粗，正文 14px 常规，辅助 12px
- **布局**：左侧固定导航栏 + 右侧内容区，卡片式内容块，状态标签带色彩区分
- **图标**：Lucide 图标库，线性风格

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 角色选择页 | 角色卡片 | 三张等宽卡片，各含角色图标、名称、简述，hover 放大阴影 |
| 护理主管-概览台 | 统计卡片 | 四宫格数据卡片，数字大字号 + 标签小字号，异常/超时用琥珀色 |
| 护理主管-审批台 | 审批列表 | 竖向列表项，左侧状态圆点，右侧通过/驳回按钮，驳回弹出原因输入框 |
| 责任护工-提醒台 | 时间线 | 纵向时间线，左段时间标签，右段提醒卡片，点击展开操作按钮 |
| 责任护工-上报台 | 上报列表 | Tab 切换（已提交/已驳回/已补录），列表项含状态标签，驳回项显示原因+补录按钮 |
| 社工-沟通台 | 沟通记录 | 列表项含异常摘要 + 家属通知状态标签，点击可切换"已通知"/"已确认" |

### 4.3 响应式

桌面优先设计（1920×1080 为基准），兼顾 1366×768 笔记本屏幕，移动端暂不做适配。

### 4.4 状态标签设计

| 状态 | 标签文案 | 颜色 | 可点击操作 |
|------|----------|------|------------|
| pending | 待处理 | zinc 灰 | 点击查看提醒详情 |
| confirmed | 已确认 | 青色 | 点击查看确认记录 |
| abnormal | 异常上报 | 琥珀色 | 点击跳转上报详情 |
| submitted | 审批中 | 蓝色 | 点击查看上报单 |
| approved | 已通过 | 绿色 | 点击查看审批记录 |
| rejected | 已驳回 | 红色 | 点击查看驳回原因 + 补录入口 |
| supplemented | 已补录 | 紫色 | 点击查看补录历史 |
| timeout | 超时 | 红色脉冲动画 | 点击查看超时详情 |
