## 1. 产品概述

社区卫生站家庭签约与档案建档管理系统，面向社区卫生服务中心内部使用。解决家庭医生签约表、随访记录、疫苗预约等纸质和口头流转导致的退回补录靠口头解释、备注停留在当前页面无法延续、签约变动后建档侧无感知等核心痛点。目标用户为全科医生、护士和公共卫生专员三类角色，系统需覆盖从签约创建到建档关闭的完整生命周期。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 全科医生 | 工号登录 | 创建/处理/修改家庭签约、退回签约、查看档案建档状态 |
| 护士 | 工号登录 | 处理签约审核、执行随访录入、批量录入、补充签约信息 |
| 公共卫生专员 | 工号登录 | 处理档案建档、退回签约至医生、标记档案完成、回看历史变更 |

### 2.2 功能模块

1. **工作台首页**：角色待办、最近打开、变更通知、快捷入口
2. **家庭签约处理**：签约创建、签约详情、备注录入（携带至建档）、状态流转、退回操作
3. **档案建档**：建档处理、签约变更感知、退回补录、备注继承、档案关闭
4. **批量录入**：批量创建签约、批量补充信息
5. **变更通知中心**：签约修改→建档感知、退回通知、补录提醒

## 3. 核心流程

### 3.1 家庭签约全生命周期

签约创建（全科医生）→ 提交审核（护士）→ 审核通过/退回修改 → 转入建档（公共卫生专员）→ 建档处理 → 退回补录（退回至签约侧）/ 完成建档 → 关闭。任何环节签约信息被修改，建档侧自动感知并提示变更。

### 3.2 流程图

```mermaid

    "A: 全科医生创建签约" --> "B: 护士审核签约"
    "B" -->|"审核通过"| "C: 转入建档队列"
    "B" -->|"退回修改"| "A"
    "A" -->|"补充信息后重新提交"| "B"
    "C" --> "D: 公卫专员处理建档"
    "D" -->|"信息完整，完成建档"| "E: 档案关闭"
    "D" -->|"签约信息有误或缺失"| "F: 退回签约补录"
    "F" --> "A"
    "A" -->|"签约被修改"| "G: 建档侧变更感知通知"
    "G" --> "D"
```

### 3.3 备注流转机制

签约处理时添加的备注，随签约一起流转至建档。建档侧可查看全部备注历史，建档退回时添加的退回原因也作为备注同步回签约侧。备注按角色和时间排列，支持按角色筛选。

### 3.4 变更感知机制

签约进入建档队列后，任何签约信息的修改（包括基本信息变更、备注新增、状态回退）都会在建档侧生成变更通知。变更通知包含：变更字段、变更前值、变更后值、变更人、变更时间。公卫专员可逐条确认变更。

## 4. 用户界面设计

### 4.1 设计风格

- 主色：深青绿 #0F766E（医疗行业信任感），辅色：暖橙 #EA580C（提醒和操作引导）
- 按钮风格：圆角8px，主要操作实心填充，次要操作描边
- 字体：思源黑体 / Noto Sans SC，标题16px/14px，正文13px，辅助文字12px
- 布局：左侧固定导航 + 右侧内容区，卡片式布局
- 图标风格：线条图标，2px描边，与主色一致

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 工作台首页 | 待办事项 | 卡片列表，左侧状态色条，右侧数量角标，hover浮层显示摘要 |
| 工作台首页 | 最近打开 | 横向时间线布局，最近记录高亮，支持hover预览摘要 |
| 工作台首页 | 变更通知 | 红点角标+列表，未读加粗，点击展开变更对比面板 |
| 签约详情 | 备注区 | 底部固定输入框，上方时间线排列备注气泡，按角色颜色区分 |
| 签约详情 | 变更记录 | 左侧时间线+右侧卡片，状态变更用不同颜色标记 |
| 建档详情 | 变更感知 | 顶部醒目横幅，展示变更摘要，可展开查看详细对比 |
| 建档详情 | 退回操作 | 弹窗表单，必填退回原因，退回后签约侧自动生成待办 |

### 4.3 响应式设计

桌面优先设计，最低支持1280px宽度。左侧导航可折叠，内容区自适应。操作按钮固定在内容区底部，长列表支持虚拟滚动。

## 5. 演示路径覆盖

| 操作路径 | 涉及角色 | 关键交互 |
|----------|----------|----------|
| 创建签约 | 全科医生 | 填写居民信息、选择服务包、添加初始备注、提交审核 |
| 处理签约 | 护士 | 查看待办、审核签约信息、通过/退回、添加审核备注 |

| 关闭档案 | 公卫专员 | 确认信息完整、标记建档完成、归档关闭 |
