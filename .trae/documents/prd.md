## 1. 产品概述

商场运营活动申请与场地审批系统，解决营运专员、客服台、工程部在活动申请与场地审批流程中信息分散、缺少交接的问题。通过为不同角色提供聚焦的常用动作入口，将租户台账、活动申请和投诉记录关联起来，避免因动作分散导致后续拖成问题。

- 目标用户：商场营运专员、客服台人员、工程部人员
- 核心价值：减少翻群记录，让活动申请和场地审批的每个环节都有据可查、有历史可回看

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 营运专员 | 默认角色 | 创建/处理活动申请、查看租户台账、补充资料、关闭申请 |
| 客服台 | 默认角色 | 受理活动申请、转交工程部、查看投诉关联记录 |
| 工程部 | 默认角色 | 场地审批（通过/退回）、查看场地历史、补充审批意见 |

### 2.2 功能模块

1. **活动申请页**：活动申请列表（含状态筛选）、创建活动申请、处理/退回/补充/关闭操作
2. **场地审批页**：场地审批列表（含状态筛选）、审批通过/退回、审批意见补充、审批历史回看
3. **申请详情页**：申请完整信息、状态流转时间线、关联租户信息、操作按钮区
4. **审批详情页**：审批完整信息、审批流转记录、关联活动申请、操作按钮区

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 活动申请列表 | 筛选栏 | 按状态（待处理/处理中/已退回/已补充/已关闭）筛选，按租户名称搜索 |
| 活动申请列表 | 申请卡片列表 | 展示申请编号、租户名称、活动名称、申请时间、当前状态、快捷操作按钮 |
| 活动申请列表 | 创建申请入口 | 弹窗表单：租户选择、活动名称、活动时间、场地选择、备注说明 |
| 场地审批列表 | 筛选栏 | 按审批状态筛选，按场地/申请编号搜索 |
| 场地审批列表 | 审批卡片列表 | 展示审批编号、关联申请、场地名称、申请方、当前状态、快捷操作按钮 |
| 申请详情页 | 基本信息区 | 申请编号、租户信息、活动详情、场地需求、附件资料 |
| 申请详情页 | 状态流转时间线 | 每次状态变更的时间、操作人、操作类型、备注，支持回看 |
| 申请详情页 | 操作区 | 根据当前状态显示可用操作：处理、退回、补充资料、关闭 |
| 审批详情页 | 基本信息区 | 审批编号、关联申请信息、场地信息、申请人信息 |
| 审批详情页 | 审批流转记录 | 每次审批操作的时间、审批人、审批结果、审批意见 |
| 审批详情页 | 操作区 | 根据当前状态显示：通过、退回、补充意见 |

## 3. 核心流程

活动申请与场地审批是两个独立但关联的流程。营运专员创建活动申请后，客服台受理并转交工程部进行场地审批。工程部审批通过后，活动申请自动推进；审批退回时，营运专员需要补充资料后重新提交。

```mermaid
flowchart TD
    "A[营运专员创建活动申请]" --> "B[客服台受理申请]"
    "B" --> "C[转交工程部场地审批]"
    "C" --> "D{工程部审批}"
    "D" -->|"通过"| "E[场地已批准]"
    "D" -->|"退回"| "F[审批退回，需补充]"
    "E" --> "G[活动申请处理完成]"
    "F" --> "H[营运专员补充资料]"
    "H" --> "B"
    "G" --> "I[关闭申请]"
    "A" -->|"营运专员主动关闭"| "I"
```

活动申请状态流转：

```mermaid
stateDiagram-v2
    [*] --> "待处理"
    "待处理" --> "处理中" : 客服台受理
    "处理中" --> "已退回" : 工程部退回
    "已退回" --> "已补充" : 营运专员补充资料
    "已补充" --> "处理中" : 重新受理
    "处理中" --> "已关闭" : 审批通过后关闭
    "待处理" --> "已关闭" : 营运专员主动关闭
```

场地审批状态流转：

```mermaid
stateDiagram-v2
    [*] --> "待审批"
    "待审批" --> "已通过" : 工程部通过
    "待审批" --> "已退回" : 工程部退回
    "已退回" --> "待审批" : 补充意见后重新提交
    "已通过" --> [*]
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深靛蓝 (#1e293b) 搭配琥珀色点缀 (#f59e0b)，传达专业与活力
- 辅助色：石板灰阶用于背景与文字层次
- 按钮风格：圆角 (rounded-lg)，主要操作用实色填充，次要操作用边框样式
- 字体：标题用 Noto Serif SC（衬线体，严肃感），正文用 Noto Sans SC（无衬线，可读性）
- 布局风格：左侧固定导航 + 右侧内容区，卡片式列表，状态标签色彩编码
- 图标风格：Lucide 线性图标，与文字搭配使用

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 活动申请列表 | 顶部导航 | 深靛蓝背景，琥珀色活动高亮标签，白色文字 |
| 活动申请列表 | 筛选栏 | 横向状态标签切换，搜索框带图标，新建按钮琥珀色实心 |
| 活动申请列表 | 申请卡片 | 白色卡片，左侧状态色条，右上角快捷操作图标 |
| 场地审批列表 | 顶部导航 | 同活动申请，当前模块高亮 |
| 场地审批列表 | 审批卡片 | 浅灰卡片，关联申请编号可点击跳转 |
| 申请详情页 | 时间线 | 竖向时间线，节点色彩随状态变化，展开显示操作详情 |
| 申请详情页 | 操作区 | 底部固定操作栏，按钮按主次排列 |
| 审批详情页 | 审批记录 | 竖向时间线，审批人头像+审批结果标签 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度 1024px
- 列表页在小屏幕下卡片单列排列
- 详情页时间线始终竖向排列

## 5. 演示路径覆盖

以下5条演示路径必须全部可操作：

1. **创建**：营运专员新建活动申请 → 自动生成场地审批单
2. **处理**：客服台受理申请 → 转交工程部 → 工程部审批通过
3. **退回**：工程部审批退回 → 营运专员看到退回原因
4. **补充**：营运专员补充资料 → 重新提交 → 再次进入审批
5. **关闭**：审批通过后关闭申请 / 营运专员主动关闭待处理申请
