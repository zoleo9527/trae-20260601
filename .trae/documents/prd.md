## 1. 产品概述

电梯维保年检资料与整改闭环管理系统——解决维保计划、故障电话和年检资料"只记结果不记原因"的痛点，让年检资料处理与整改闭环之间的责任归属和状态流转清晰可追溯。

- 面向维保技师、客服、项目主管三类角色，提供差异化处理入口和判断依据
- 核心价值：把"为什么"写进流程，让每次年检和整改都有据可查、责任到人

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 | 处理入口 |
|------|----------|----------|----------|
| 维保技师 | 工号登录 | 上传年检资料、执行整改、提交完工 | 年检资料录入 → 整改执行 |
| 客服 | 工号登录 | 接收故障电话、创建异常工单、跟进整改进度 | 异常接收 → 工单派发 |
| 项目主管 | 工号登录 | 审核年检资料、审批整改方案、闭环确认 | 审核审批 → 闭环回看 |

### 2.2 功能模块

1. **首页仪表盘**：按角色展示待办事项、异常提醒、已完成记录；含统计卡片与快捷入口
2. **年检资料处理**：年检资料录入/审核全流程，每步附带判断依据字段，状态清晰可追踪
3. **整改闭环回看**：整改任务创建→执行→验收→闭环全链路，责任归属明确，可回溯历史
4. **异常提醒**：实时异常通知面板，按紧急程度分级，支持一键跳转处理
5. **角色视图切换**：顶部角色切换器，切换后菜单、待办、快捷入口全部跟随变化

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |

## 3. 核心流程

### 年检资料处理流程
维保技师收到年检通知 → 录入年检资料（填写判断依据） → 提交审核 → 项目主管审核（填写审核依据）→ 通过/驳回 → 驳回则技师修改重新提交

### 整改闭环流程
异常触发（故障电话/年检不通过）→ 客服创建整改工单 → 维保技师执行整改（记录执行依据）→ 项目主管验收（填写验收依据）→ 闭环确认

### 异常提醒流程
系统检测异常（超期未检/整改超时/年检驳回）→ 生成异常通知 → 推送到对应角色 → 角色点击通知跳转处理

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝灰 (#1E293B) 为基底，琥珀色 (#F59E0B) 为强调色，传达工业严谨感
- **辅助色**：状态绿 (#10B981) / 警告红 (#EF4444) / 信息蓝 (#3B82F6)
- **按钮风格**：圆角微弧（rounded-lg），主操作填充色，次操作描边
- **字体**：标题用 Noto Sans SC Bold，正文用 Noto Sans SC Regular
- **布局风格**：左侧固定导航 + 顶部角色切换，内容区卡片式布局
- **图标风格**：Lucide 线性图标，24px，与文字等高对齐

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 首页仪表盘 | 统计卡片 | 3列网格卡片，数字大字+标签小字，琥珀色边框强调 |
| 首页仪表盘 | 待办列表 | 左侧列表，每行含状态标签+简述+时间，hover高亮 |
| 首页仪表盘 | 异常提醒条 | 顶部固定横幅，红色背景闪烁动画（紧急） |
| 年检资料处理 | 资料列表 | 卡片网格，每卡片含状态徽章+判断依据摘要+操作按钮 |
| 年检资料处理 | 资料详情 | 上下布局：信息区+判断依据表单+状态流转时间线 |
| 整改闭环回看 | 整改列表 | 卡片列表，含责任头像+状态标签+剩余天数 |
| 整改闭环回看 | 整改详情 | 垂直时间线，每节点含操作人/依据/时间 |
| 异常提醒 | 通知面板 | 右侧抽屉，紧急项红色边框+脉冲动画 |

### 4.3 响应式

- 桌面优先设计，最小宽度 1280px
- 平板适配：导航折叠为汉堡菜单，卡片从3列变2列
- 移动端暂不做适配（工业场景以桌面为主）

### 4.4 样例数据要求

- 至少5条待办事项（不同状态）
- 至少3条异常提醒（含1条紧急）
- 至少4条已完成记录
- 年检资料至少6条（各状态覆盖）
- 整改任务至少5条（各状态覆盖）
