
## 1. Product Overview
搬家公司物损申诉与赔付处理工作台，解决物损申诉与赔付处理之间责任不清、信息断层的问题。提供完整的流程追溯能力，支持一线处理和管理层回看使用同一份数据。

## 2. Core Features

### 2.1 User Roles
| Role | Registration Method | Core Permissions |
|------|---------------------|------------------|
| 一线处理员 | 内部账号 | 处理物损申诉、上传照片、填写备注、推进流程 |
| 赔付审核员 | 内部账号 | 查看申诉详情、审核赔付申请、处理异常 |
| 管理员 | 内部账号 | 查看全部数据、追溯历史、导出报表 |

### 2.2 Feature Module
1. **工作台首页**: 任务列表、待处理提醒、异常预警
2. **物损申诉处理**: 申诉详情、照片上传、责任判定、备注填写
3. **赔付处理回看**: 赔付流程、历史记录、责任追溯
4. **异常提醒中心**: 异常工单、问题流处理
5. **侧栏详情面板**: 快速查看预约单、车辆排班、物损照片

### 2.3 Page Details
| Page Name | Module Name | Feature description |
|-----------|-------------|---------------------|
| 工作台首页 | 任务列表 | 按状态筛选待处理、处理中、已完成工单 |
| 工作台首页 | 异常预警 | 显示超时、争议、待审核工单 |
| 物损申诉处理 | 申诉表单 | 填写物损详情、上传照片、责任判定 |
| 物损申诉处理 | 备注记录 | 备注信息可被后续赔付流程继承 |
| 赔付处理回看 | 赔付流程 | 查看赔付申请、审核状态、打款记录 |
| 赔付处理回看 | 责任追溯 | 关联预约单、车辆排班、物损照片 |
| 异常提醒中心 | 异常工单 | 超时工单提醒、争议处理、问题流跟踪 |

## 3. Core Process

### 3.1 顺利流
```mermaid
flowchart LR
    A[客户报修] --> B[一线处理员创建申诉]
    B --> C[上传物损照片]
    C --> D[责任判定]
    D --> E[提交赔付申请]
    E --> F[赔付审核通过]
    F --> G[打款完成]
    G --> H[归档]
```

### 3.2 问题流
```mermaid
flowchart LR
    A[客户报修] --> B[一线处理员创建申诉]
    B --> C[上传物损照片]
    C --> D{责任争议}
    D -->|有争议| E[异常工单]
    E --> F[管理层介入]
    F --> G[重新判定]
    G --> H[提交赔付申请]
    D -->|无争议| H
    H --> I[赔付审核]
    I -->|审核不通过| J[退回修改]
    J --> H
    I -->|审核通过| K[打款完成]
    K --> L[归档]
```

### 3.3 归档流程
```mermaid
flowchart LR
    A[工单完成] --> B[数据归档]
    B --> C[生成报表]
    C --> D[历史查询]
```

## 4. User Interface Design

### 4.1 Design Style
- **主色调**: 深蓝色系 (#1e3a5f) 搭配橙色强调色 (#f97316)
- **按钮风格**: 圆角矩形，悬停有阴影效果
- **字体**: Inter，标题18px，正文14px，备注12px
- **布局风格**: 卡片式布局，左侧导航，右侧内容区，侧栏详情面板
- **图标**: Lucide React 图标库

### 4.2 Page Design Overview
| Page Name | Module Name | UI Elements |
|-----------|-------------|-------------|
| 工作台首页 | 任务列表 | 卡片列表、状态标签、优先级标识 |
| 工作台首页 | 异常预警 | 红色警示图标、倒计时显示 |
| 物损申诉处理 | 申诉表单 | 表单输入、图片上传、下拉选择 |
| 赔付处理回看 | 流程时间线 | 时间轴展示、状态节点 |
| 侧栏详情面板 | 详情展示 | 折叠面板、标签页切换 |

### 4.3 Responsiveness
- 桌面优先设计
- 支持1024px以上分辨率
- 侧栏可折叠

### 4.4 交互设计
- 点击工单卡片显示侧栏详情
- 状态变更有动画过渡
- 备注实时保存
- 照片支持预览和下载
