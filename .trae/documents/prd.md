## 1. 产品概述

字幕工作室流程管理桌面工具，解决多项目并行时翻译、时间轴、校对、压制各环节文件版本混乱、返工追踪困难的问题。面向字幕工作室项目经理与团队成员，提供任务拆分、人员分配、文件版本管理、校对意见标注和返工状态追踪的完整流程闭环。

- 目标用户：字幕工作室项目经理、译员、校对人员、压制同事
- 核心价值：消除版本混乱、减少返工丢失、提升多项目并行效率

## 2. 核心功能

### 2.1 用户角色

| 角色 | 说明 | 核心权限 |
|------|------|----------|
| 项目经理 | 统筹项目进度 | 创建项目、拆分集数/段落、分配人员、确认最终版本 |
| 译员 | 翻译字幕文件 | 提交翻译版本、查看校对意见 |
| 时间轴人员 | 调整时间轴 | 提交时间轴版本 |
| 校对人员 | 审核字幕质量 | 标注问题、打回返工、确认通过 |
| 压制人员 | 压制最终字幕 | 查看确认状态、标记压制完成 |

### 2.2 功能模块

1. **仪表盘**：项目总览、待办事项、状态统计、最近打开项目
2. **项目管理**：节目列表、新建/编辑项目、项目详情
3. **集数管理**：集数拆分、段落划分、人员分配、状态追踪
4. **版本管理**：文件提交历史、版本对比入口、本地路径记录
5. **校对工单**：校对意见列表、问题标注、返工标记、通过确认
6. **交付看板**：压制状态总览、待交付项目、完成归档

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|

## 3. 核心流程

项目经理创建节目并拆分集数 → 分配译员/校对/压制人员 → 译员提交翻译版本（记录文件路径）→ 校对人员审核并标注意见 → 通过则流转至待压制 / 打回则返工至译员 → 压制人员确认完成并录入输出路径 → 项目经理标记交付

```mermaid
flowchart TD
    "创建节目" --> "拆分集数/段落"
    "拆分集数/段落" --> "分配人员"
    "分配人员" --> "翻译提交"
    "翻译提交" --> "校对审核"
    "校对审核" --> "通过？"
    "通过？" -- 否 --> "返工标注"
    "返工标注" --> "翻译提交"
    "通过？" -- 是 --> "待压制"
    "待压制" --> "压制完成"
    "压制完成" --> "待交付"
    "待交付" --> "已交付"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深灰底色（#1a1a2e）搭配琥珀色强调（#f59e0b），营造专业影视后期工具感
- **辅助色**：状态色——翻译中蓝（#3b82f6）、校对中紫（#8b5cf6）、待压制橙（#f97316）、已交付绿（#22c55e）、异常红（#ef4444）
- **按钮风格**：圆角6px，填充按钮用琥珀色，幽灵按钮用边框+文字色
- **字体**：中文用系统默认（PingFang SC / Microsoft YaHei），数字/英文用 JetBrains Mono 等宽体突出版本号和时间码
- **布局风格**：左侧固定导航栏 + 右侧内容区，顶部面包屑导航，内容区使用卡片与表格混合布局
- **图标风格**：Lucide 线性图标，24px 主导航，16px 内联操作

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 仪表盘 | 状态统计 | 4张统计卡片（圆角、渐变背景、大号数字+标签），水平排列 |
| 仪表盘 | 最近项目 | 紧凑卡片列表，显示项目名、进度条、最后打开时间 |
| 仪表盘 | 异常告警 | 红色左边框卡片列表，图标+集数标签+异常描述 |
| 项目管理 | 项目列表 | 网格卡片模式，每张卡片含封面色块、项目名、集数进度、状态标签 |
| 项目详情 | 集数表格 | 表格行展开显示段落，每行含状态徽章、人员头像组、版本数、操作按钮 |
| 项目详情 | 段落面板 | 水平分割面板，左列表右详情，段落用色块区分 |
| 版本管理 | 版本时间线 | 垂直时间线组件，左侧时间戳，右侧版本卡片含文件路径和操作 |
| 校对工单 | 意见列表 | 卡片列表，问题类型用色标，支持内联回复 |
| 交付看板 | 看板列 | 4列水平看板，卡片可拖拽排序 |

### 4.3 响应式

桌面优先设计，最小宽度1280px。内容区使用弹性布局，表格水平滚动，面板可折叠。

### 4.4 3D 场景

不适用
