## 1. 产品概述

百货专柜促销活动与销售核对工作面，解决促销活动信息分散、接力处理断档、销售核对无法追溯等问题。以**柜长→楼层主管→品牌督导**三级接力为核心流程，实现从促销活动立项到销售核对的全链路连续处理。

- 解决痛点：信息散在旧台账、现场记录、沟通截图，无法形成完整链路；促销备注无法延续到销售核对环节
- 目标用户：百货商场柜长、楼层主管、品牌督导
- 核心价值：处理链路可追溯、备注信息可延续、断网重开不丢状态

---

## 2. 核心功能

### 2.1 用户角色

| 角色 | 说明 | 核心权限 |
|------|------|----------|
| 柜长 | 专柜负责人，发起促销活动 | 创建促销单、录入活动信息、提交初审 |
| 楼层主管 | 楼层管理者，审核促销活动 | 审核促销单、补充审批意见、流转到督导 |
| 品牌督导 | 品牌方代表，最终确认并核对销售 | 终审促销单、录入销售数据、完成销售核对 |

### 2.2 功能模块

1. **工作台首页**：待处理单子列表、最近状态变化时间线、快速入口
2. **促销活动处理**：三级接力处理、备注延续、状态流转
3. **销售核对回看**：按促销单查看销售核对记录、历史追溯
4. **导入导出**：批量导入促销单、导出完整处理记录
5. **最近打开**：快速访问最近处理过的单据

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|----------|
| 工作台 | 待处理单列表 | 按角色显示当前用户待处理的促销单，显示紧急程度、剩余时间 |
| 工作台 | 最近状态时间线 | 展示所有促销单最近的状态变化，可点击跳转 |
| 工作台 | 快捷操作区 | 新建促销单、导入数据、查看最近打开 |
| 促销处理页 | 促销单详情 | 展示活动基本信息、历史处理记录、接力链条 |
| 促销处理页 | 处理操作区 | 当前角色可填写处理意见、上传凭证、提交下一环节 |
| 促销处理页 | 备注延续区 | 所有历史备注自动延续，销售核对时可见 |
| 销售核对页 | 销售数据录入 | 录入实际销售、对比预算、计算达成率 |
| 销售核对页 | 核对追溯 | 查看完整的促销活动→销售核对全链路记录 |
| 导入导出页 | 数据导入 | 支持 Excel/JSON 格式批量导入促销单 |
| 导入导出页 | 数据导出 | 导出单条或批量导出处理记录 |

## 3. 核心流程

### 3.1 促销活动接力处理流程

```mermaid

    A["柜长创建促销单<br/>填写活动信息"] --> B["柜长提交<br/>楼层主管审核"]

    C --> D["主管提交<br/>品牌督导确认"]
```

### 3.2 信息延续机制

促销活动处理时的所有备注、附件、审批意见，都会自动延续到销售核对环节，确保信息不丢失。每个环节的处理人都可以看到之前所有环节的完整记录。

## 4. 用户界面设计

### 4.1 设计风格

**设计定位：专业高效的零售管理工作面**
- 主色调：深海军蓝 `#0F2B4A`（专业、稳重），搭配琥珀金 `#D4A853`（高端零售气质）
- 辅助色： Emerald 绿 `#10B981`（通过）、珊瑚红 `#EF4444`（驳回）、天空蓝 `#3B82F6`（处理中）
- 背景：浅灰 `#F8FAFC` 打底，卡片纯白 `#FFFFFF`，分区清晰
- 字体：标题使用「思源宋体 CN」彰显零售行业质感，正文使用「Inter」确保易读性
- 按钮：微圆角 6px，悬停有微妙浮起效果，点击有按压反馈
- 卡片：细腻阴影 + 1px 边框，分区明确，信息层级清晰
- 动效：页面加载时卡片错落淡入，状态变化时有高亮闪烁提示

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|---------|---------|---------|
| 工作台 | 待处理单 | 卡片式列表，左侧角色标签、状态色标，右侧操作按钮 |
| 工作台 | 状态时间线 | 左侧时间轴，右侧事件卡片，hover 显示详情 |
| 促销处理页 | 接力链条 | 顶部横向步骤条，当前步骤高亮，已完成步骤打钩 |
| 促销处理页 | 备注区 | 对话气泡式展示，不同角色用不同颜色区分 |
| 销售核对页 | 数据对比 | 预算 vs 实际双栏对比，达成率用进度条可视化 |
| 销售核对页 | 追溯链路 | 可折叠的全链路时间轴，点击展开每环节详情 |

### 4.3 响应式

- 桌面端优先设计，适配 1280px 及以上
- 平板端自适应，卡片布局调整为双列
- 移动端单列布局，底部导航切换
- 所有操作区域确保触摸友好（最小 44px 点击区域）

### 4.4 状态持久化

- 所有数据实时写入 localStorage
- 未提交的表单内容自动草稿保存
- 断网或刷新页面后状态完全恢复
- 支持导出完整数据备份
