## 1. 产品概述

滑雪场运营管理系统——教练课程与学员签到，替代租赁单、教练排班表和救援记录的人工拼凑。核心解决雪具错拿、课程爽约和摔伤记录缺证据三大痛点，确保教练课程到学员签到之间无无人负责的空档。

- 目标用户：滑雪场租赁员、教练主管、安全巡逻员
- 核心价值：状态口径一致、全流程可追溯、角色视角差异化但数据统一

## 2. 核心功能

### 2.1 用户角色

| 角色 | 登录方式 | 核心权限 |
|------|----------|----------|
| 租赁员 | 角色切换选择 | 查看/办理雪具租赁、归还、错拿标记 |
| 教练主管 | 角色切换选择 | 排班管理、课程创建/取消、查看学员签到 |
| 安全巡逻员 | 角色切换选择 | 录入救援/摔伤记录、上传证据附件、查看历史 |

### 2.2 功能模块

1. **仪表盘页**：角色概览、当日关键指标、待办事项、状态一致概览
2. **雪具租赁页**：租赁单管理、归还确认、错拿预警与标记
3. **教练排班页**：教练排班表、课程创建/编辑、爽约标记与统计
4. **学员签到页**：课程签到码、签到回看、空档检测与提醒
5. **救援记录页**：摔伤/事故录入、证据附件占位与上传、历史回溯
6. **角色切换**：顶部角色选择器，切换后视图与操作权限联动

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 仪表盘 | 关键指标卡 | 当日租赁数/课程数/签到率/救援数，各角色口径一致 |

## 3. 核心流程

### 3.1 雪具租赁-课程-签到闭环

学员到达 → 租赁雪具（生成租赁单，关联课程） → 教练确认课程（排班已就绪） → 学员签到（自动校验租赁状态） → 课程结束 → 雪具归还 → 闭环。任何环节断裂均有系统提醒。

### 3.2 救援记录闭环

巡逻员发现事故 → 录入救援记录（附件可占位） → 关联学员/课程 → 附件补全 → 记录闭环。

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：冰蓝色 `#E8F4FD`（背景）、深岩板灰 `#1E293B`（文字/导航）、极光绿 `#10B981`（状态正常）、雪道橙 `#F97316`（警告/错拿）、冰红 `#EF4444`（危险/缺失证据）
- 按钮风格：圆角微凸（rounded-lg），主按钮实色填充，次按钮描边
- 字体：标题用 DM Sans（几何感），正文用 Noto Sans SC（中文清晰）
- 布局：左侧固定导航栏 + 右侧内容区，卡片式模块
- 图标风格：Lucide 线性图标，统一 18px

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 仪表盘 | 指标卡 | 4 列网格，冰蓝渐变底色，数字加粗，同比趋势箭头 |
| 仪表盘 | 待办列表 | 卡片列表，左侧色条标识优先级，hover 微浮起 |
| 雪具租赁 | 租赁单列表 | 表格+状态标签，错拿标记橙色闪烁 |
| 雪具租赁 | 新建租赁 | 侧滑面板，下拉选择+自动补全 |
| 教练排班 | 排班日历 | 周视图网格，教练色块，拖拽调整 |
| 教练排班 | 课程卡片 | 圆角卡片，时间+教练+名额，爽约灰色划线 |
| 学员签到 | 签到面板 | 课程卡片+学员头像网格，签到绿色勾，未签到灰色 |
| 学员签到 | 签到回看 | 时间轴布局，空档段橙色高亮 |
| 救援记录 | 事故列表 | 卡片列表，严重度色条，附件图标+状态 |
| 救援记录 | 新建记录 | 模态弹窗，表单+附件拖拽区（虚线框占位） |

### 4.3 响应式

桌面优先设计，导航栏在小屏折叠为汉堡菜单，卡片网格自适应列数。触屏设备适配点击区域增大。

### 4.4 3D 场景

不涉及 3D 场景。
