## 1. 产品概述

农资门店肥料订货与到货通知系统，面向农资门店一线操作员和店主，解决赊账难催、订货备注断裂、到货后信息无法追溯等日常经营痛点。核心目标：让肥料从订货到到货的完整链路数据不断裂、可追溯、可回看。

- 目标用户：农资门店店员（一线录入/处理）、店主（管理回看与对账）
- 核心价值：订货备注自动流转到到货通知，操作全程留痕，一线操作与管理回看基于同一份数据

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 店员 | 默认登录 | 创建/编辑订货单、确认到货、查看通知 |
| 店主 | 默认登录（同系统） | 全部店员权限 + 查看操作日志 + 导出数据 |

### 2.2 功能模块

1. **工作台**：当日待办统计、近期订货/到货快捷入口
2. **肥料订货管理**：创建订货单、编辑备注、状态流转、附件占位
3. **到货通知管理**：从订货单生成通知、备注自动继承、到货确认、异常标记
4. **操作日志**：按时间/实体/操作类型查询，支持追溯

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|

| 工作台 | 快捷列表 | 最近5条订货单、最近5条到货通知 |
| 肥料订货管理 | 订货单列表 | 按状态/日期/客户筛选，显示单号/客户/产品/数量/状态/备注摘要 |

## 3. 核心流程

**肥料订货到到货通知主链路**：

1. 店员创建肥料订货单，填写客户信息、产品、数量和备注
2. 店主或店员确认订货单，状态变为"已确认"
3. 订货单发货后，状态变为"已发货"
4. 货物到店后，从订货单一键创建到货通知，备注和附件占位自动继承
5. 店员确认到货，核对实到数量；如有差异，标记异常并填写异常说明
6. 全程操作自动记入操作日志

```mermaid
flowchart TD
    "创建订货单" --> "待确认"
    "待确认" --> "已确认"
    "已确认" --> "已发货"
    "已发货" --> "创建到货通知"
    "创建到货通知" --> "到货待确认"
    "到货待确认" --> "到货确认（正常）"
    "到货待确认" --> "到货确认（异常）"
    "到货确认（异常）" --> "异常说明"
```

**备注流转规则**：
- 订货单备注 → 自动复制到到货通知的"订货备注"字段（只读）
- 到货通知可额外填写"到货备注"字段
- 异常说明独立记录，关联到到货通知

**附件占位规则**：
- 订货单和到货通知均可添加附件占位（文件名 + 备注，无实际上传）
- 从订货单创建到货通知时，附件占位自动继承
- 附件占位状态：待上传 / 已占位

## 4. 用户界面设计

### 4.1 设计风格

- 主色：深棕 #5D4037（大地/农资感）+ 辅色：翠绿 #2E7D32（农业生机）
- 强调色：琥珀 #FF8F00（提醒/待办）
- 按钮风格：圆角 6px，实心填充，hover 微上浮阴影
- 字体：思源黑体（Noto Sans SC）标题 16-20px，正文 14px
- 布局：左侧固定导航 + 右侧内容区，卡片式布局
- 图标：Element Plus 内置图标

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 工作台 | 统计卡片 | 3列卡片，深棕底+白字，数字大号加粗 |
| 工作台 | 快捷列表 | 两列卡片列表，左侧订货右侧到货 |
| 肥料订货管理 | 列表 | 表格，状态用彩色标签，备注截断显示 |
| 肥料订货管理 | 表单 | 抽屉式表单，备注为多行文本域，附件占位为可增删行 |
| 到货通知管理 | 列表 | 表格，关联订单号为可点击链接，备注继承标识 |
| 到货通知管理 | 创建 | 对话框，预填继承信息，到货备注可编辑 |
| 操作日志 | 列表 | 表格，操作类型彩色标签，时间精确到秒 |

### 4.3 响应式

- 桌面优先（1280px+），最小支持 1024px 宽度
- 表格在小屏下横向滚动
- 抽屉/对话框在移动端全屏展示

## 5. 轻量能力说明

| 能力 | 实现方式 | 说明 |
|------|----------|------|
| 数据导出 | 订货单/到货通知列表页提供 CSV 导出按钮 | 仅导出当前筛选结果 |
| 附件 | 附件占位（文件名+备注+状态），无真实文件上传 | 预留文件上传接口，前端仅做占位记录 |
| 消息通知 | 到货通知创建时，列表页新增条目+页面内 Toast 提醒 | 不接入外部推送，仅在系统内提醒 |
