## 1. 产品概述
鲜花配送站花材采购与到货分级系统——解决采购备注无法流转到到货分级、角色入口混在一起、流程靠口头衔接的问题。系统让花材采购处理的备注自然延续到到货分级环节，三个角色（花艺师、配送调度、售后客服）各有独立入口，采购完成自动驱动分级跟进，不再依赖消息提醒。

## 2. 核心功能

### 2.1 用户角色
| 角色 | 登录方式 | 核心权限 |
|------|----------|----------|
| 花艺师 | 演示账号选择 | 发起花材采购、填写采购备注、查看到货分级结果 |
| 配送调度 | 演示账号选择 | 接收待分级花材、执行到货分级、标注异常 |
| 售后客服 | 演示账号选择 | 回查已关闭单据、处理退回申诉、查看全链路备注 |

### 2.2 功能模块
1. **登录页**: 角色选择式简化登录，三个角色入口分离
2. **花艺师工作台**: 花材采购处理（新建/编辑/提交）、采购单筛选列表、备注字段（强提醒：此备注将传递到到货分级）
3. **配送调度工作台**: 待分级任务队列、到货分级操作面板、异常退回操作
4. **售后客服工作台**: 全量单据回查、退回申诉处理、链路备注时间线
5. **到货分级回看**: 任一角色可查看单据从采购到分级的完整链路

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 登录页 | 角色选择卡片 | 三个角色卡片，点击即登录，无需密码 |
| 花艺师工作台 | 采购处理面板 | 新建采购单、填写花材名称/数量/供应商/紧急度/备注 |
| 花艺师工作台 | 采购单筛选列表 | 按状态（待办/处理中/被退回/已关闭/需回查）筛选，支持搜索 |
| 花艺师工作台 | 采购备注传递区 | 备注输入时提示"此备注将传递到到货分级环节"，提交后不可仅在此页面查看 |
| 配送调度工作台 | 待分级队列 | 按紧急度和到达时间排序的待分级任务列表 |
| 配送调度工作台 | 到货分级操作 | 读取采购备注、执行分级（A级/B级/C级/报废）、标注异常 |
| 配送调度工作台 | 退回操作 | 退回至采购环节并填写退回原因 |
| 售后客服工作台 | 全量单据回查 | 按状态/时间/供应商筛选，查看完整链路 |
| 售后客服工作台 | 申诉处理 | 处理退回申诉，恢复或关闭单据 |
| 售后客服工作台 | 链路时间线 | 采购备注→到货分级→退回/关闭的完整时间线 |
| 到货分级回看 | 链路追踪 | 单据从采购到分级的全流程备注和操作记录 |

## 3. 核心流程

花艺师创建采购单并填写备注 → 采购单提交后自动出现在配送调度的待分级队列中 → 配送调度查看采购备注并执行分级 → 分级结果自动回传给花艺师 → 如有异常则退回并附原因 → 售后客服可随时回查全链路

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深灰底色(#1a1a2e) + 琥珀色(#f59e0b)作为高亮警示 + 翡翠绿(#10b981)作为确认色
- 强调现场压力感：信息密度高、状态色彩鲜明、紧急任务脉冲动画
- 按钮风格：实心圆角按钮，操作类用琥珀色，确认类用翡翠绿
- 字体：数字和状态用等宽字体突出，正文用无衬线体
- 布局风格：左右分栏——左侧为任务列表/队列，右侧为操作详情面板
- 图标：使用 lucide-react 图标库
- 整体氛围：类似调度中心/作战室，不是安静的管理后台

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI要素 |
|----------|----------|--------|
| 登录页 | 角色选择 | 三张角色卡片并排，卡片内含角色图标和名称，hover时卡片抬升 + 角色专属色彩亮起 |
| 花艺师工作台 | 采购处理面板 | 左侧筛选列表(含状态标签色块)，右侧表单(备注区带黄色脉冲边框提醒) |
| 花艺师工作台 | 状态标签 | 待办=琥珀脉冲，处理中=蓝色呼吸，被退回=红色闪烁，已关闭=灰色，需回查=紫色 |
| 配送调度工作台 | 待分级队列 | 紧急任务顶部置顶 + 脉冲边框，每行显示花材名/数量/供应商/采购备注摘要 |
| 配送调度工作台 | 分级操作 | 右侧面板展示采购备注全文(带来源标记)，四级分级按钮横排，退回操作在底部 |
| 售后客服工作台 | 回查面板 | 全宽表格，行内展开链路时间线，备注气泡按角色着色 |
| 到货分级回看 | 链路追踪 | 垂直时间线，每个节点显示操作人/角色/时间/备注内容 |

### 4.3 响应式
- 桌面优先设计，左右分栏布局
- 平板端分栏变为上下布局
- 移动端单列堆叠，操作面板改为抽屉式

### 4.4 现场压力感设计要素
- 紧急任务队列项带有微妙脉冲动画（CSS animation）
- 被退回状态使用红色闪烁边框
- 待分级任务数量badge实时显示在导航栏
- 备注传递区使用琥珀色脉冲边框 + 文字提示"此备注将传递到到货分级环节"
- 操作反馈使用toast通知而非页面刷新
- 时间相关字段使用相对时间（"3分钟前"）增加紧迫感
