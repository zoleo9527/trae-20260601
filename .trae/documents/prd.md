## 1. 产品概述

再生资源分拣中心调价审核与库存锁价系统，解决库存商品销售价格临时变动导致的结算争议问题。通过规范的调价申请-审核-锁价流程，确保仓库出库价格与审核通过价格一致，区分市场价格变化、客户议价和库存等级变化三种调价类型，为客户提供透明的报价记录。

- 目标用户：再生资源分拣中心销售内勤、负责人、仓库管理员
- 核心价值：防止临时改价引发结算纠纷，实现价格变动全流程可追溯

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 销售内勤 | 系统分配 | 发起调价申请、查看客户报价记录 |
| 负责人 | 系统分配 | 审核调价申请（通过/拒绝）、查看全部数据 |
| 仓库管理员 | 系统分配 | 按锁价出库、查看锁价库存 |

### 2.2 功能模块

1. **调价管理页**：调价申请表单、调价记录列表、筛选与搜索
2. **审核管理页**：待审核列表、审核操作（通过/拒绝及意见）、审核历史
3. **锁价库存页**：锁价库存列表、失效时间管理、价格状态监控
4. **客户报价记录页**：客户报价历史、报价详情、价格趋势

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 调价管理 | 调价申请表单 | 选择库存商品、输入新价格、选择调价类型（市场价变化/客户议价/等级变化）、填写调价原因、设置期望锁价有效期 |
| 调价管理 | 调价记录列表 | 展示所有调价申请记录，支持按状态（待审核/已通过/已拒绝/已过期）筛选，按商品/客户/日期搜索 |
| 审核管理 | 待审核列表 | 展示待审核的调价申请，显示原价、新价、调价幅度、调价类型、申请人信息 |
| 审核管理 | 审核操作 | 审核通过（确认锁价及有效期）或拒绝（填写拒绝原因） |
| 审核管理 | 审核历史 | 查看所有已审核记录，包括审核意见和时间 |
| 锁价库存 | 锁价列表 | 展示所有已锁价库存，显示商品名称、锁定价、原市场价、锁价有效期、剩余天数 |
| 锁价库存 | 失效提醒 | 已过期或即将过期（≤3天）的锁价高亮提醒 |
| 锁价库存 | 状态监控 | 实时显示锁价状态（生效中/即将过期/已过期） |
| 客户报价记录 | 报价历史 | 按客户展示所有报价记录，含调价类型标签 |
| 客户报价记录 | 报价详情 | 展示单条报价的完整信息：商品、原价、新价、调价原因、审核结果、锁价信息 |

## 3. 核心流程

销售内勤发起调价申请 → 负责人审核（通过则自动锁价，拒绝则退回）→ 审核通过后库存按锁定价出库 → 锁价到期后自动失效恢复市场价

```mermaid
flowchart TD
    "A[销售内勤发起调价申请]" --> "B[选择调价类型：市场价变化/客户议价/等级变化]"
    "B" --> "C[填写新价格与原因]"
    "C" --> "D[提交审核]"
    "D" --> "E{负责人审核}"
    "E" -->|"通过"| "F[系统自动锁价，设置有效期]"
    "F" --> "G[仓库按锁定价出库]"
    "E" -->|"拒绝"| "H[记录拒绝原因，退回申请]"
    "F" --> "I{锁价有效期检查}"
    "I" -->|"未过期"| "G"
    "I" -->|"已过期"| "J[锁价失效，恢复市场价]"
    "G" --> "K[记录客户报价]"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深石墨灰(#1E293B) + 琥珀黄(#F59E0B)强调色
- 辅助色：翠绿(#10B981)表示通过、玫红(#EF4444)表示拒绝、石板蓝(#3B82F6)表示信息
- 按钮风格：圆角矩形，适度阴影，悬停时微抬升效果
- 字体：Noto Sans SC（中文UI）+ JetBrains Mono（数字/金额）
- 布局：左侧固定导航栏 + 右侧内容区，卡片式模块
- 图标：Lucide图标体系

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 调价管理 | 调价申请表单 | 卡片式表单，下拉选择器，金额输入带货币符号，调价类型标签选择，日期选择器 |
| 调价管理 | 调价记录列表 | 表格布局，状态徽章（彩色圆点+文字），行悬停高亮，分页器 |
| 审核管理 | 待审核列表 | 卡片列表，左彩色边条标识紧急程度，价格对比展示（删除线原价+新价） |
| 审核管理 | 审核操作 | 模态对话框，通过/拒绝按钮组，拒绝原因文本域 |
| 审核管理 | 审核历史 | 时间线布局，审核意见气泡 |
| 锁价库存 | 锁价列表 | 数据表格，进度条显示有效期剩余，过期行灰色+删除线 |
| 锁价库存 | 失效提醒 | 顶部警示横幅，闪烁图标提示即将过期 |
| 锁价库存 | 状态监控 | 状态标签（绿色生效/橙色即将过期/灰色已过期），倒计时 |
| 客户报价记录 | 报价历史 | 按客户分组的手风琴列表，调价类型彩色标签 |
| 客户报价记录 | 报价详情 | 侧滑面板，完整信息展示 |

### 4.3 响应式设计

- 桌面优先设计，1280px以上最佳体验
- 1024px-1280px：侧边栏可折叠
- 768px以下：底部标签导航，表格改为卡片列表
