## 1. 产品概述

水产养殖场塘口巡检与水质预警系统——为养殖技术员、饲料仓管和场长提供一站式工作台，让每日巡检、投喂、用药和水质异常处理形成闭环。第一屏即告知今日优先处理事项，巡检备注能被水质预警模块感知并继续使用，真正实现"信息一条线"。

- 目标用户：中大型水产养殖场的日常运营团队
- 核心价值：消除巡检-投喂-用药-预警之间的信息孤岛，让状态变更、责任人、时间点和备注全部沉淀在数据中，而非页面临时写死

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 养殖技术员 | 下拉选择身份 | 塘口巡检处理、水质异常上报、投喂记录填写 |
| 饲料仓管 | 下拉选择身份 | 投喂记录确认、药品台账出入库、库存预警 |
| 场长 | 下拉选择身份 | 全部模块查看、预警审批、数据重置、异常处理终审 |

### 2.2 功能模块

1. **今日工作台**：今日待办优先级、各模块待处理数量、最新预警卡片、角色切换
2. **塘口巡检**：巡检列表、巡检处理（含备注）、巡检历史回看
3. **水质预警**：预警列表、预警详情与回看、关联巡检备注自动带入、预警状态流转
4. **投喂记录**：投喂计划与实际记录、关联塘口
5. **药品台账**：药品出入库、库存余量、关联使用记录
6. **异常处理抽屉**：从预警或巡检触发的异常处理面板，记录处理人、时间、结果

| 页面名称 | 模块名称 | 功能说明 |
|----------|----------|----------|

## 3. 核心流程

### 3.1 塘口巡检 → 水质预警联动流程

养殖技术员进行塘口巡检，填写水质指标和备注。若指标超阈值，系统自动生成水质预警。预警中可查看巡检备注，场长审批后关闭预警。整个链路的状态变更、责任人、时间点和备注均记录在数据库中。

```mermaid
flowchart TD
    "养殖技术员创建巡检" --> "填写水质指标+备注"
    "填写水质指标+备注" --> "指标是否超阈值？"
    "指标是否超阈值？" -->|"是"| "自动生成水质预警"
    "指标是否超阈值？" -->|"否"| "巡检状态→已检"
    "自动生成水质预警" --> "预警携带巡检备注"
    "预警携带巡检备注" --> "养殖技术员追加备注"
    "养殖技术员追加备注" --> "场长审批处理"
    "场长审批处理" --> "预警状态→已关闭"
    "巡检备注被修改" --> "水质预警感知变更"
    "水质预警感知变更" --> "更新预警关联信息"
```

### 3.2 异常处理抽屉流程

```mermaid

    "状态变更记录入库" --> "关联模块感知更新"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深海蓝 (#0C4A6E) + 浅水绿 (#10B981)，辅以警示琥珀 (#F59E0B) 和危险红 (#EF4444)
- **按钮风格**：圆角 8px，主按钮实心深蓝，次按钮描边，危险按钮红色实心
- **字体**：标题用 Noto Sans SC Bold，正文用 Noto Sans SC Regular，数据用 JetBrains Mono
- **布局**：左侧导航栏 + 右侧内容区，卡片式内容组织
- **图标风格**：线性图标 (Lucide)，统一 20px 大小

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 今日工作台 | 优先待办区 | 深色卡片、左侧色条标识紧急程度、数字徽标 |
| 今日工作台 | 预警速览 | 渐变背景卡片、预警级别色条、点击涟漪动效 |
| 今日工作台 | 角色切换 | 顶部导航栏下拉、头像+角色名 |
| 塘口巡检 | 巡检列表 | 分组卡片、状态标签（绿/黄/红）、点击展开详情 |
| 塘口巡检 | 处理面板 | 模态弹窗、表单分组、备注高亮关联标记 |
| 水质预警 | 预警列表 | 紧急程度色条、关联巡检标签、状态流转时间线 |
| 水质预警 | 回看详情 | 时间线组件、关联备注面板、状态变更记录 |
| 异常处理抽屉 | 处理面板 | 右侧滑出抽屉、表单、操作日志、提交动效 |

### 4.3 响应式

桌面优先设计，最小宽度 1280px，左侧固定导航 240px，内容区自适应。平板端导航折叠为汉堡菜单。

### 4.4 数据重置

场长角色可在设置面板中点击"重置数据"，将所有业务数据恢复到种子数据初始状态，操作需二次确认。
