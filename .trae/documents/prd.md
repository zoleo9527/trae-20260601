## 1. 产品概述

车辆年检站预约接车与资料核验系统，用于解决年检站中预约接车、资料核验、检测审核各环节信息割裂、责任不清的问题。核心目标是将预约单、检测线记录和整改复检表统一到同一条记录链上，让接车员、检测员、审核员各司其职、信息贯通。

- 目标用户：车辆年检站接车员、检测员、审核员
- 核心价值：消除接车与核验间的信息断层，备注与退回原因跨环节可追溯

## 2. 核心功能

### 2.1 用户角色

| 角色 | 登录方式 | 核心权限 |
|------|----------|----------|
| 接车员 | 选择角色即可登录 | 查看待接车预约、处理接车、填写接车备注 |
| 检测员 | 选择角色即可登录 | 查看待检测记录、执行检测、填写检测结果 |
| 审核员 | 选择角色即可登录 | 查看待审核记录、通过/退回、填写退回原因 |

### 2.2 功能模块

1. **登录页**：角色选择登录，无密码验证
2. **工作台页**：根据当前角色展示待办列表，支持单条处理与批量操作
3. **记录详情页**：查看单条记录的完整生命周期（预约→接车→检测→审核），含所有备注与退回原因
4. **数据管理页**：批量处理与数据重置

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 登录页 | 角色选择 | 三个角色卡片，点击即登录进入工作台 |
| 工作台 | 待办列表 | 按角色筛选待处理记录，显示车牌号、预约时间、当前状态 |
| 工作台 | 接车处理 | 接车员确认接车，填写接车备注，提交后进入"待检测" |
| 工作台 | 资料核验 | 审核员核验资料，可"通过"进入"检测完成"，或"退回"并填写原因 |
| 工作台 | 批量操作 | 支持全选/多选后批量通过或批量退回 |
| 记录详情 | 完整时间线 | 展示预约→接车→检测→审核全流程，含每步操作人、时间、备注 |
| 记录详情 | 退回与复检 | 退回后记录回到接车员，接车员可补充备注后重新提交 |
| 数据管理 | 数据重置 | 一键重置所有记录到初始预约状态 |

## 3. 核心流程

### 正常流程
预约单创建 → 接车员接车（填写备注）→ 检测员检测（填写结果）→ 审核员核验通过 → 年检完成

### 异常流程
预约单创建 → 接车员接车 → 检测员检测 → 审核员退回（填写退回原因）→ 记录回到接车员待办 → 接车员补充备注 → 重新提交 → 检测员复检 → 审核员复核通过/不通过

## 4. 用户界面设计

### 4.1 设计风格

- 主色：深蓝灰 (#1E293B)，辅色：琥珀橙 (#F59E0B) 作为操作提示
- 按钮风格：圆角中等按钮，主操作实色，次要操作描边
- 字体：标题使用 DM Sans Bold，正文使用 DM Sans Regular
- 布局风格：左侧导航栏 + 右侧内容区，卡片式列表
- 图标风格：Lucide 线性图标

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 登录页 | 角色卡片 | 三列卡片布局，每卡片含角色图标+角色名，hover时上浮+阴影 |
| 工作台 | 待办列表 | 表格式列表，行状态色标（蓝待办/橙退回/绿完成/红终止） |
| 工作台 | 操作面板 | 右侧滑出抽屉，含表单与提交按钮 |
| 记录详情 | 时间线 | 纵向时间线，每节点含操作人、时间戳、备注内容 |
| 数据管理 | 操作区 | 顶部工具栏含"批量通过""批量退回""重置数据"按钮 |

### 4.3 响应式

桌面优先设计，左侧固定导航 + 右侧自适应内容区。移动端导航折叠为汉堡菜单。
