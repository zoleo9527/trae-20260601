# 蓝领招聘平台 - 返费结算与异常申诉工作台 PRD

## 1. 产品概述

蓝领招聘平台返费结算与异常申诉工作台是一个面向运营、招聘顾问、企业HR三类角色的业务处理系统。系统解决返费结算与异常申诉之间的责任界定不清问题，通过岗位发布、面试名单、入职回执等关键节点数据兜底，实现返费结算到异常申诉的自然衔接，支持连续处理工作流，提升业务处理效率。

**核心价值**：
- 三类角色入口分离，权限清晰，避免操作混乱
- 返费结算完成后自动触发异常申诉流程，无需人工提醒
- 业务工作台支持本地流转、连续处理、历史回看，提升处理效率
- 完整的历史备注和操作记录，责任可追溯

## 2. 核心功能

### 2.1 用户角色

| 角色 | 入口方式 | 核心权限 |
|------|---------|---------|
| 运营 | 独立运营工作台入口 | 全局数据查看、返费结算审核、异常申诉仲裁、数据导出 |
| 招聘顾问 | 招聘顾问工作台入口 | 岗位发布管理、面试名单维护、入职回执上传、返费结算发起、异常申诉处理 |
| 企业HR | 企业HR工作台入口 | 岗位需求发布、面试确认、入职确认、返费结算确认、异常申诉发起 |

### 2.2 功能模块

#### 2.2.1 运营工作台
1. **全局监控面板**：实时展示待处理返费结算数量、待处理异常申诉数量、本月结算金额统计
2. **返费结算审核**：查看所有待审核的返费结算申请，支持批量审核、单独审核
3. **异常申诉仲裁**：处理招聘顾问与企业HR之间的争议申诉，查看完整历史备注
4. **数据统计报表**：按时间、岗位、招聘顾问等维度导出数据

#### 2.2.2 招聘顾问工作台
1. **岗位管理**：发布岗位、编辑岗位信息、查看岗位状态
2. **面试名单管理**：添加面试候选人、更新面试状态、上传面试记录
3. **入职回执管理**：上传入职回执文件、关联候选人信息
4. **返费结算处理**：发起返费结算申请、查看结算状态、处理异常情况
5. **异常申诉处理**：查看企业HR发起的申诉、补充说明材料、查看处理结果

#### 2.2.3 企业HR工作台
1. **岗位需求发布**：提交岗位需求、查看岗位发布状态
2. **面试确认**：确认面试名单、反馈面试结果
3. **入职确认**：确认入职信息、上传入职证明
4. **返费结算确认**：确认返费金额、签署结算单
5. **异常申诉发起**：对返费结算有异议时发起申诉、上传证据材料

## 3. 核心流程

### 3.1 返费结算主流程

招聘顾问发起返费结算申请 → 企业HR确认返费金额 → 运营审核结算单 → 结算完成 → 自动触发异常申诉窗口期（如有异议）

### 3.2 异常申诉流程

企业HR对结算有异议 → 发起异常申诉 → 招聘顾问补充说明 → 运营仲裁 → 申诉处理完成 → 更新结算状态

## 4. 用户界面设计

### 4.1 设计风格

**整体风格**：专业业务工作台风格，注重信息密度和操作效率

**色彩方案**：
- 主色调：深蓝色系（#1E40AF - #3B82F6），体现专业性和信任感
- 辅助色：橙色（#F59E0B）用于警示和重要操作，绿色（#10B981）用于成功状态
- 中性色：灰色系（#F3F4F6 - #111827）用于背景和文字

**按钮风格**：
- 主要操作：圆角矩形按钮，填充主色调，悬停时加深
- 次要操作：圆角矩形按钮，描边样式，悬停时填充浅色背景
- 危险操作：圆角矩形按钮，填充红色，悬停时加深

**字体**：
- 标题字体：思源黑体（Source Han Sans），粗体，18-24px
- 正文字体：思源黑体，常规，14-16px
- 数据字体：Roboto Mono，用于数字展示

**布局风格**：
- 左侧固定导航栏，宽度240px
- 顶部工具栏，高度64px
- 主内容区域，采用卡片式布局
- 表格采用斑马纹样式，提升可读性

**图标风格**：
- 线性图标，2px线宽
- 统一圆角风格
- 配合文字标签使用

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|---------|---------|--------|
| 登录页 | 角色选择 | 三列卡片布局，每个角色一张卡片，包含角色图标、角色名称、登录表单 |
| 运营工作台首页 | 数据概览 | 顶部统计卡片（待审核结算、待仲裁申诉、本月结算金额），中部趋势图，底部待处理任务列表 |
| 运营工作台-返费结算详情 | 结算详情 | 左侧结算单信息卡片，右侧操作面板，底部历史备注时间线，支持连续处理下一个 |
| 运营工作台-异常申诉详情 | 申诉详情 | 左侧申诉信息卡片，中部双方证据材料对比，右侧仲裁操作面板，底部历史备注时间线 |
| 招聘顾问工作台-返费结算详情 | 结算详情 | 顶部岗位信息，中部候选人列表，底部结算申请表单，右侧历史备注面板 |
| 招聘顾问工作台-异常申诉详情 | 申诉详情 | 左侧申诉详情，右侧补充说明表单，底部历史备注时间线 |
| 企业HR工作台-返费结算详情 | 结算详情 | 左侧结算单信息，右侧确认操作面板，底部签署结算单按钮 |
| 企业HR工作台-异常申诉详情 | 申诉详情 | 左侧申诉详情，右侧上传证据材料面板，底部历史备注时间线 |

### 4.3 响应式设计

- 桌面优先设计，最小支持1366px宽度
- 在1440px以上宽度时，主内容区域采用三列布局
- 在1366px-1440px宽度时，主内容区域采用两列布局
- 表格支持横向滚动，固定首列

### 4.4 交互设计

**连续处理机制**：
- 详情页底部固定"处理下一个"按钮，点击后自动跳转到下一个待处理任务
- 处理完成后，页面顶部显示成功提示，3秒后自动跳转
- 支持键盘快捷键：Enter确认，Esc取消

**历史备注时间线**：
- 垂直时间线布局，左侧显示时间，右侧显示备注内容
- 不同角色用不同颜色标识：运营（蓝色）、招聘顾问（绿色）、企业HR（橙色）
- 支持展开/收起长备注

**本地流转提示**：
- 页面顶部显示当前任务流转状态
- 使用进度条展示当前处于流程的哪个环节
- 每个环节显示负责人和处理时间
