## 1. 产品概述

酒店客房部退房查房与迷你吧核对系统，解决房态板、布草记录与维修单之间缺少交接、退房查房与迷你吧核对责任不清导致的拖尾问题。面向客房主管、保洁员、工程师三类角色，提供从退房查房到迷你吧核对的无缝衔接主链路。

- 目标用户：酒店客房部一线人员（主管、保洁员、工程师）
- 核心价值：消除退房查房→迷你吧核对之间的责任真空，确保房态、布草、维修三类记录实时同步，断网/重开不丢状态

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 客房主管 | 登录页选择"主管"入口 | 查看全局房态板、分配查房任务、审核迷你吧异常、查阅布草/维修交接记录 |
| 保洁员 | 登录页选择"保洁员"入口 | 接收查房任务、执行退房查房、填写布草记录、触发迷你吧核对 |
| 工程师 | 登录页选择"工程师"入口 | 接收维修单、标记维修状态、关联退房查房记录 |

### 2.2 功能模块

1. **角色选择页**: 三角色独立入口，登录后进入各自工作台
2. **主管工作台**: 全局房态看板、任务分配面板、迷你吧异常审核、布草/维修交接总览
3. **保洁员工作台**: 待查房列表、退房查房表单、布草记录填写、迷你吧核对入口
4. **工程师工作台**: 待处理维修单列表、维修状态更新、维修与查房关联
5. **退房查房页**: 逐项检查表单(设施/卫生/布草/迷你吧初查)、问题上报、自动触发下一环节
6. **迷你吧核对页**: 消费品逐项核对、快捷筛选(按房号/状态/日期)、异常高亮提示、回看历史核对记录

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 角色选择页 | 角色卡片 | 三张角色卡片，点击进入对应工作台；支持记住上次角色 |
| 主管工作台 | 房态看板 | 颜色编码展示所有房间状态(空脏/空净/住客/查房中/维修中) |

| 主管工作台 | 异常审核 | 迷你吧异常单列表，可逐条确认或驳回 |
| 主管工作台 | 交接总览 | 布草记录与维修单的聚合视图，按时间线排列 |
| 保洁员工作台 | 待查房列表 | 已分配给当前保洁员的退房任务，按紧急度排序 |
| 保洁员工作台 | 布草记录 | 查房时同步填写布草更换/缺失情况 |
| 工程师工作台 | 维修单列表 | 待处理/处理中维修单，可按区域筛选 |

| 退房查房页 | 交接触发 | 查房完成一键提交，自动将迷你吧核对任务推给保洁员(不靠消息提醒) |

## 3. 核心流程

退房查房主链路：客人退房 → 前台标记退房 → 房态板更新为"空脏" → 主管分配查房任务给保洁员 → 保洁员执行查房(逐项检查+布草记录+问题上报) → 查房完成自动触发迷你吧核对 → 保洁员逐项核对迷你吧消费品 → 发现异常自动标记并推送主管审核 → 主管审核异常 → 房态更新为"空净"(或"维修中")。

维修交接支线：查房发现设施问题 → 自动生成维修单 → 工程师接收维修单 → 维修完成更新状态 → 房态从"维修中"恢复。

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深靛蓝(#1E3A5F)作为品牌色，搭配暖琥珀(#D4A853)作为强调色
- 辅助色：状态色——空脏(灰)、空净(绿)、住客(蓝)、查房中(橙)、维修中(红)、迷你吧异常(琥珀闪烁)
- 按钮风格：圆角矩形(8px)，主按钮实色填充，次按钮描边
- 字体：标题用 Noto Serif SC(衬线)，正文用 Noto Sans SC(无衬线)
- 布局：左侧固定导航栏(角色专属菜单)，右侧主内容区
- 图标风格：线性图标(lucide-react)，统一24px网格

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI要素 |
|----------|----------|--------|
| 角色选择页 | 角色卡片 | 三列等宽卡片，每张带角色图标+名称+简述，hover微上浮+阴影加深 |
| 主管工作台 | 房态看板 | 网格布局房间卡片，颜色编码状态，点击展开详情侧滑面板 |
| 保洁员工作台 | 待查房列表 | 紧凑列表卡片，左侧色条标识紧急度，右侧操作按钮 |
| 工程师工作台 | 维修单列表 | 双栏布局(待处理/处理中)，卡片含房号+问题描述+优先级标签 |
| 退房查房页 | 逐项检查 | 四个可折叠分区，每区含勾选列表，底部固定操作栏(保存草稿/提交) |
| 迷你吧核对页 | 逐项核对 | 商品列表(图标+名称+数量输入)，底部汇总栏，异常项红色高亮 |

### 4.3 响应式

- 桌面优先设计，最小宽度1024px
- 平板适配：导航栏收缩为图标模式
- 不做手机端适配(酒店一线人员使用平板或桌面设备)
