## 1. 产品概述

滑雪场救援处置与保险材料管理系统，解决救援处置与保险理赔之间责任不清、信息断裂的问题。通过责任人和时间线切入，确保一线处理与管理回看基于同一份数据，救援处置备注能被保险材料继续使用，全流程可追溯。

- 目标用户：滑雪场一线救援人员、运营管理员、保险对接专员
- 核心价值：消除救援处置到保险理赔之间的信息断层，实现从"谁在什么时候做了什么"到"为什么这样做"的完整链路

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 一线救援员 | 工号登录 | 创建/处理救援事件、添加处置备注 |
| 运营管理员 | 工号登录 | 查看全部事件、状态流转审批、导出报表 |
| 保险专员 | 工号登录 | 查看保险材料、关联救援备注、生成理赔文档 |

### 2.2 功能模块

1. **事件总览页**：救援事件看板、状态分布统计、责任人快速筛选
2. **事件详情页**：时间线、处置备注流、状态流转记录、关联信息追溯
3. **救援处置处理页**：处置操作、状态推进、备注录入（备注可被保险模块引用）
4. **保险材料页**：关联救援记录、备注回看、材料状态管理

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 事件总览页 | 状态看板 | 按状态（待处理/处置中/待审核/已完成/已归档）分组展示事件卡片 |
| 事件总览页 | 责任人筛选 | 按责任人快速过滤，展示当前负责的活跃事件 |
| 事件总览页 | 统计概览 | 今日救援数、处置中数量、待保险材料数 |
| 事件详情页 | 时间线 | 按时间倒序展示所有操作记录、备注、状态变更 |
| 事件详情页 | 处置备注流 | 带分类标签的备注列表（救援/医疗/保险/异常），可展开详情 |
| 事件详情页 | 状态流转 | 展示当前状态及可执行的状态流转操作 |
| 事件详情页 | 基础信息 | 事件编号、类型、地点、伤者信息、责任人 |
| 救援处置处理页 | 处置操作 | 状态推进（待处理→处置中→待审核→已完成→已归档） |
| 救援处置处理页 | 备注录入 | 添加处置备注，选择分类标签，备注自动带责任人+时间戳 |
| 救援处置处理页 | 操作日志 | 记录每次状态变更和操作详情 |
| 保险材料页 | 材料列表 | 关联事件的保险材料清单及状态 |
| 保险材料页 | 备注回看 | 引用救援处置时的备注，标注来源和责任人 |
| 保险材料页 | 异常说明 | 记录保险与救援之间的差异说明 |

## 3. 核心流程

用户从事件总览页发现待处理事件 → 进入事件详情页查看时间线和历史备注 → 点击处理进入救援处置页 → 录入处置备注并推进状态 → 状态流转自动记录操作日志 → 保险专员在保险材料页看到救援备注 → 补充异常说明 → 归档完成。

```mermaid
    "录入处置备注" --> "推进状态流转"
    "推进状态流转" --> "自动记录操作日志"
    "自动记录操作日志" --> "保险材料回看"
    "保险材料回看" --> "引用救援备注"
    "引用救援备注" --> "补充异常说明"
    "补充异常说明" --> "归档完成"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：冷白蓝灰（#F0F4F8 底色）+ 冰蓝强调色（#0EA5E9）+ 警示红（#EF4444）
- 按钮风格：圆角8px，状态按钮带左侧色条标识
- 字体：思源黑体/Noto Sans SC，正文14px，标题18-24px
- 布局风格：左侧导航栏 + 右侧内容区，卡片式布局
- 图标风格：线性图标（Lucide），简洁专业

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 事件总览页 | 状态看板 | 顶部统计卡片、状态标签色条、卡片网格布局 |
| 事件总览页 | 筛选区 | 责任人下拉、状态筛选、日期范围、搜索框 |
| 事件详情页 | 时间线 | 左侧时间轴竖线+圆点、右侧内容卡片、分类标签色块 |
| 事件详情页 | 状态流转 | 水平步骤条、当前步骤高亮、可点击下一步 |
| 事件详情页 | 备注流 | 卡片列表、分类标签、展开/收起 |
| 救援处置处理页 | 处置表单 | 备注文本框+分类选择、状态按钮组、操作确认弹窗 |
| 保险材料页 | 材料列表 | 表格布局、引用标注、状态徽章 |

### 4.3 响应式

桌面优先设计，支持1280px以上屏幕。关键操作区域固定在视口内。
