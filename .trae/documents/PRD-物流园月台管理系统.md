## 1. 产品概述

物流园月台管理系统，解决卸货签到与差异登记的责任不清问题，替代传统到车计划、月台白板和司机电话反复确认的工作方式。

- 核心目标：让调度员、叉车班长、仓库文员各自看到自己的待办，全流程数据留痕，责任清晰
- 目标用户：物流园调度员、叉车班长、仓库文员、司机

## 2. 核心功能

### 2.1 用户角色

| 角色 | 核心权限 | 待办关注 |
|------|----------|----------|
| 调度员 | 创建到车计划、分配月台、查看全局状态 | 待分配月台的车辆、超时未签到的车辆 |
| 叉车班长 | 确认卸货签到、处理卸货中异常 | 待开始卸货的任务、卸货中的任务 |
| 仓库文员 | 差异登记、确认收货、查看历史记录 | 待登记差异的任务、待确认的差异记录 |

### 2.2 功能模块

1. **首页仪表盘**：待办事项列表 + 最近状态变化时间线
2. **到车计划与月台看板**：车辆计划录入、月台分配、月台状态可视化
3. **卸货签到处理**：司机/叉车班长签到、开始/结束卸货记录
4. **差异登记**：数量差异、破损登记、退回原因、补充备注（与签到同一条记录）
5. **历史记录与回看**：按条件查询、操作日志全链路追踪
6. **批量处理**：批量分配月台、批量确认签到

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|
| 首页仪表盘 | 待办卡片组 | 按角色显示待处理事项数量及列表，点击直达处理 |
| 首页仪表盘 | 状态时间线 | 最近24小时关键状态变化，可展开查看详情 |
| 月台看板 | 月台状态图 | 10个月台可视化，显示当前车辆、状态、预计结束时间 |
| 月台看板 | 到车计划列表 | 今日计划车辆，可拖拽分配到月台 |
| 卸货签到页 | 签到表单 | 车牌号、司机姓名、联系电话、货品类型、件数、签到时间 |
| 卸货签到页 | 状态流转 | 待签到 → 卸货中 → 卸货完成 → 差异登记中 → 已完成 |
| 差异登记页 | 差异表单 | 差异类型（数量/破损/其他）、差异数量、退回原因、照片上传、补充备注 |
| 历史记录页 | 查询筛选 | 按时间、车牌号、状态、处理人筛选 |
| 历史记录页 | 记录详情 | 全链路操作日志，每条记录包含签到+差异完整信息 |
| 历史记录页 | 批量操作 | 批量导出、批量标记完成 |

## 3. 核心流程

### 3.1 主流程

```mermaid
flowchart LR
    A["调度员创建到车计划"] --> B["分配月台"]
    B --> C["司机到达签到"]
    C --> D["叉车班长确认开始卸货"]
    D --> E["卸货完成"]
    E --> F{"有无差异?"}
    F -->|无差异| G["仓库文员确认完成"]
    F -->|有差异| H["仓库文员登记差异"]
    H --> I["填写退回原因+备注"]
    I --> G
    G --> J["记录归档，生成操作日志"]
```

### 3.2 一条记录的数据结构

每条卸货记录包含：
- 基础信息：车牌号、司机、电话、货品、计划件数
- 签到信息：签到时间、签到人、月台号、实际开始时间、结束时间
- 差异信息：差异类型、差异数量、实收数量、退回原因、补充备注、照片
- 操作日志：每个状态节点的操作人、操作时间、IP

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：工业蓝（#1e40af）+ 警示橙（#f97316）+ 成功绿（#10b981）
- **辅助色**：深灰背景（#0f172a），适合仓库/工业场景，长时间使用不刺眼
- **按钮风格**：直角微圆角（4px），实心按钮为主，强调工业感
- **字体**：Inter 无衬线，清晰易读，数字等宽
- **布局**：顶部导航 + 左侧角色待办 + 主内容区卡片式布局
- **图标**：Lucide 线性图标，统一粗细

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|-----------|-------------|----------|
| 首页仪表盘 | 待办卡片组 | 3色卡片（蓝/橙/绿），数字醒目，悬停上浮效果 |
| 首页仪表盘 | 时间线 | 左侧竖线时间轴，节点带颜色状态标记 |
| 月台看板 | 月台网格 | 10个月台卡片网格，颜色表示状态（空闲/使用中/异常） |
| 签到/差异表单 | 表单区域 | 左侧表单输入，右侧实时预览记录卡片 |
| 历史记录 | 数据表格 | 斑马纹，行悬停高亮，可展开行内详情 |

### 4.3 响应式
- 桌面端优先（1280px+），适配调度室大屏
- 平板端：侧边栏可折叠，表格横向滚动
- 移动端：卡片式布局，适合司机手机签到

### 4.4 动效设计
- 状态变化：数字跳动动画 + 背景色闪烁提示
- 卡片悬停：轻微上浮 + 阴影加深
- 页面切换：淡入淡出 + 轻微位移
- 表单提交：按钮loading状态 + 成功反馈动效
