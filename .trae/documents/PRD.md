## 1. 产品概述

人力派遣公司入场培训与证件收集管理系统——解决临时缺岗发现晚、考勤争议说不清、工资扣款无据可查、入场培训到证件收集之间无人负责等问题。系统将状态变化、责任人、时间点和备注全部写入数据，让招聘专员、驻场主管、薪酬会计看到的信息口径一致，减少翻群记录的需求。

- 目标用户：人力派遣公司的招聘专员、驻场主管、薪酬会计
- 核心价值：把旧台账、现场记录和沟通截图中的关键问题提前标出，让入场培训备注能被证件收集继续使用，消除流程空档

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 招聘专员 | 角色切换选择 | 管理入场培训处理、批量分配培训、查看培训状态 |
| 驻场主管 | 角色切换选择 | 管理证件收集、确认到岗情况、标记缺岗/考勤异常 |
| 薪酬会计 | 角色切换选择 | 查看培训与证件状态、核对扣款依据、导出数据 |

### 2.2 功能模块

1. **仪表盘页面**：状态概览、风险预警（临时缺岗/考勤争议/工资扣款不清）、各阶段人员统计
2. **入场培训页面**：培训记录处理、批量操作、培训备注（可传递至证件收集）、状态流转
3. **证件收集页面**：证件收集回看、关联培训备注、收集状态管理、缺证提醒
4. **人员详情页面**：单人完整时间线（状态变化+责任人+时间点+备注）、数据重置

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 仪表盘 | 风险预警卡片 | 临时缺岗、考勤争议、工资扣款不清三项预警，显示数量和最新案例 |
| 仪表盘 | 流程概览 | 按状态统计人数：待培训→培训中→待收集证件→证件收集中→已完成 |
| 仪表盘 | 责任空档检测 | 检测入场培训完成但未进入证件收集的人员，标红提示 |
| 入场培训 | 培训列表 | 可筛选、搜索、按状态/日期/负责人分组查看 |
| 入场培训 | 培训处理 | 填写培训结果、备注（备注字段将传递至证件收集阶段） |
| 入场培训 | 批量处理 | 选中多人批量更新培训状态、批量分配负责人 |
| 证件收集 | 收集列表 | 显示证件收集状态，可回看关联的培训备注 |
| 证件收集 | 收集操作 | 逐人确认证件，显示从培训阶段传递的备注 |
| 证件收集 | 缺证预警 | 未按时提交证件的人员高亮显示 |
| 人员详情 | 状态时间线 | 完整记录每步状态变化、操作人、时间、备注 |
| 人员详情 | 数据重置 | 可重置单人的流程状态（需记录重置操作人和原因） |

## 3. 核心流程

用户打开系统→选择角色视角→查看仪表盘风险预警→进入入场培训页面处理培训→培训完成自动流转至证件收集→驻场主管在证件收集页面继续处理（可看到培训备注）→薪酬会计查看全流程状态核对扣款依据。全程状态口径一致，每步有明确责任人，无空档。

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深青蓝 (#0F4C5C) 代表专业和可靠，辅助色：琥珀橙 (#E36414) 用于预警和提醒
- 按钮风格：圆角（8px）、适度阴影、状态色明确
- 字体：思源黑体 / Noto Sans SC，正文 14px，小标题 16px，大标题 24px
- 布局风格：左侧导航栏 + 主内容区，卡片式布局，表格式列表
- 图标风格：线性图标，统一 20px 尺寸

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 仪表盘 | 风险预警卡片 | 三列卡片，各带图标和计数，点击可展开案例列表 |
| 仪表盘 | 流程概览 | 横向流程条，每步显示人数气泡，颜色渐变表示进度 |
| 仪表盘 | 责任空档检测 | 红色边框卡片，列出空档人员，一键分配按钮 |
| 入场培训 | 培训列表 | 表格布局，状态标签带颜色，行内操作按钮 |
| 入场培训 | 培训处理 | 侧滑抽屉，表单字段含备注文本域，备注旁提示"此备注将传递至证件收集" |
| 入场培训 | 批量处理 | 顶部批量操作栏，勾选后显示，支持批量状态更新和负责人分配 |
| 证件收集 | 收集列表 | 表格布局，关联培训备注以折叠行显示 |
| 证件收集 | 缺证预警 | 行高亮+图标标记，超期天数显示 |
| 人员详情 | 状态时间线 | 竖向时间线组件，每节点含状态/责任人/时间/备注 |
| 人员详情 | 数据重置 | 确认对话框，需填写重置原因，重置记录写入时间线 |

### 4.3 响应式设计

桌面优先设计，适配 1280px+ 宽度。在较小屏幕下表格改为卡片列表，侧滑抽屉改为全屏模态。
