# 家政服务公司 - 过程反馈与加项记录管理系统

## 1. 产品概述

本系统旨在解决家政服务公司在过程反馈与加项记录管理中"卡单"问题发现滞后的问题。通过实时监控、异常预警和责任追踪，让管理者能够第一时间发现并处理卡住的单子，而不是等到阿姨档案、订单排班或客户评价时才暴露问题。

**核心价值**：从"事后发现"转变为"实时暴露"，让客服、家政员、质检主管的处理进度透明可见，过程反馈卡点和加项记录延误原因一目了然。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 核心权限 |
|------|----------|
| 客服 | 处理过程反馈、创建加项记录、查看订单状态 |
| 家政员 | 提交过程反馈、确认加项记录 |
| 质检主管 | 审核过程反馈、批准加项记录、处理异常 |
| 系统管理员 | 查看所有数据、重置模拟数据、配置系统参数 |

### 2.2 功能模块

1. **监控看板页面**：实时展示所有订单状态，高亮显示卡住的单子
2. **过程反馈管理页面**：处理过程反馈流，追踪处理进度
3. **加项记录管理页面**：管理加项记录的创建、审核、完成流程
4. **异常处理抽屉**：快速处理卡住的订单，记录处理原因

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 监控看板 | 卡单预警面板 | 实时展示卡住的订单，按紧急程度排序 |
| 监控看板 | 处理人追踪面板 | 显示每个卡单的处理人（客服/家政员/质检主管） |

## 3. 核心流程

### 3.1 卡单发现与处理流程

系统自动监控订单状态，当订单在某个状态停留超过阈值时间时，自动标记为"卡单"并推送到监控看板。处理人收到通知后，通过异常处理抽屉快速处理。

    "推送到监控看板" --> "处理人收到通知"

    "查看卡单详情" --> "选择处理方式"
    "选择处理方式" -->|"驳回"| "记录驳回原因"
    "选择处理方式" -->|"补录"| "补录信息"

    "转交其他处理人" --> "新处理人收到通知"

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝色系（#1E3A8A）作为主色，橙色（#F97316）作为警示色，绿色（#10B981）作为成功色
- **按钮风格**：圆角按钮，主要操作使用实心填充，次要操作使用边框样式
- **字体**：使用思源黑体（Noto Sans SC）作为主字体，标题使用较大字号加粗
- **布局风格**：左侧固定导航栏，右侧内容区域采用卡片式布局
- **图标风格**：使用线性图标，保持简洁清晰

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|---------|---------|--------|
| 监控看板 | 卡单预警面板 | 红色高亮卡片，显示卡单数量、紧急程度、处理人信息 |
| 监控看板 | 处理人追踪面板 | 头像+姓名+角色标签，实时在线状态指示器 |
| 监控看板 | 状态流转时间线 | 垂直时间线，每个节点显示状态、时间、处理人 |
| 过程反馈管理 | 反馈列表 | 表格布局，支持排序筛选，状态标签彩色区分 |
| 过程反馈管理 | 处理进度追踪 | 进度条+步骤指示器，当前步骤高亮显示 |
| 过程反馈管理 | 驳回/补录处理 | 模态框形式，包含表单字段和操作按钮 |
| 加项记录管理 | 记录列表 | 表格布局，完成状态用图标标识 |
| 加项记录管理 | 未完成原因分析 | 统计图表+原因分类标签 |
| 加项记录管理 | 回看功能 | 时间轴展示历史处理记录 |
| 异常处理抽屉 | 快速处理面板 | 右侧抽屉，包含订单详情和处理表单 |
| 异常处理抽屉 | 处理历史 | 折叠面板，按时间倒序展示 |

### 4.3 响应式设计

- 采用桌面优先设计，主要在PC端使用
- 支持平板端适配，导航栏可折叠
- 移动端提供简化版视图，核心功能可用

### 4.4 交互设计

- 卡单预警使用闪烁动画和声音提示
- 状态变更使用平滑过渡动画
- 表格行悬停高亮显示
- 抽屉滑入滑出动画
- 加载状态使用骨架屏

## 5. 非功能性需求

### 5.1 性能要求

- 页面加载时间 < 2秒
- 数据刷新间隔可配置（默认30秒）
- 支持至少1000条订单同时监控

### 5.2 数据模拟说明

以下能力为模拟实现：
- 用户登录认证（使用模拟用户数据）
- 实时推送通知（使用定时轮询模拟）
- 数据持久化（使用localStorage存储）
- 后端API（使用Mock数据）

### 5.3 数据重置

系统提供数据重置功能，可将所有模拟数据恢复到初始状态，方便测试和演示。
