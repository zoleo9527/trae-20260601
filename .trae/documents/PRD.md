# 会计代账公司换人交接与续约风险管理系统 - 产品需求文档

## 1. 产品概述

本系统旨在解决会计代账公司在客户经理或会计人员变动后出现的信息断层问题。通过数字化交接清单、风险标签管理和续约跟进功能，确保客户服务连续性，降低续约风险，提升客户满意度。

**核心价值**：
- 消除人员变动带来的信息断层，确保客户历史问题可追溯
- 通过风险标签提前预警续约风险，主动干预
- 建立标准化的交接流程，提升交接效率和质量

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|---------|---------|
| 会计 | 管理员创建 | 整理账务、填写交接清单、查看分配客户 |
| 客户经理 | 管理员创建 | 补充沟通记录、续约跟进、查看分配客户 |
| 主管 | 管理员创建 | 判断续约风险、审批交接、查看所有客户、数据统计 |
| 系统管理员 | 系统初始化 | 用户管理、系统配置、数据备份 |

### 2.2 功能模块

1. **客户管理页面**：客户列表、客户详情、交接记录、风险标签
2. **交接管理页面**：交接清单填写、交接历史查询、待办事项提醒
3. **续约跟进页面**：到期预警、续约跟进记录、风险客户列表
4. **历史备注查询页面**：备注搜索、时间线查看、多维度筛选

## 3. 核心流程

### 3.1 交接流程

当客户经理或会计离职时，系统触发交接流程：
1. 系统自动创建交接任务，通知相关人员
2. 前任会计整理账务注意事项，填写交接清单
3. 前任客户经理补充沟通记录和客户习惯
4. 主管审核交接清单，判断续约风险
5. 新接手人员确认接收，系统更新客户负责人
6. 所有交接信息归档，支持历史查询

### 3.2 续约跟进流程

系统定期扫描客户到期时间，自动预警：
1. 系统自动标记临近到期客户（30/60/90天）
2. 客户经理查看风险标签，制定跟进策略
3. 记录每次续约沟通，更新客户状态
4. 主管审核高风险客户，决定干预措施
5. 续约成功或失败后，更新客户状态和风险标签

## 4. 用户界面设计

### 4.1 设计风格

**主题定位**：专业、高效、可信赖的企业管理系统

**配色方案**：
- 主色调：深蓝色 (#1e40af) - 专业、稳重
- 辅助色：浅灰色 (#f3f4f6) - 清爽、现代
- 强调色：橙色 (#f97316) - 警示、提醒
- 成功色：绿色 (#10b981) - 完成、正常
- 危险色：红色 (#ef4444) - 风险、紧急

**字体**：
- 标题：思源黑体 / Noto Sans SC（粗体）
- 正文：思源黑体 / Noto Sans SC（常规）
- 数字：Roboto Mono（用于数据展示）

**布局风格**：
- 左侧固定导航栏
- 顶部状态栏（用户信息、通知、搜索）
- 卡片式内容区域
- 响应式设计，支持桌面和平板

**图标风格**：
- 使用 Heroicons 或 Lucide Icons
- 线性图标为主，保持简洁专业

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|---------|---------|--------|
| 客户管理 | 客户列表 | 表格布局、筛选器、搜索框、风险标签徽章、到期倒计时 |
| 客户管理 | 客户详情 | 信息卡片、时间线、标签云、操作按钮组 |
| 交接管理 | 交接清单 | 表单布局、分步骤引导、必填项提示、附件上传区 |
| 交接管理 | 交接审核 | 对比视图、审核意见框、通过/驳回按钮 |
| 续约跟进 | 到期预警 | 卡片网格、倒计时显示、风险等级标识、快捷操作按钮 |
| 续约跟进 | 风险客户 | 列表视图、风险原因标签、跟进记录时间线 |
| 历史备注 | 备注搜索 | 搜索栏、筛选面板、结果列表、高亮关键词 |
| 历史备注 | 时间线 | 垂直时间线、事件节点、展开详情、筛选器 |

### 4.3 响应式设计

- **桌面优先**：主要在桌面端使用，优化大屏幕体验
- **平板适配**：支持iPad等平板设备，导航栏可折叠
- **触控优化**：按钮和交互元素尺寸适合触控操作

### 4.4 交互细节

**风险标签系统**：
- 🔴 高风险：红色徽章，显示具体风险原因
- 🟡 中风险：黄色徽章，需要关注
- 🟢 低风险：绿色徽章，正常状态
- ⚪ 无风险：灰色徽章，新客户或已续约

**交接清单模板**：
1. 未完事项（必填）
   - 待处理发票
   - 待申报税种
   - 待核对账目
   - 其他待办事项

2. 客户习惯（必填）
   - 沟通偏好（电话/微信/邮件）
   - 最佳联系时间
   - 特殊要求
   - 注意事项

3. 发票口径（必填）
   - 发票类型
   - 开票频率
   - 特殊开票要求
   - 历史问题记录

4. 下次申报提醒（必填）
   - 申报税种
   - 申报截止日期
   - 申报注意事项
   - 相关附件

**续约跟进提醒**：
- 系统自动发送邮件/站内信提醒
- 支持设置自定义提醒时间
- 跟进记录支持添加附件（沟通截图、邮件往来等）

## 5. 数据需求

### 5.1 样例数据场景

系统需预置以下样例数据，便于演示和测试：

**场景1：客户临近到期**
- 客户名称：北京科技有限公司
- 当前状态：合同将于30天后到期
- 风险标签：🟡 中风险（临近到期）
- 前任负责人：张会计（在职）
- 交接状态：无需交接
- 跟进记录：客户经理已联系，客户表示有意续约，正在商谈价格

**场景2：前任离职**
- 客户名称：上海贸易有限公司
- 当前状态：正常服务中
- 风险标签：🔴 高风险（前任离职、资料不齐）
- 前任负责人：李会计（已离职）
- 新负责人：王会计
- 交接状态：已完成交接，但交接清单显示资料长期不齐
- 交接清单摘要：
  - 未完事项：2024年Q1季度报表未核对
  - 客户习惯：偏好微信沟通，下午2-4点最佳
  - 发票口径：每月15号前开票，需要提前通知
  - 下次申报提醒：增值税申报截止6月20日

**场景3：资料长期不齐**
- 客户名称：广州制造有限公司
- 当前状态：服务暂停
- 风险标签：🔴 高风险（资料不齐、客户失联）
- 前任负责人：赵客户经理（在职）
- 交接状态：多次交接，资料始终不齐
- 交接清单摘要：
  - 未完事项：缺少2023年全年银行流水、缺少成本发票
  - 客户习惯：电话经常无人接听，微信回复慢
  - 发票口径：开票金额与实际业务不符，需要调整
  - 下次申报提醒：已逾期，需要补申报

### 5.2 数据统计需求

- 交接完成率统计（按月/季度）
- 续约成功率统计（按客户经理）
- 风险客户占比统计
- 平均交接时长统计
- 客户满意度统计（可选）

## 6. 非功能性需求

### 6.1 性能要求

- 页面加载时间 < 2秒
- 列表查询响应时间 < 1秒
- 支持100+并发用户

### 6.2 安全要求

- 用户登录认证（JWT Token）
- 角色权限控制（RBAC）
- 敏感数据加密存储
- 操作日志记录

### 6.3 可用性要求

- 系统可用性 > 99.5%
- 数据每日自动备份
- 支持数据导出（Excel/PDF）

### 6.4 兼容性要求

- 浏览器：Chrome 90+、Edge 90+、Safari 14+
- 分辨率：最低支持1366x768
- 操作系统：Windows 10+、macOS 11+
