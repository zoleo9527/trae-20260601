# 农家乐经营-食材采购与库存预估 产品需求文档

## 1. 产品概述
农家乐经营管理系统，解决信息散落在包间预订、食材采购和住宿登记中难以整合的问题。系统通过统一的流程管理，让老板、后厨、客房阿姨清晰了解各自职责，追踪食材采购进度，完成库存预估，减少翻群记录的困扰。

- **核心价值**：将分散的经营信息整合成可追溯的流程线，明确责任人和处理状态
- **目标用户**：农家乐经营者、后厨人员、客房服务人员

## 2. 核心功能

### 2.1 用户角色
| 角色 | 权限说明 |
|------|---------|
| 老板 | 查看所有流程、处理异常、审批采购、查看库存预估 |
| 后厨 | 处理食材采购申请、更新采购状态、提交库存需求 |
| 客房阿姨 | 登记住宿信息、查看包间预订、反馈客房物资需求 |

### 2.2 功能模块
1. **首页仪表盘**：流程概览、待办事项、异常提醒、快捷操作
2. **包间预订管理**：预订列表、预订详情、状态流转
3. **食材采购处理**：采购申请、采购审批、采购跟踪、采购历史
4. **住宿登记**：入住登记、退房记录、客房状态
5. **库存预估**：库存盘点、消耗预估、采购建议
6. **异常提醒中心**：异常列表、处理记录、本地通知

## 3. 核心流程

### 3.1 食材采购流程
用户（后厨）提交采购申请 → 老板审批 → 审批通过后进入采购中 → 后厨确认收货 → 更新库存

```mermaid
    "老板审批" -->|"同意"| "采购中"
    "老板审批" -->|"拒绝"| "采购结束（已拒绝）"
    "采购中" --> "后厨确认收货"
    "后厨确认收货" --> "更新库存"
    "更新库存" --> "采购完成"
```

### 3.2 包间预订流程
客户预订 → 确认预订 → 客人到店 → 用餐中 → 结账 → 完成

```mermaid

    "客户预订" --> "确认预订"

    "客人到店" --> "用餐中"
    "用餐中" --> "结账"
```

### 3.3 异常处理流程
系统检测异常 → 记录异常 → 推送通知 → 责任人处理 → 记录处理结果

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：温暖的橙黄色系（#F59E0B）搭配大地色（#92400E），体现农家乐的温馨自然
- **辅助色**：绿色（#10B981）用于成功状态，红色（#EF4444）用于异常提醒
- **按钮风格**：圆角按钮，带有轻微阴影，hover时有提升效果
- **字体**：使用中文字体"思源黑体"或系统默认中文字体，标题加粗
- **布局风格**：卡片式布局，左侧导航栏，右侧内容区
- **图标风格**：使用线性图标，简洁清晰

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|---------|---------|--------|
| 首页仪表盘 | 流程概览 | 4个统计卡片，显示待处理、进行中、已完成、异常数量 |
| 首页仪表盘 | 待办事项 | 列表形式，每项显示标题、处理人、时间，可点击 |
| 首页仪表盘 | 异常提醒 | 红色边框卡片，显示异常标题和简要描述 |
| 首页仪表盘 | 快捷操作 | 4个圆形按钮，图标+文字，hover放大效果 |
| 包间预订 | 预订列表 | 表格形式，支持排序和筛选，状态用标签显示 |
| 包间预订 | 预订详情 | 卡片布局，左侧基本信息，右侧状态流转时间线 |
| 食材采购 | 采购申请 | 表单卡片，下拉选择食材，输入数量，提交按钮 |
| 食材采购 | 采购跟踪 | 进度条显示当前状态，每个节点可点击查看详情 |
| 食材采购 | 采购历史 | 时间线布局，按日期分组，每条记录可展开详情 |
| 库存预估 | 库存盘点 | 表格形式，支持编辑，低库存高亮显示 |
| 库存预估 | 采购建议 | 列表卡片，显示食材名称、建议数量、原因 |

### 4.3 响应式设计
- **桌面优先**：主要在桌面端使用，布局宽度1200px以上
- **移动端适配**：导航栏收起为汉堡菜单，卡片单列显示
- **触摸优化**：按钮和可点击区域至少44px，支持滑动操作

### 4.4 交互设计
- **状态流转可视化**：使用进度条和时间线清晰展示流程状态
- **点击反馈**：所有可点击元素都有hover和active状态
- **本地通知模拟**：使用本地存储记录通知触发，在页面顶部显示通知横幅
- **数据持久化**：使用localStorage存储所有数据，刷新页面不丢失
