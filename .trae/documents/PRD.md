## 1. 产品概述
卫浴安装队漏水返工与责任判定系统，用于管理卫浴安装全流程中的漏水返工处理和责任判定。系统支持安装调度、安装师傅、售后客服三角色协作，确保漏水返工问题能够被及时发现、处理和判定责任，所有驳回和补录操作均有完整记录，便于主管随时追问进度和回看历史。

**核心价值**：
- 解决漏水返工流程中信息断层问题，确保每个环节都有据可查
- 提供异常样例自动触发提醒机制，避免问题遗漏
- 支持主管临时追问进度，实时掌握处理状态

## 2. 核心功能

### 2.1 用户角色
| 角色 | 创建方式 | 核心权限 |
|------|---------|---------|
| 调度员 | 系统预设 | 创建订单、分配师傅、查看进度、追问处理状态 |
| 安装师傅 | 系统预设 | 接单、上传安装照片、标记配件使用、处理返工 |
| 售后客服 | 系统预设 | 发起返工、上传漏水照片、判定责任、查看历史 |

3. **返工处理页**：返工申请、漏水照片、处理跟进、责任判定
4. **历史回看页**：订单筛选、责任判定记录、驳回补录历史

## 3. 核心流程

### 3.1 正常安装流程
调度员创建订单 → 分配师傅 → 师傅接单 → 开始安装 → 上传照片 → 标记配件 → 完成安装

### 3.2 漏水返工流程
售后客服发现漏水 → 上传漏水照片 → 发起返工申请 → 师傅接受返工 → 处理返工 → 上传返工照片 → 完成返工 → 售后客服判定责任 → （可选）驳回补录 → 最终判定

### 3.3 异常处理流程
系统检测异常（超时、漏水、驳回等）→ 自动触发提醒 → 相关角色收到通知 → 主管可追问进度

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：专业蓝色系（#1890FF）作为主色，橙色（#FA8C16）作为警示/异常色，绿色（#52C41A）作为成功色
- **按钮风格**：圆角按钮，主要操作使用填充色，次要操作使用描边样式
- **字体**：使用思源黑体或系统默认中文字体，标题16px，正文14px，辅助文字12px
- **布局风格**：顶部导航栏 + 左侧菜单 + 右侧内容区的经典管理后台布局
- **图标风格**：线性图标，与文字搭配使用，提供清晰的视觉指引

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|---------|---------|--------|
| 调度管理页 | 订单创建 | 表单布局、日期选择器、下拉选择框、提交按钮 |
| 调度管理页 | 师傅分配 | 卡片列表、师傅头像、状态标签、分配按钮 |
| 调度管理页 | 进度看板 | 看板视图、状态列、订单卡片、拖拽排序 |
| 调度管理页 | 异常提醒 | 通知栏、红色警示图标、快速跳转链接 |
| 安装作业页 | 待办列表 | 列表视图、订单卡片、状态标签、操作按钮 |
| 安装作业页 | 安装流程 | 步骤条、照片上传区、配件清单表格、完成按钮 |

### 4.3 响应式设计
- 桌面优先设计，最小宽度1200px
- 移动端适配：保持核心功能可用，简化布局
- 触摸优化：按钮最小44px高度，表格行高适中

### 4.4 异常状态设计
- **漏水提醒**：红色边框卡片 + 警示图标 + 快速操作按钮
- **驳回提醒**：橙色标签 + 驳回原因气泡提示
- **超时提醒**：黄色背景 + 倒计时显示
- **责任待判定**：紫色标签 + 待处理数量角标
