# 小贷公司放款确认与还款计划管理系统 - 产品需求文档

## 1. 产品概述
本系统旨在解决小贷公司业务流程中的数据断层问题，实现借款申请、风控资料、放款确认、还款计划、催收记录之间的无缝交接与追溯。系统确保一线处理与管理回看基于同一数据源，通过完整的状态流转和异常处理机制，避免驳回和补录仅停留在提示文案层面。

**核心价值**：
- 消除业务流程中的数据孤岛，实现全流程数据追溯
- 提供完整的异常处理机制，确保流程闭环
- 支持一线操作与管理回看的统一视图

## 3. 核心流程

### 3.1 放款确认流程
用户提交借款申请后，系统进行风控审核。审核通过后进入放款确认环节，一线操作员可以：
- 确认放款：生成还款计划，状态流转至"已放款"
- 驳回申请：填写驳回原因，申请退回风控环节
- 要求补录：标记缺失资料，通知借款人补充

### 3.2 还款计划管理流程
放款确认后自动生成还款计划，一线操作员可以：
- 查看还款计划详情
- 标记还款异常（逾期、部分还款等）
- 触发催收流程

### 3.3 异常处理流程
当出现异常时（驳回、补录、逾期等），系统：
- 在异常处理抽屉中显示详细信息
- 提供处理选项（退回、提醒、补录）
- 记录处理结果，确保可追溯

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深蓝色系（#1E3A8A）+ 金色强调色（#F59E0B），体现金融行业的专业性和稳重感
- **辅助色**：成功绿（#10B981）、警告橙（#F97316）、错误红（#EF4444）
- **按钮风格**：圆角矩形，轻微阴影，hover时提升阴影层次
- **字体**：标题使用思源黑体（Source Han Sans），正文使用系统默认字体
- **布局风格**：卡片式布局，左侧固定导航栏，右侧内容区
- **图标**：使用Lucide Icons，线条风格，统一尺寸

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|---------|---------|--------|
| 登录页面 | 角色选择卡片 | 白色卡片，居中布局，两个角色按钮，渐变背景 |
| 放款确认页面 | 申请列表 | 表格布局，状态标签使用不同颜色区分，操作按钮右对齐 |
| 放款确认页面 | 状态流转 | 时间线组件，垂直排列，节点使用圆点标记 |
| 还款计划页面 | 计划列表 | 卡片网格布局，每个卡片显示关键信息，支持hover效果 |
| 异常处理抽屉 | 抽屉面板 | 右侧滑出抽屉，半透明遮罩，内容分区块展示 |
| 数据追溯面板 | 时间线视图 | 横向时间线，节点可点击查看详情，连接线使用虚线 |

### 4.3 响应式设计
- **桌面优先**：主要在桌面端使用，优化大屏幕体验
- **移动适配**：支持平板和手机访问，导航栏折叠为汉堡菜单
- **触控优化**：按钮和交互元素尺寸不小于44px，支持触摸手势

## 5. 数据模型

### 5.1 核心实体
1. **借款申请（LoanApplication）**
   - 申请ID、借款人信息、申请金额、申请时间
   - 风控状态、风控审核结果
   - 当前状态（待审核、审核中、已通过、已驳回、已放款）

2. **风控资料（RiskControlDocument）**
   - 资料ID、关联申请ID
   - 资料类型、上传时间、审核状态

3. **放款确认（LoanConfirmation）**
   - 确认ID、关联申请ID
   - 确认时间、确认人、确认结果
   - 驳回原因、补录要求（如有）

4. **还款计划（RepaymentPlan）**
   - 计划ID、关联确认ID
   - 还款期数、每期金额、还款日期
   - 还款状态（待还款、已还款、逾期、部分还款）

5. **催收记录（CollectionRecord）**
   - 记录ID、关联计划ID
   - 催收时间、催收方式、催收结果

6. **异常记录（ExceptionRecord）**
   - 异常ID、关联业务ID、异常类型
   - 异常描述、处理状态、处理结果

### 5.2 状态流转
- **借款申请状态**：PENDING → RISK_REVIEW → APPROVED → CONFIRMED → DISBURSED
- **还款计划状态**：PENDING → PAID → OVERDUE → PARTIAL_PAID
- **异常处理状态**：OPEN → PROCESSING → RESOLVED

## 6. 非功能性需求

### 6.1 性能要求
- 页面加载时间 < 2秒
- 列表查询响应时间 < 500ms
- 支持100+并发用户

### 6.2 安全要求
- 简化的登录验证（演示环境）
- 数据操作日志记录
- 敏感信息脱敏显示

### 6.3 可追溯性要求
- 所有操作记录时间戳和操作人
- 状态变更记录完整历史
- 支持按时间、操作人、业务ID查询历史记录
