# 企业内训部-证书发放与效果评估系统

## 1. 产品概述

### 1.1 产品定位
一个专注于**培训过程管理**而非仅记录结果的企业内训系统。核心解决"培训需求表、讲师排期和签到表只记录结果，不记录为什么变成报名后不来、课后作业没人收、证书发放混乱"这一真实痛点。

### 1.2 核心价值
- **过程追踪**：记录每一个异常状态的原因和处置动作
- **角色协同**：培训经理、部门负责人、讲师各有职责边界和推进节奏
- **效果闭环**：证书发放变更能实时触达效果评估模块

### 1.3 目标用户
- **培训经理**：统筹全局，负责证书最终发放、效果评估汇总
- **部门负责人**：关注本部门培训投入产出，负责报名人员管理
- **讲师**：负责课程执行、作业收集、学员表现记录

## 2. 核心功能模块

### 2.1 培训项目管理

#### 2.1.1 培训需求表
**不仅记录结果，还要记录过程：**
- 需求发起 → 审批通过/驳回（驳回要记录原因）
- 报名阶段 → 实际参训（流失率监控）
- 流失原因追踪：
  - 主动取消（记录员工个人原因）
  - 无故缺席（标记为异常，需部门负责人跟进）
  - 临时替换（记录替换原因）

#### 2.1.2 讲师排期表
**不仅记录排期，还要记录问题：**
- 讲师确认 → 排期锁定
- 课程取消/改期（记录原因：不可抗力/讲师原因/报名人数不足）
- 讲师临时更换（记录原因和接替方案）

#### 2.1.3 签到表
**不仅记录到场，还要记录异常：**
- 正常签到
- 迟到（记录迟到时长）
- 早退（记录早退原因）
- 未到（关联报名流失原因）

### 2.2 证书发放管理

#### 2.2.1 证书发放规则
- 必修课：完课率100% + 课后作业提交 + 考核通过
- 选修课：完课率80% + 考核通过
- 特殊情况：可申请豁免（需培训经理审批）

#### 2.2.2 证书发放流程
```
待发放 → 制作中 → 待审核 → 已发放/已退回
```

#### 2.2.3 证书变更追溯
**关键功能：证书发放被改动后，效果评估要能感知**
- 证书撤回（记录撤回原因：信息错误/违规获取/重复发放）
- 证书补发（记录补发原因：丢失/信息错误）
- 证书作废（记录作废原因：投诉查实/成绩造假）
- **效果评估联动**：上述变更自动触发效果评估模块重新计算

#### 2.2.4 证书发放处理台
- 待处理列表（按紧急程度排序）
- 批量处理（支持Excel导入）
- 历史处理记录（可回看每个证书的完整生命周期）

### 2.3 效果评估模块

#### 2.3.1 评估维度
- **即时评估**：课后满意度调查
- **行为评估**：训后30天技能应用情况
- **结果评估**：培训后的绩效变化

#### 2.3.2 评估触发机制
- 课程结束后自动发送评估问卷
- 证书状态变更时重新计算通过率
- 异常数据自动标记（如某课程通过率突然下降）

#### 2.3.3 效果评估回看
- 支持按课程、部门、讲师、时间段筛选
- 导出详细报告（PDF/Excel）
- 趋势分析图表

### 2.4 异常处理中心

#### 2.4.1 异常类型
1. **报名后不来**
   - 原因分类：个人原因/工作冲突/忘记参加/其他
   - 跟进状态：待跟进/跟进中/已解决
   - 处置动作：取消资格/改期参加/记入考勤异常

2. **课后作业没人收**
   - 未提交名单
   - 迟交记录
   - 催交提醒（自动+手动）
   - 最终处置（影响证书发放）

3. **证书发放混乱**
   - 信息错误（姓名/工号/证书编号）
   - 重复发放
   - 漏发
   - 冒领风险

#### 2.4.2 异常处理流程
```
发现异常 → 标记异常 → 分配处理人 → 处置中 → 已处置
```

## 3. 角色权限与工作台

### 3.1 培训经理
**职责：全局统筹、证书最终审批、效果评估汇总**

#### 工作台功能：
- 今日待办：待审批证书、待处理异常、待评估报告
- 证书发放审核（批量+单个）
- 效果评估报告查看
- 异常处理超时会话提醒
- 证书变更历史（可回看任意证书的完整轨迹）

#### 关键指标：
- 本月证书发放及时率
- 培训效果评分趋势
- 异常处理平均时长

### 3.2 部门负责人
**职责：本部门培训投入产出、人员管理**

#### 工作台功能：
- 本部门培训计划
- 部门员工参训情况
- 报名后取消/缺席人员管理
- 部门培训效果评估
- 催促未完成作业员工

#### 关键指标：
- 部门培训参与率
- 员工培训满意度
- 培训后绩效变化

### 3.3 讲师
**职责：课程执行、作业收集、学员表现**

#### 工作台功能：
- 课程日历
- 学员签到管理
- 作业布置与收集
- 学员表现记录
- 课程反馈查看

#### 关键指标：
- 课程完成率
- 作业提交率
- 学员满意度

| 证书制作 | ✓ | ✗ | ✗ |
| 效果评估汇总 | ✓ | ✗ | ✗ |
| 部门培训管理 | ✓ | ✓ | ✗ |
| 课程执行 | ✓ | ✗ | ✓ |
| 作业批改 | ✓ | ✗ | ✓ |

## 5. 筛选列表功能

### 5.1 通用筛选条件
- 状态筛选（全部/待处理/处理中/已完成/异常）
- 时间范围（今天/本周/本月/自定义）
- 关键词搜索（培训名称/员工姓名/工号）

### 5.2 模块特定筛选
- **培训列表**：课程类型（必修/选修）、培训形式（线上/线下）、培训状态
- **证书列表**：证书状态、发放进度、异常标记
- **效果评估**：评估维度、评分范围、趋势方向

### 5.3 筛选联动
- 选择"异常"状态时，自动展开异常类型子筛选
- 筛选条件可保存为常用视图
- 支持导出筛选结果

## 6. 数据联动机制

### 6.1 证书变更 → 效果评估感知
```javascript
// 证书变更触发效果评估重新计算
{
  "event": "certificate_status_changed",
  "data": {
    "certificate_id": "CERT-2024-001",
    "old_status": "issued",
    "new_status": "revoked",
    "reason": "信息错误",
    "changed_by": "training_manager_001",
    "changed_at": "2024-01-15 10:30:00"
  },
  "effects": [
    {
      "module": "effect_evaluation",
      "action": "recalculate",
      "target": "course_001",
      "reason": "通过率从95%变为94.5%"
    }
  ]
}
```

### 6.2 异常处理 → 关联培训数据
- 报名流失 → 自动关联该员工的培训记录
- 作业未提交 → 自动标记影响证书发放
- 证书异常 → 自动冻结相关效果评估报告

  - 2张因作业未提交暂缓发放

## 8. 界面原型说明

### 8.1 整体布局
- **顶部导航**：角色切换 | 搜索框 | 通知中心 | 用户头像
- **左侧菜单**：根据角色动态显示菜单项
- **主内容区**：工作台 + 详情页
- **右侧抽屉**：快捷操作面板（移动端为底部弹出）

### 8.2 关键页面
1. **工作台首页**：待办事项卡片 + 关键指标 + 最近动态
2. **培训详情页**：基础信息 + 参训人员 + 异常记录 + 证书状态 + 效果评估
3. **证书处理台**：列表页 + 详情弹窗 + 批量操作
4. **效果评估页**：数据概览 + 明细表格 + 导出功能
5. **异常处理中心**：异常列表 + 跟进记录 + 处置历史

### 8.3 交互细节
- 列表项悬停显示快捷操作
- 状态变更实时更新
- 重要操作需二次确认
- 操作成功/失败即时反馈

## 9. 非功能性需求

### 9.1 性能要求
- 页面加载时间 < 2秒
- 列表查询响应时间 < 500ms
- 数据更新延迟 < 1秒

### 9.2 兼容性要求
- 支持Chrome、Firefox、Safari、Edge最新版本
- 响应式布局，支持1024px以上屏幕

### 9.3 数据安全
- 操作日志完整记录
- 敏感操作需权限验证
- 数据变更可追溯

1. ✅ 三个角色能正常切换，各角色看到对应的功能和数据
2. ✅ 证书状态变更能实时触发效果评估重新计算
3. ✅ 异常处理流程完整，状态可追溯
4. ✅ 支持筛选、搜索、分页等基础功能
5. ✅ 提供至少3条带完整历史备注的样例数据
