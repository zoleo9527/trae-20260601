## 1. 产品概述

物流园月台业务工作台，解决滞留费用计算、司机申诉处理和责任追溯的人工效率问题。通过系统化记录状态变化、责任人、时间点和备注，实现费用变动可追溯、申诉处理可回看、各角色工作节奏协同。

- 目标用户：调度员、叉车班长、仓库文员
- 核心价值：告别人工拼凑上下文，实现滞留费用与司机申诉的全流程数字化管理

## 2. 核心功能

### 2.1 用户角色

| 角色 | 核心职责 | 核心权限 |
|------|----------|----------|
| 调度员 | 车辆到车计划安排、月台分配 | 创建滞留记录、调整费用、查看所有记录 |
| 叉车班长 | 装卸货执行、异常情况上报 | 标记装卸开始/结束、提交异常备注 |
| 仓库文员 | 费用核算、申诉处理、数据核对 | 审核费用、处理申诉、导出报表 |

### 2.2 功能模块

1. **工作台首页**：数据概览、待办事项、快捷操作入口
2. **滞留费用管理**：费用列表、费用详情、状态流转、费用调整
3. **司机申诉管理**：申诉列表、申诉详情、申诉处理、历史回看
4. **筛选搜索中心**：多维度筛选、关键字搜索、状态标签过滤

| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|
| 工作台首页 | 数据概览卡片 | 今日滞留单量、待处理申诉、费用总额统计 |
| 工作台首页 | 待办事项列表 | 按角色展示待处理任务，支持一键跳转 |

## 3. 核心流程

### 3.1 滞留费用产生流程
车辆到达月台 → 叉车班长标记开始装卸 → 装卸完成（预计超时）→ 系统自动计算滞留费用 → 调度员确认费用 → 费用生效

### 3.2 司机申诉处理流程
司机提交申诉 → 仓库文员受理 → 关联滞留单详情核查 → 费用调整（如需）→ 申诉裁决 → 结果通知

### 3.3 状态流转图

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：工业蓝 #165DFF，代表专业和信赖
- **辅助色**：警示橙 #FF7D00（待处理）、成功绿 #00B42A（已完成）、危险红 #F53F3F（异常）
- **中性色**：深灰 #1D2129、中灰 #4E5969、浅灰 #C9CDD4、背景灰 #F2F3F5
- **按钮风格**：直角微圆角（4px），实心按钮为主，次要操作使用描边按钮
- **字体**：系统字体栈，中文优先 PingFang SC，英文优先 SF Pro
- **布局风格**：左侧导航 + 顶部工具栏 + 主内容区的经典业务系统布局
- **卡片风格**：白底卡片，1px 浅灰边框，2px 圆角，轻微阴影
- **图标风格**：线性图标，统一 16px/20px 尺寸

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI Elements |
|-----------|-------------|-------------|
| 工作台首页 | 数据概览 | 4张统计卡片，图标+数字+环比指标，卡片hover微上浮 |
| 工作台首页 | 待办列表 | 表格形式，每行包含状态标签、关键信息、快捷操作按钮 |
| 滞留费用列表 | 工具栏 | 搜索框、筛选下拉、状态标签组、新增按钮 |
| 滞留费用列表 | 数据表格 | 固定表头、斑马纹、行hover高亮、状态标签色区分 |
| 费用详情抽屉 | 时间线 | 垂直时间线展示所有状态变更，含操作人、时间、备注 |
| 申诉详情 | 信息区块 | 分栏布局，左侧申诉信息，右侧关联滞留单信息 |

### 4.3 响应式
- Desktop-first 设计，最小支持 1280px 宽度
- 左侧导航可折叠，适配不同屏幕尺寸
- 表格区域支持横向滚动，保证小屏数据完整性

### 4.4 交互细节
- 状态标签使用不同背景色和文字色组合，一眼可辨
- 费用变更时，新旧金额对比展示，高亮变化部分
- 操作后自动刷新列表并显示成功提示
- 表格行点击展开详情，支持连续处理不中断
