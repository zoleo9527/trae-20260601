# 博物馆社教系统-技术架构文档

## 1. 架构设计

```
┌─────────────────────────────────────────────────────┐
│                    前端应用层                         │
│  React 18 + TypeScript + TailwindCSS + React Router │
└─────────────────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────┐
│                    数据管理层                         │
│         Context API + useReducer + localStorage       │
└─────────────────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────┐
│                    Mock 数据层                       │
│     静态JSON + 运行时数据操作 + 状态持久化            │
└─────────────────────────────────────────────────────┘
```

## 2. 技术选型

- **前端框架**：React 18.2
- **构建工具**：Vite 5
- **样式方案**：TailwindCSS 3
- **路由管理**：React Router DOM 6
- **状态管理**：React Context + useReducer
- **数据持久化**：localStorage
- **图标库**：Lucide React
- **日期处理**：date-fns

## 3. 路由定义

| 路由路径 | 页面组件 | 功能描述 |
|----------|----------|----------|
| `/` | Dashboard | 今日待办工作台首页 |
| `/feedback` | FeedbackList | 反馈记录列表页 |
| `/feedback/:id` | FeedbackDetail | 反馈详情与处理页 |
| `/certificate` | CertificateList | 证书管理列表页 |
| `/certificate/:id` | CertificateDetail | 证书详情页 |
| `/flow` | FlowBoard | 流转看板页面 |

## 4. 数据模型

### 4.1 实体类型定义

```typescript
// 用户/角色
interface User {
  id: string;
  name: string;
  role: 'teacher' | 'volunteer' | 'supervisor';
  avatar?: string;
}

// 活动
interface Activity {
  id: string;
  name: string;
  date: string;
  lecturer: string;
  participantCount: number;
  status: 'upcoming' | 'ongoing' | 'completed';
}

// 反馈记录
interface Feedback {
  id: string;
  activityId: string;
  activityName: string;
  submittedAt: string;
  content: {
    summary: string;
    ratings: number;
    comments: string[];
    photos: string[];
  };
  status: 'pending_review' | 'organized' | 'pending_approval' | 'completed';
  currentStep: 'teacher' | 'volunteer' | 'supervisor';
  assigneeId: string;
  certificateEligible: boolean;
  flowLogs: FlowLog[];
}

// 证书
interface Certificate {
  id: string;
  feedbackId: string;
  activityId: string;
  activityName: string;
  recipientName: string;
  recipientPhone?: string;
  status: 'pending' | 'ready' | 'issued' | 'archived';
  issueMethod?: 'onsite' | 'mail';
  issuedAt?: string;
  issuedBy?: string;
}

// 流转日志
interface FlowLog {
  id: string;
  relatedType: 'feedback' | 'certificate';
  relatedId: string;
  operatorId: string;
  operatorName: string;
  action: 'submit' | 'review' | 'organize' | 'approve' | 'issue' | 'reject' | 'note';
  remark?: string;
  timestamp: string;
}
```

## 5. Mock数据设计

### 5.1 样例场景

#### 场景1：正常流程完成
- 活动：青铜器探秘亲子课堂
- 反馈状态：已完成
- 证书状态：已发放
- 流转记录：完整的4个节点记录

#### 场景2：需补充反馈
- 活动：古籍修复体验课
- 反馈状态：待初核（被退回）
- 当前环节：社教老师
- 包含补充说明的备注

#### 场景3：滞留任务
- 活动：瓷片鉴赏入门
- 反馈状态：已整理（超过24小时未处理）
- 当前环节：志愿者
- 预警标识

#### 场景4：批量待发放
- 活动：暑期夏令营结业
- 参与人数：35人
- 35条证书待发放记录
- 支持批量选择

#### 场景5：特殊备注案例
- 活动：志愿者培训专场
- 包含多条历史备注
- 说明为何未发证
- 关联多个操作人

### 7.1 连续处理（下一条）

```typescript
// FeedbackDetail页面逻辑
const handleNext = () => {
  const currentIndex = feedbacks.findIndex(f => f.id === currentId);
  const nextFeedback = feedbacks[currentIndex + 1];
  if (nextFeedback) {
    navigate(`/feedback/${nextFeedback.id}`);
  }
};
```
