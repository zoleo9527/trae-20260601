## 1. 产品概述

考务中心-缺考违纪与成绩发布系统，面向考试管理场景，解决缺考违纪数据从监考提交到成绩发布确认全流程缺少留痕与推进动作的问题。目标用户为考务专员、监考老师和技术支持三类角色，系统需提供可操作的工作流而非仅查询入口，确保驳回、补录等动作真实落地并留痕可追溯。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 监考老师 | 选择角色进入 | 提交缺考记录、提交违纪记录、查看本人提交记录 |
| 考务专员 | 选择角色进入 | 审核缺考违纪记录（通过/驳回/补录）、发起成绩发布、驳回成绩发布、查看全部记录与审计日志 |
| 技术支持 | 选择角色进入 | 确认成绩发布、处理导出任务、查看系统运行状态与日志 |

### 2.2 功能模块

1. **考务中心面板**：考试概览、各环节状态卡片、快捷操作入口
2. **缺考违纪管理**：缺考记录提交与审核、违纪记录提交与审核、驳回与补录操作、操作留痕
3. **成绩发布审批**：发起发布申请、审核确认、驳回打回、发布回看
4. **详情查询**：按考生/考场/科目多维度查询、详情弹窗
5. **导出任务**：缺考违纪导出、成绩导出、任务状态追踪

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|

| 考务中心面板 | 最近操作时间线 | 展示最近10条操作日志，含操作人、操作类型、时间 |
| 缺考违纪管理 | 缺考记录列表 | 按考场/科目筛选，显示考生姓名、准考证号、缺考类型、审核状态 |
| 缺考违纪管理 | 违纪记录列表 | 按考场/科目筛选，显示考生姓名、准考证号、违纪类型、审核状态 |
| 缺考违纪管理 | 提交表单 | 监考老师填写缺考/违纪信息，选择考生、类型、备注 |
| 缺考违纪管理 | 审核操作区 | 考务专员对每条记录执行通过/驳回/补录，填写审核意见，自动留痕 |
| 成绩发布审批 | 发布申请列表 | 显示待发布科目、成绩统计摘要、申请人与时间 |

| 成绩发布审批 | 发布回看 | 查看已发布成绩的详情、审批链路、操作历史 |

| 详情查询 | 结果列表与详情 | 查询结果表格，点击行展开详情（含操作历史） |
| 导出任务 | 导出任务列表 | 显示任务类型、状态、创建人、时间、下载链接 |
| 导出任务 | 创建导出 | 选择导出类型（缺考违纪/成绩）、筛选条件，提交生成 |

## 3. 核心流程

主流程为：监考老师提交缺考违纪 → 考务专员审核（通过/驳回/补录）→ 考务专员发起成绩发布 → 技术支持确认发布。驳回后监考老师可重新提交，补录由考务专员直接补充记录。每个操作节点均记录操作人、操作类型、时间戳和备注。

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝 #1e3a5f，辅助色：琥珀 #d97706，成功色 #059669，危险色 #dc2626
- 按钮：圆角 6px，主按钮实色填充，次要按钮描边
- 字体：思源黑体 / Noto Sans SC，标题 18px/16px，正文 14px，辅助文字 12px
- 布局：左侧固定导航 + 右侧内容区，卡片式布局，表格行间斑马纹
- 图标：lucide-react 图标库

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 考务中心面板 | 考试概览卡片 | 深蓝渐变背景，白色大字统计数字，底部图标 |
| 考务中心面板 | 环节状态卡片 | 横向步骤条，当前环节高亮，待办数字角标 |
| 考务中心面板 | 快捷操作区 | 按角色显示操作按钮组，琥珀色主操作，灰色次要操作 |
| 考务中心面板 | 最近操作时间线 | 左侧竖线 + 圆点 + 右侧卡片，按时间倒序 |
| 缺考违纪管理 | 列表 | 表格含筛选栏，状态标签彩色，行悬停高亮 |
| 缺考违纪管理 | 审核操作区 | 行内操作按钮，弹窗填写审核意见 |

### 4.3 响应式

桌面优先设计，最小宽度 1024px，导航栏在窄屏下折叠为侧边抽屉。
