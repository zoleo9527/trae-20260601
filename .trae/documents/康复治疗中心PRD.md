## 1. 产品概述

康复治疗中心治疗排班与签到消课管理系统，围绕"排班被打乱、评估没跟进、器械冲突"三大痛点，以催促/退回/补材料三种状态流转为主线，为康复治疗师、前台、主任提供分角色的操作视图，实现治疗排班、签到消课的完整闭环与历史回看。

- 目标用户：康复治疗中心的治疗师、前台人员、科室主任
- 核心价值：减少排班混乱与漏课，提前预警复盘关键风险，提升治疗中心运营效率

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 康复治疗师 | 简化登录选择 | 查看/操作自己的排班、执行签到消课、查看评估表、标记治疗计划状态 |
| 前台 | 简化登录选择 | 签到办理、消课确认、催促/退回/补材料处理、附件上传入口 |
| 科室主任 | 简化登录选择 | 全局排班查看与调整、复盘预警总览、审批退回/补材料、器械冲突协调 |

### 2.2 功能模块

1. **登录与角色切换页**：简化登录，选择角色即可进入对应视图
2. **治疗排班工作台**：排班列表、状态流转（催/退回/补材料）、排班调整、复盘预警标示
3. **签到消课工作台**：签到办理、消课确认、历史回看、附件占位
4. **复盘预警面板**：治疗计划打乱、评估结果未跟进、器械占用冲突的提前标示
5. **详情页**：单条排班/消课的完整信息，含历史记录、附件、状态变更日志

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能说明 |
|----------|----------|----------|
| 登录页 | 角色选择 | 选择治疗师/前台/主任角色，简化登录直接进入 |
| 治疗师-排班工作台 | 今日排班列表 | 显示当日排班，标注催/退回/补材料状态标签 |

| 主任-预警总览 | 复盘预警 | 治疗计划打乱、评估未跟进、器械冲突的聚合视图 |

| 详情页 | 排班详情 | 排班完整信息、状态变更历史、关联评估与器械 |
| 详情页 | 签到消课详情 | 签到消课记录、历史回看、附件列表 |

## 3. 核心流程

### 3.1 治疗排班状态流转

治疗排班从"待确认"开始，经催促/退回/补材料三种状态流转，最终确认或取消：

```mermaid
flowchart TD
    "待确认" --> "已催促"
    "待确认" --> "已确认"
    "待确认" --> "已退回"
    "已催促" --> "已确认"
    "已催促" --> "已退回"
    "已退回" --> "补材料中"
    "补材料中" --> "待确认"
    "补材料中" --> "已退回"
    "已确认" --> "治疗中"
    "治疗中" --> "已完成"
    "治疗中" --> "已取消"
    "待确认" --> "已取消"
```

### 3.2 签到消课流程

```mermaid
flowchart TD
    "患者到达" --> "前台签到"
    "前台签到" --> "等待治疗"
    "等待治疗" --> "治疗中"
    "治疗中" --> "消课确认"
    "消课确认" --> "已完成"
    "治疗中" --> "未到/取消"
```

### 3.3 复盘预警触发

```mermaid
flowchart TD
    "排班时间冲突" --> "治疗计划打乱预警"
    "评估后超48h无排班" --> "评估未跟进预警"
    "同一器械同一时段" --> "器械占用冲突预警"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深靛蓝 (#1e3a5f) 搭配暖橙色 (#e8723a) 作为强调色，传达专业与紧迫感
- 辅助色：浅灰蓝 (#e8edf3) 背景，白色卡片，浅黄 (#fef3cd) 用于预警
- 状态标签色彩：催促用橙色，退回用红色，补材料用蓝色
- 按钮风格：圆角矩形，主操作实心填充，次操作描边
- 字体：思源黑体 / Noto Sans SC，标题加粗，正文常规
- 布局：左侧固定导航 + 右侧内容区，卡片式信息展示
- 图标：Lucide Icons，线面风格

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 登录页 | 角色选择卡片 | 三张角色卡片横排，图标+角色名，hover 上浮阴影 |
| 治疗师排班工作台 | 排班列表 | 时间轴式列表，每条含状态标签、患者名、治疗项目、操作按钮 |
| 治疗师排班工作台 | 状态操作栏 | 底部固定操作栏：催促/补材料/查看退回 |
| 前台签到消课工作台 | 签到队列 | 卡片队列，待签到/已签到/待消课分区显示 |
| 前台签到消课工作台 | 消课弹窗 | 模态框，确认消课+器械使用选择+附件上传占位 |
| 主任预警总览 | 预警卡片组 | 三类预警分组，每张卡片含预警级别、影响范围、快捷操作 |
| 主任预警总览 | 全局排班甘特图 | 简化甘特图，按治疗师分行，标注冲突时段 |
| 详情页 | 状态时间线 | 竖向时间线，展示状态变更历史 |
| 详情页 | 附件区 | 文件列表+上传按钮（占位），外部通知入口按钮 |

### 4.3 响应式设计

- 桌面优先，最小宽度 1024px
- 侧边栏可折叠，内容区自适应
- 移动端暂不作为主要适配目标，但卡片布局在窄屏下堆叠

## 5. 附件与通知占位说明

- 附件上传：UI 入口可见（上传按钮+文件列表），点击后使用占位逻辑模拟上传，不接真实存储
- 外部通知（短信/微信提醒）：操作按钮可见，点击后 toast 提示"通知已发送（占位）"
- 占位数据要能看出是模拟的，但入口完整可交互
