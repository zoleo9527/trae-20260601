## 1. 产品概述

康复治疗中心疗程复评与续疗判断系统，用于处理疗程临近结束时的关键决策环节——结案、续疗、转诊或换方案。系统串联治疗师复评提交、主任审批建议、前台费用排期跟进的完整工作流，确保每一项续疗判断都有可量化的评估依据。

目标用户为康复治疗中心的治疗师、科室主任和前台管理人员，核心价值在于将经验性决策转化为数据驱动的规范化流程。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 治疗师 | 工号登录 | 提交复评记录、查看患者历史、编辑复评结论 |
| 科室主任 | 工号登录 | 审批复评结论、给出续疗建议、退回修改 |
| 前台 | 工号登录 | 跟进续疗费用、排期预约、更新沟通状态 |

### 2.2 功能模块

1. **复评总览页**：待复评患者列表、各状态统计看板、快捷筛选
2. **复评记录详情页**：前一阶段数据摘要、复评表单填写、结论提交
3. **审批工作台页**：待审批队列、审批操作（通过/退回）、续疗建议录入
4. **续疗计划与沟通页**：续疗方案详情、费用与排期、患者沟通状态跟踪

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 复评总览页 | 状态看板 | 显示待复评、待审批、待沟通、已结案各状态数量 |

## 3. 核心流程

治疗师在疗程临近结束时提交复评记录，包含前一阶段训练数据与评估结论。主任收到复评后进行审批，可给出续疗建议或退回补充。审批通过后，前台根据续疗建议与患者/家属沟通费用及排期，最终确认或记录暂停/拒绝状态。

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：医疗蓝绿（#0D9488），辅以暖灰底色（#F8FAFC）与警示橙（#F59E0B）
- 按钮风格：圆角微弧（8px），主要操作实色填充，次要操作描边
- 字体：标题使用思源黑体/Noto Sans SC Bold，正文使用 Noto Sans SC Regular，数字使用 JetBrains Mono
- 布局风格：左侧固定导航 + 右侧内容区，卡片式内容组织，信息密度适中
- 图标：线性图标风格，统一 20px 尺寸

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 复评总览页 | 状态看板 | 四色统计卡片，数字大号加粗，趋势箭头指示 |
| 复评总览页 | 患者列表 | 表格布局，进度条显示疗程完成度，状态标签色彩区分 |
| 复评记录详情页 | 前阶段摘要 | 三列数据卡片（训练次数/疼痛变化/未完成项），疼痛趋势迷你折线图 |
| 复评记录详情页 | 复评表单 | 分组表单，量表滑块输入，必填项标记 |
| 复评记录详情页 | 结论提交 | 单选按钮组（结案/续疗/转诊/换方案），文本域填写依据 |
| 审批工作台页 | 待审批队列 | 卡片列表，左侧患者信息右侧操作按钮 |
| 审批工作台页 | 审批操作 | 底部固定操作栏，通过绿色退回橙色 |
| 审批工作台页 | 续疗建议 | 富文本域，疗程数输入，标签式注意事项 |
| 续疗计划与沟通页 | 续疗方案 | 方案卡片，包含疗程目标与项目明细 |
| 续疗计划与沟通页 | 费用与排期 | 费用表格 + 排期时间线 |
| 续疗计划与沟通页 | 沟通状态 | 时间线式沟通记录，状态标签（已同意/已暂停/已拒绝） |

### 4.3 响应式设计

桌面优先设计，最小支持 1280px 宽度。平板端隐藏侧边栏为汉堡菜单，移动端仅保留核心列表与操作。

## 5. 样例数据

### 样例一：进展良好 → 结案

- 患者姓名：王建国，男，58岁，脑卒中后右侧偏瘫
- 第一疗程：24次训练，已完成22次
- 疼痛VAS：入院6分 → 当前2分
- 未完成项目：无
- 复评结论：结案（功能恢复达预期目标）
- 主任审批：通过
- 沟通状态：患者同意结案

### 样例二：效果不明显 → 换方案

- 患者姓名：李美玲，女，45岁，腰椎间盘突出
- 第一疗程：18次训练，已完成16次
- 疼痛VAS：入院7分 → 当前5分
- 未完成项目：核心稳定性训练3项未达标
- 复评结论：换方案（当前方案效果不佳，建议调整为麦肯基疗法）
- 主任审批：通过，建议新疗程12次
- 沟通状态：患者同意换方案，待前台确认新费用

### 样例三：家属要求暂停

- 患者姓名：张浩然，男，72岁，膝关节置换术后
- 第一疗程：20次训练，已完成14次
- 疼痛VAS：入院5分 → 当前3分
- 未完成项目：步态训练2项、上下阶梯1项未达标
- 复评结论：续疗（进展中但未达目标）
- 主任审批：通过，建议续6次
- 沟通状态：家属要求暂停，原因：家庭照护困难，预计2周后恢复
