# 税务咨询机构 - 政策判断与方案审批工作台

## 1. 产品概述

### 1.1 产品背景
税务咨询机构日常工作中面临四大痛点：
- **政策适用争议**：旧台账、现场记录、沟通截图散落各处，无法快速判断政策适用
- **底稿版本混乱**：政策判断和方案审批版本不清晰，容易混淆
- **答复无人签收**：处理结果缺乏明确的责任人和签收机制
- **复盘困难**：历史处理过程难以追溯，缺乏完整的处理链路

### 1.2 核心定位
为税务顾问、项目经理、客户财务提供统一的业务工作台，实现政策判断和方案审批的闭环管理，支持从详情页到处理完成的连续操作流程。

### 1.3 目标用户
- **税务顾问**：执行政策判断，生成处理意见
- **项目经理**：审批政策判断结果，监督处理流程
- **客户财务**：查看处理进度，签收最终方案

## 2. 功能架构

### 2.1 角色视图差异化

| 功能模块 | 税务顾问 | 项目经理 | 客户财务 |
|---------|---------|---------|---------|
| 我的待办 | ✓ | ✓ | ✓ |
| 政策判断处理 | ✓ | ✓（审批入口） | ✗ |
| 方案审批 | ✗ | ✓ | ✓（查看进度） |
| 全部记录 | ✓ | ✓ | ✓（仅查看） |
| 筛选搜索 | ✓ | ✓ | ✓ |

### 2.2 核心业务流程

```
[政策判断] ──→ [方案审批] ──→ [处理完成]
    ↓
状态：待判断 → 判断中 → 待审批 → 审批通过/驳回 → 已签收
```

### 2.3 状态定义

| 状态码 | 状态名称 | 触发角色 | 说明 |
|-------|---------|---------|------|
| 0 | 待判断 | 系统 | 新建工单等待政策判断 |
| 1 | 判断中 | 税务顾问 | 税务顾问正在处理判断 |
| 2 | 待审批 | 税务顾问 | 判断完成，等待项目经理审批 |
| 3 | 审批通过 | 项目经理 | 方案获批，可执行 |
| 4 | 审批驳回 | 项目经理 | 需要返回重新判断 |
| 5 | 已签收 | 客户财务 | 客户确认接收方案 |
| 6 | 处理完成 | 系统 | 全流程闭环 |

## 3. 页面结构

### 3.1 页面入口
- 左侧导航栏根据角色权限显示不同入口
- 顶部展示当前用户名、角色身份
- 快捷入口：我的待办（显示未处理数量徽章）

### 3.2 角色视图

#### 3.2.1 税务顾问视图
- **我的待办**：显示政策判断待处理列表
- **政策判断处理**：详细处理页面，包含判断表单、历史备注
- **全部记录**：查看所有经手的政策判断记录

#### 3.2.2 项目经理视图
- **我的待办**：显示待审批的方案列表
- **方案审批**：审批页面，显示政策判断结果和处理意见
- **全部记录**：查看所有审批记录

#### 3.2.3 客户财务视图
- **我的待办**：显示待签收的方案列表
- **方案回看**：查看已审批通过的方案详情
- **全部记录**：查看本项目的所有处理记录

### 3.3 列表页设计

#### 3.3.1 筛选搜索区域
- **快速筛选**：
  - 状态筛选（下拉多选）
  - 时间范围（开始日期 - 结束日期）
  - 业务类型（政策咨询、税务筹划、争议处理）
- **高级搜索**：
  - 关键词搜索（支持工单编号、客户名称、业务摘要）
  - 紧急程度（普通、紧急、加急）
  - 责任顾问（仅项目经理可见）

#### 3.3.2 列表展示
- **列表项信息**：
  - 工单编号（高亮显示）
  - 客户名称
  - 业务摘要（截断显示，悬停完整）
  - 当前状态（状态标签，颜色区分）
  - 创建时间
  - 最近操作时间
  - 责任人
- **批量操作**：
  - 批量指派（项目经理权限）
  - 批量导出（Excel格式）
- **列表交互**：
  - 点击行进入详情页
  - 右键菜单（快速操作）
  - 拖拽排序（自定义列表顺序）

#### 3.4.2 连续处理交互
- **政策判断处理页**：
  1. 查看关联附件（旧台账、现场记录、沟通截图）
  2. 填写判断依据、政策引用
  3. 添加风险提示和处理意见
  4. 提交判断结果
  5. 自动跳转到下一个待处理工单（可配置）

- **方案审批页**：
  1. 查看政策判断详情
  2. 查看关联附件
  3. 填写审批意见
  4. 选择审批结论（通过/驳回）
  5. 如驳回，填写驳回原因和修改建议
  6. 提交审批结果
  7. 自动跳转到下一个待审批工单

- **方案回看页（客户财务）**：
  1. 查看已审批通过的完整方案
  2. 查看处理时间轴
  3. 下载完整方案PDF
  4. 确认签收
  5. 填写签收备注

## 4. 样例数据

### 4.1 工单样例1：研发费用加计扣除政策适用争议
```
工单编号：TC-2024-00123
客户名称：科技创新有限公司
业务类型：政策咨询
紧急程度：紧急
状态：待审批

【历史备注】
2024-03-15 09:30 [税务顾问-张明]
创建工单，上传旧台账（2023年度研发费用明细.xlsx）

2024-03-15 10:20 [税务顾问-张明]
政策判断完成：
- 判断依据：根据《财政部 税务总局关于进一步完善研发费用税前加计扣除政策的公告》（2023年第7号），
  企业开展研发活动中实际发生的研发费用，未形成无形资产计入当期损益的，在按规定据实扣除的基础上，
  再按照实际发生额的100%在税前加计扣除。
- 政策引用：财税〔2023〕7号公告第一条
- 风险提示：客户提供的研发费用明细中，部分费用类型（如咖啡、招待费）不在加计扣除范围内，
  需要剔除后重新计算。
- 处理意见：建议客户重新梳理研发费用明细，剔除不符合规定的费用项目后，可按100%比例加计扣除。
  预估可节税约28万元。

2024-03-15 11:15 [客户财务-李华]
补充上传：本季度研发项目立项书、项目人员名单

2024-03-15 14:30 [项目经理-王强]
审批意见：判断依据充分，政策引用准确，风险提示到位，处理意见合理。
审批结论：通过
备注：请税务顾问协助客户完成研发费用明细的重新梳理工作。
```

### 4.2 工单样例2：高新技术企业所得税优惠争议
```
工单编号：TC-2024-00124
客户名称：制造业股份有限公司
业务类型：争议处理
紧急程度：普通
状态：审批驳回

【历史备注】
2024-03-10 09:00 [税务顾问-张明]
创建工单，上传高新技术企业资格证书、年度审计报告

2024-03-10 10:30 [税务顾问-张明]
政策判断完成：
- 判断依据：客户持有有效的高新技术企业证书（证书编号：GR2023XXXXXXXX），
  2023年度企业所得税可享受15%优惠税率。
- 政策引用：企业所得税法第二十八条、国家税务总局公告2017年第24号
- 风险提示：客户2023年度研发投入占比为4.8%，略低于高新技术企业的研发投入要求（5%），
  存在被税务机关质疑的风险。
- 处理意见：建议客户准备充分的研发投入证明材料，如研发项目立项书、研发费用台账等，
  以应对可能的税务检查。

2024-03-10 14:00 [项目经理-王强]
审批意见：初步判断正确，但风险提示不够详细。
审批结论：驳回
驳回原因：需要进一步分析研发投入占比的计算方式，并提供具体的应对建议。

2024-03-11 09:30 [税务顾问-张明]
补充判断：
- 研发投入占比计算说明：客户2023年度研发费用为860万元，销售收入为17916万元，
  占比为4.8%。但根据《高新技术企业认定管理工作指引》，研发费用是指归集到特定科目的费用，
  需要重新核对归集口径。
- 应对建议：
  1. 重新梳理研发费用归集，确保符合规定口径
  2. 准备研发项目立项书、过程管理文档、成果转化证明等辅助材料
  3. 如归集后研发投入仍低于5%，建议与税务机关提前沟通
- 预估结论：重新归集后，研发投入占比预计可达到5.2%

2024-03-11 15:00 [项目经理-王强]
审批意见：补充分析详细，风险提示充分，应对建议具体可行。
审批结论：通过
备注：请税务顾问跟进客户的研发费用归集工作。
```

## 5. 交互规范

### 5.1 状态流转交互
- 状态变更需要明确的状态标签和颜色区分
- 每次状态变更必须记录时间戳和操作人
- 驳回操作必须填写驳回原因
- 签收操作必须填写签收备注

### 5.2 连续处理机制
- 支持"处理完成后自动跳转下一条"的配置
- 未保存的修改会提示"是否保存"
- 快捷键支持：Ctrl+S 保存，Ctrl+N 下一条，Ctrl+P 上一条

### 5.3 权限控制
- 不同角色看到不同的入口和操作按钮
- 敏感操作（如审批、签收）需要二次确认
- 操作日志完整记录，支持审计追溯

### 5.4 附件管理
- 支持上传旧台账、现场记录、沟通截图
- 附件格式：PDF、Word、Excel、图片
- 附件大小限制：单个文件不超过20MB
- 支持附件预览和下载
