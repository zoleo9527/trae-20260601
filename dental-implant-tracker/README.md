# 种植牙排期追溯系统

将种植排期和耗材追溯放在同一条线上的全栈管理系统。前台安排患者节点，医生补手术记录，库管查看耗材锁定与使用状态。

## 技术栈

- **后端**: Node.js + Express + better-sqlite3 + JWT
- **前端**: React 18 + Vite + Ant Design 5 + React Router 6 + Axios
- **数据库**: SQLite（零配置，数据文件为 `server/dental.db`）

## 快速启动

```bash
# 1. 安装依赖
cd dental-implant-tracker/server && npm install
cd ../client && npm install
cd .. && npm install

# 2. 初始化数据 + 启动后端（端口 3001）
cd server && node seed.js && node index.js

# 3. 启动前端开发服务器（新终端）
cd client && npx vite --port 5173

# 4. 浏览器打开 http://localhost:5173
```

或者用并发模式一条命令启动（需先安装根目录依赖）：

```bash
npm run dev
```

> 生产部署：`cd client && npx vite build`，然后只启动后端即可自动托管前端静态文件。

### 核心页面

- **首页仪表盘**：统计卡片（总患者数、今日手术、待处理提醒、库存预警）+ 今日手术列表 + 最近提醒
- **患者管理**：搜索过滤 + 表格 + 治疗进度 Steps + 新建患者
- **患者详情（核心页面）**：基本信息卡 + **治疗时间线**（6 步可视化，可展开查看详情/完成/改期/取消）+ 关联耗材表 + 患者提醒侧栏
- **每日手术**：日期选择 + 当日节点卡片列表，按节点类型颜色区分
- **耗材管理**：分类 Tab + 状态筛选 + 搜索 + 锁定/解锁/使用/过期操作
- **提醒中心**：全部/未读/已读 Tab + 类型标签 + 标记已读
- **操作日志**：患者筛选 + 只读表格

### 提醒触发场景

1. **患者改期**：改期操作自动创建提醒，旧节点标记为 `rescheduled`，新节点创建为 `planned`
2. **耗材型号变更**：库管修改耗材型号时，手动创建提醒
3. **遗漏随访**：计划日期已过但节点仍为 `planned` 状态，前端显示红色逾期标签

## 限制条件

1. **密码明文存储**：演示用途，生产环境需使用 bcrypt 等加密
2. **JWT Secret 硬编码**：生产环境应从环境变量读取
3. **无并发控制**：SQLite 单写，适合小诊所单机使用，不适合高并发
4. **无数据备份**：需自行备份 `server/dental.db` 文件
5. **无审计加密**：操作日志明文存储
6. **耗材无批号追溯链**：仅记录批次号，未实现完整供应链追溯
7. **无消息推送**：提醒仅在页面内展示，无短信/微信推送
8. **无国际化**：全中文界面
