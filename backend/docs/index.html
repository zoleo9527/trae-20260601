📋 预约单管理

GET /api/bookings 获取预约单列表（分页/筛选）

查询参数

参数类型必填说明

statusstring否状态筛选: pending/assigned/in_progress/completed

{

    "id": "uuid",
    "customer_name": "刘先生",

    "to_address": "北京市海淀区...",

    "status": "pending",
    "total_price": 1200
  }],

  "page": 1

字段类型说明

📅 排班派工管理 核心模块

POST /api/schedules 创建排班 + 派工一步完成 关键接口

请求体 (JSON)

参数类型必填说明
vehicle_iduuid是车辆ID
booking_iduuid是预约单ID
planned_startdatetime是计划开始时间
planned_enddatetime是计划结束时间
assignmentsarray是派工人员列表
assignments[].crew_iduuid是搬运人员ID
assignments[].rolestring否角色（组长/搬运工/司机）

请求示例

{
  "vehicle_id": "v1-uuid",
  "booking_id": "b1-uuid",
  "planned_start": "2026-06-17T09:00:00Z",
  "planned_end": "2026-06-17T12:00:00Z",
  "assignments": [
    { "crew_id": "c1-uuid", "role": "组长" },
    { "crew_id": "c2-uuid", "role": "搬运工" }
  ]
}
GET /api/schedules 排班列表（多条件筛选）

查询参数

参数类型必填说明
vehicle_iduuid否按车辆筛选
statusstring否状态: created/assigned/departed/arrived/loading/moving/unloading/done
datestring否按日期筛选 (YYYY-MM-DD)
GET /api/schedules/:id 排班详情（关联预约单+派工列表）

返回包含

关联数据说明
booking关联预约单完整信息（客户/地址/价格等）
vehicle车辆信息
assignments派工人员列表（含人员姓名/角色/状态）
PATCH /api/schedules/:id/status 更新排班状态（状态流转）

请求体

参数类型必填说明
statusstring是目标状态（按顺序流转）
remarksstring否状态变更备注

状态流转

created → assigned → departed → arrived → loading → moving → unloading → done

⚠️ 异常处理 核心模块

POST /api/exceptions 创建异常（支持物损照片上传）

请求体 (multipart/form-data 或 JSON)

参数类型必填说明
booking_iduuid是关联预约单
schedule_iduuid否关联排班
typestring是delay(延误) / surcharge(加收) / damage(物损) / other
titlestring是异常标题
descriptionstring是详细描述
severitystring否low / medium / high
refund_amountnumber否建议退款金额
surcharge_amountnumber否加收金额
photosfiles否物损照片（多文件，type=damage时推荐）
GET /api/exceptions 异常列表（筛选）

查询参数

参数类型必填说明
booking_iduuid否按预约单筛选
statusstring否pending / rejected / confirmed / refunded / resolved
typestring否delay / surcharge / damage
PATCH /api/exceptions/:id/handle 处理异常（四种操作）

请求体

参数类型必填说明
actionstring是noticed(已知晓) / refunded(已退款) / closed(已关闭) / rejected(已驳回)
refund_amountnumber否实际退款金额（action=refunded时建议）
handle_remarkstring是处理意见（必填）
GET /api/exceptions/trigger/:booking_id 异常测试触发接口 测试专用

路径及查询参数

参数类型必填说明
booking_iduuid是目标预约单ID
scenariostring是delay / surcharge / damage

三种模拟场景说明

场景触发效果
delay生成"延误2小时"异常，状态pending，自动通知调度
surcharge生成"加收楼层费300元"异常，建议附加费300元
damage生成"贵重物品损坏"异常，附3张示例物损照片URL，建议退款800元

📌 通用状态枚举参考

预约单状态 (BookingStatus)

值说明流转方向
pending待调度→ assigned
assigned已派工→ in_progress
in_progress进行中→ delayed / surcharged / completed
delayed延误中→ in_progress
surcharged有加收→ completed
completed已完成终态
cancelled已取消终态

排班状态 (ScheduleStatus)

值说明
created → assigned → departed → arrived → loading → moving → unloading → done正常流程
exception发生异常（可回退到上一步）
