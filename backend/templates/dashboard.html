📌 设计说明

一体化设计：

  • 叉车派工、作业计时、退回原因、补充备注在同一条记录
  • 状态历史全程追踪，责任清晰可追溯
  • 作业计时从派工上下文自动带出，无需重复录入

API 接口：

  • 幂等提交：创建作业单支持 idempotency_key 防重复
  • 状态变更：派工→开始→结束→确认，状态流转有校验
  • 计时回看：每条作业单时间线完整可查
