# 咖啡烘焙厂 - 生豆入库与烘焙计划系统

基于 SvelteKit + SQLite 的生豆入库与烘焙计划跟踪系统，解决生豆入库和烘焙计划之间责任不清、处理过程无法追溯的问题。

## 启动方式

```bash
# 安装依赖
npm install

# 开发模式启动
npm run dev

# 生产构建
npm run build
npm run preview
```

启动后访问 http://localhost:5173

## 数据重置

删除 `data/coffee.db` 文件后重启应用，系统会自动重建数据库并填入种子数据：

```bash
rm data/coffee.db
npm run dev
```

## 核心流程

1. **生豆入库** → 记录产地/批次/检测数据 → 状态：待检验 → 已检验 → 已入库
2. **入库后创建烘焙计划** → 从生豆详情页直接创建，系统自动关联，无需额外通知
3. **烘焙计划审批** → 待审批 → 已审批 → 进行中 → 已完成
4. **烘焙批次** → 烘焙师在计划详情中创建，自动记录时间线
5. **杯测记录** → 杯测员对烘焙批次评分，结果回写到计划时间线
6. **异常处理** → 任意环节可报告异常，通过抽屉式面板提交，支持跟踪处理进度

## 模拟能力说明

以下能力为演示模拟，非生产级实现：

- **登录认证**：密码明文存储在 Cookie 中，仅做角色区分，无加密/Token 机制
- **权限控制**：仅做前端角色显示和 API 基础校验，未做细粒度权限
- **通知推送**：生豆入库 → 烘焙计划的"自动接上"通过页面内操作流程实现，非实时推送
- **烘焙批次**：开始/结束时间手动填写，未接入烘焙机硬件
- **杯测评分**：SCA 标准简化版，仅保留核心维度
- **数据存储**：SQLite 单文件，无备份/迁移机制
- **并发处理**：单进程 SQLite，无乐观锁/冲突处理
