# 🖥️ 电脑装机店 - 配件到货与装机排程系统（前端原型）

## 🚀 快速启动

```bash
cd pc-shop
npm install
npm run dev
```
访问 http://localhost:5173

## 📂 模拟数据位置

所有模拟数据位于 `src/data/` 目录下：

| 文件 | 内容 | 数据量 |
|------|------|--------|
| `parts.js` | 配件目录（CPU/GPU/主板等18种SKU） | 18条 |
| `arrivals.js` | 到货单（含验收中、已完成、批次异常等） | 4条 |
| `schedules.js` | 装机排程（价格异常、批次风险、急单） | 4条 |
| `anomalies.js` | 异常提醒、返修记录、责任认定 | 5条异常 + 3条返修 |

**状态 Store**: `src/store/app.js` - 集中管理数据和业务动作

## 🔒 关键设计：解决的三个核心问题

### ① 配置改动漏算价
- 在 `ScheduleDetail.vue` 中实现**自动价差计算引擎**
- 每行配件对比 `originalPrice` vs `currentPrice`
- 异常提醒中心独立条目，销售为责任人
- 处理弹窗支持三种确认方式，强制操作留痕

### ② 配件批次难查
- **批次号可点击**：到货详情、装机配置中每个批次号都是查询入口
- **跨单据关联**：每个返修单记录 `batchCode`，到货入库时自动匹配
- **批次预警看板**：入库时一旦关联返修，立即预警后续所有在制单

### ③ 蓝屏返修的责任和时效
- **责任认定字段**：每条返修记录明确 `responsible.person/detail/costBorne`
- **SLA可视化**：进度条直观展示已用时间/剩余时间
- **装机前强制检测**：使用了存疑批次的订单标红，必须勾选"完成4小时压力测试"才能交付
